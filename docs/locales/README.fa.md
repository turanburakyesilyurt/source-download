Source Download یک پنل Chrome DevTools است که همه منابعی را که یک صفحه وب بارگذاری می‌کند پیدا، بررسی و دانلود می‌کند. چه به فایل‌های رسانه‌ای نیاز داشته باشید، چه به اسکریپت‌های توسعه، منابع استایل یا پاسخ‌های شبکه، می‌توانید آن‌ها را به‌صورت فایل‌های جداگانه یا در یک ZIP مرتب با ساختار پوشه‌ای ذخیره کنید.

از صفر و بدون هیچ وابستگی به کتابخانه‌های ثالث ساخته شده است: مولد ZIP، سازنده XLSX، ادغام‌کننده HLS و قالب‌بندهای کد همگی با JavaScript خالص و به‌صورت دستی نوشته شده‌اند. بدون فریم‌ورک، بدون مرحله ساخت، بدون تله‌متری. همه‌چیز به‌صورت محلی در مرورگر شما اجرا می‌شود.

## تازه‌ها در v1.16.0
- پشتیبانی کامل چندزبانه در 54 زبان، با بومی‌سازی کامل DevTools و صفحه فروشگاه.
- 17 دسته‌بندی اختصاصی منابع با شمارنده زنده، شامل همه رسانه‌ها، کد، API، ذخیره‌سازی و اسناد.
- اسکرین‌شات‌های دوخته‌شده از کل صفحه و ثبت ناحیه دلخواه با پنهان‌سازی هوشمند سربرگ‌های ثابت.
- ضبط ویدیوی صفحه (MP4) و موتور سبک خروجی GIF متحرک بدون نشت لبه‌ها.
- استخراج زنده جدول‌های DOM به Microsoft Excel (.XLSX) چندبرگه‌ای و CSV، به‌همراه حذف‌کننده عناصر DOM Zapper.
- قطره‌چکان رنگ روی صفحه با کپی فوری hex/rgb/hsl و زیباساز کد یکپارچه.
- پایداری بهتر اسنیفر DevTools و خط لوله شبکه با هم‌روندی بالا.

## چرا به آن نیاز دارید
اسکرین‌شات کافی نیست. فایل‌های واقعی را بردارید — تصاویر با وضوح کامل، جریان‌های ویدیویی اصلی، استایل‌شیت‌ها و اسکریپت‌های اصلی — نه یک تصویر مسطح.

DevTools گاهی طاقت‌فرسا به نظر می‌رسد. Source Download همان داده‌های شبکه را در یک گالری تمیز و دسته‌بندی‌شده، با جستجو، فیلتر و دانلود تک‌کلیکی پیش روی شما می‌گذارد.

SPAها همه‌چیز را پنهان می‌کنند. برنامه‌های پویا منابع و فراخوانی‌های API‌ای می‌سازند که هرگز در منبع صفحه نمی‌بینید. Source Download آن‌ها را همان لحظه‌ای که رخ می‌دهند، از جمله حالت‌های میانی، ثبت می‌کند.

## چه کارهایی انجام می‌دهد
### کشف همه‌چیز
- ثبت شبکه (HAR + درخواست‌های زنده) را با اسکن DOM برای همه عناصر بصری و ساختاری، از جمله فایل‌های رسانه‌ای، اسکریپت‌ها، استایل‌شیت‌ها و فریم‌های جاسازی‌شده ترکیب می‌کند.
- **آگاه از CSS:** منابع داخل url(...) و قوانین @import به‌صورت بازگشتی دنبال می‌شوند، بنابراین حتی فونت‌های پنهان در استایل‌شیت‌های وارد‌شده هم پیدا می‌شوند.
- **تشخیص از روی محتوا:** چند بایت از فایل‌های ناشناخته خوانده می‌شود و فایل به دسته نوع واقعی خود منتقل می‌شود.
- **17 دسته با شمارنده زنده:** منابع ثبت‌شده در زبانه‌های اختصاصی برای رسانه، کد، داده، فراخوانی‌های API، کوکی‌ها، ذخیره‌سازی و اسناد مرتب می‌شوند.

### فیلتر، جستجو، بررسی
- جستجوی مبتنی بر عبارت منظم در نام فایل‌ها، URLها، نوع‌های MIME، متن جایگزین و حتی محتوای فایل‌ها.
- **فیلترهای هر دسته:** حداقل/حداکثر اندازه و برای رسانه، حداقل/حداکثر عرض و ارتفاع — برای مثال «فقط تصاویر شاخص ≥ 1200px». فراخوانی‌های API بر اساس متد HTTP و نوع درخواست فیلتر می‌شوند.
- نمای فهرستی یا شبکه‌ای، قابل مرتب‌سازی، با دیواره زنده تصاویر بندانگشتی.
- **بازرس با زبانه‌های متعدد و با پیش‌نمایش واقعی:** لایت‌باکس قابل بزرگ‌نمایی، پخش ویدیو و صدا، نمونه زنده فونت، نمایشگر SVG، کد با هایلایت نحوی و شماره خط و کلید زیبا کردن.
- **نمای تقسیم‌شده API:** پاسخ در سمت چپ؛ متد، وضعیت، پارامترهای query و بدنه درخواست در سمت راست.

### دانلود اصولی
- دانلود انتخاب‌شده‌ها — فقط فایل‌هایی که علامت زده‌اید.
- دانلود نما — هر آنچه پس از فیلترها و جستجوی فعلی نمایان است.
- دانلود همه — همه منابع ثبت‌شده در یک ZIP با ساختار پوشه‌ای و حذف خودکار موارد تکراری.
- دانلودهای گروهی با هم‌روندی محدود و نوار پیشرفت زنده اجرا می‌شوند؛ موارد ناموفق به‌طور خودکار و همچنین از طریق منوی راست‌کلیک دوباره تلاش می‌شوند.

### HLS و ویدیوهای پیچیده
- جریان‌هایی که مرورگر به‌صورت بومی نمی‌تواند پخش کند (HLS .m3u8، DASH .mpd، کدک‌های ناشناخته) به‌جای پخش‌کننده سیاه، یک راه‌حل جایگزین هوشمند نشان می‌دهند.
- ادغام بخش‌ها و دانلود، یک جریان HLS را درست داخل پنل به یک فایل قابل پخش تبدیل می‌کند.

### میز کار متن (جعبه‌ابزار محتوای SPA)
- **زبانه متن یک نمایشگر زنده محتواست:** هر عنصری که متن دارد — عنوان‌ها، پاراگراف‌ها، آیتم‌های فهرست، دکمه‌ها، divها، spanها — به ترتیب DOM ثبت می‌شود.
- جدول‌های پویا تاریخچه محدودی از اسنپ‌شات‌ها را نگه می‌دارند (مثلاً «8 اسنپ‌شات · 124 ردیف یکتا»)، تا داشبوردهای با بازخوانی خودکار هرگز حالت‌های میانی را از دست ندهند.
- خروجی به‌صورت Markdown، یا جدول‌ها به‌صورت CSV، HTML یا یک فایل XLSX واقعی چندبرگه‌ای که با مولد XLSX دست‌نویس خودمان ساخته می‌شود.

## نحوه استفاده
1. Source Download را نصب کنید، سپس در هر صفحه F12 را بزنید.
2. روی زبانه Source Download در نوار ابزار DevTools کلیک کنید (Chrome اجازه نمی‌دهد افزونه‌ها DevTools را خودکار باز کنند — به همین دلیل آنجا قرار دارد).
3. زبانه‌های دسته‌بندی را مرور کنید، جستجو و فیلتر کنید و هر چیزی را در پنل سمت راست بررسی کنید.
4. فایل‌های دلخواه را علامت بزنید و دانلود انتخاب‌شده‌ها، دانلود نما یا دانلود همه را بزنید.
5. پنل DevTools را هنگام بارگذاری صفحه باز نگه دارید تا همه درخواست‌های شبکه ثبت شوند.

## کاربردهای واقعی
- **تحلیل رقبا:** تصاویر بندانگشتی ویدیوهای هر کانال را — با فیلتر حداقل عرض — در یک پوشه جمع کنید.
- **وب اسکرپینگ بدون کد:** فراخوانی‌های API یک SPA را زیر نظر بگیرید، endpoint موردنظر را فیلتر کنید و پاسخ‌های JSON دقیق آن را دانلود کنید.
- **کالبدشکافی تایپوگرافی:** بفهمید یک سایت واقعاً از کدام فونت استفاده می‌کند و فایل‌های فونت اصلی را بردارید.
- **بازتولید باگ:** نسخه‌های دقیق CSS/JS را که هنگام بروز باگ منتشر شده بود نگه دارید.
- **خروجی داده داشبورد:** یک جدول با بازخوانی خودکار را به همراه تاریخچه، به یک فایل Excel چندبرگه‌ای صادر کنید.
- **تست QA:** بررسی کنید در هر پیکربندی A/B کدام نسخه ویدیو/صدا ارائه می‌شود.

## حریم خصوصی
- 100% محلی اجرا می‌شود. بدون سرور، بدون آنالیتیکس، هیچ داده‌ای از دستگاه شما خارج نمی‌شود.
- **فقط آنچه لازم دارد درخواست می‌کند:** ذخیره‌سازی (تنظیمات شما)، کلیپ‌بورد (کپی URLها و رنگ‌ها)، دانلودها (ذخیره فایل‌ها از طریق Chrome)، منوهای راست‌کلیک، اسکریپت‌نویسی و دسترسی به میزبان (برای اسکن صفحه‌ها و دریافت محتوای فایل‌ها).
- فایل‌ها از طریق روند عادی دانلود Chrome ذخیره می‌شوند — بدون دانلود پنهانی.

## نصب و شروع سریع

### روش 1: نصب مستقیم از Chrome Web Store (توصیه‌شده)
1. به [صفحه رسمی Source Download در Chrome Web Store](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd) بروید.
2. روی **Add to Chrome** کلیک کنید و مجوزها را بدهید.
3. Chrome DevTools را باز کنید (`F12` یا `Ctrl+Shift+I` / در macOS `Cmd+Option+I`) و روی زبانه **Source Download** کلیک کنید، یا در هر جای صفحه راست‌کلیک کنید.

### روش 2: بارگذاری افزونه از سورس (حالت توسعه‌دهنده)
1. مخزن رسمی GitHub را کلون کنید:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome را باز کنید و به `chrome://extensions` بروید.
3. کلید **Developer mode** را در گوشه بالا سمت راست فعال کنید.
4. روی **Load unpacked** کلیک کنید و پوشه کلون‌شده پروژه `source-download` را انتخاب کنید.
