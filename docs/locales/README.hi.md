- टेबल से स्प्रेडशीट: लाइव टेबल को Excel या CSV में एक्सपोर्ट करें, बदलती रहने वाली टेबल की पिछली स्थितियों के साथ।
- ऑफ़लाइन कॉपी: किसी साइट को एक HTML दस्तावेज़ के रूप में रखें जो बिना इंटरनेट खुलता है।
- कलर पिकर: दिख रहा कोई भी रंग चुनें और उसे HEX, RGB या HSL के रूप में कॉपी करें।

## शुरू कैसे करें
1. वह साइट खोलें जिस पर आप काम करना चाहते हैं।
2. F12 दबाएँ (Mac पर Option + Command + I) और Source Download टैब चुनें। अगर यह न दिखे, तो टैब बार के आखिर में » पर क्लिक करें।
3. लोड होते समय पैनल खुला रखें ताकि कुछ न छूटे।

स्क्रीनशॉट, रिकॉर्डिंग और कलर पिकर राइट-क्लिक मेन्यू और एक्सटेंशन बटन से भी मिलते हैं।

## निजता

सब कुछ आपके कंप्यूटर पर चलता है। न अकाउंट है और न एनालिटिक्स, और आपकी सहेजी कोई भी चीज़ डेवलपर को नहीं भेजी जाती। सहेजी गई चीज़ें Chrome के ज़रिए आपके सामान्य डाउनलोड फ़ोल्डर में जाती हैं।

एक्सटेंशन को देखी गई साइटों तक पहुँच चाहिए, ताकि वह उनके संसाधन ढूँढ सके और अपने काम कर सके।

कृपया कॉपीराइट और इस्तेमाल की शर्तों का सम्मान करें और सिर्फ़ वही सामग्री रखें जिसे इस्तेमाल करने की आपको अनुमति है।

## इंस्टॉलेशन और क्विक स्टार्ट

### तरीका 1: Chrome Web Store से सीधे इंस्टॉल करें (अनुशंसित)
1. आधिकारिक [Source Download Chrome Web Store लिस्टिंग](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd) पर जाएँ।
2. **Chrome में जोड़ें** पर क्लिक करें और अनुमतियाँ दें।
3. Chrome DevTools खोलें (`F12` या `Ctrl+Shift+I` / macOS पर `Cmd+Option+I`) और **Source Download** टैब पर क्लिक करें, या पेज पर कहीं भी राइट-क्लिक करें।

### तरीका 2: सोर्स से अनपैक्ड एक्सटेंशन लोड करें (डेवलपर मोड)
1. आधिकारिक GitHub रिपॉज़िटरी क्लोन करें:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome खोलें और `chrome://extensions` पर जाएँ।
3. ऊपर दाएँ कोने में **डेवलपर मोड** टॉगल चालू करें।
4. **अनपैक्ड लोड करें** पर क्लिक करें और क्लोन किया हुआ `source-download` प्रोजेक्ट फ़ोल्डर चुनें।
