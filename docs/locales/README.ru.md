Source Download — набор инструментов для сохранения веб-контента. Он добавляет в инструменты разработчика Chrome отдельную вкладку. Там всё загруженное сайтом разложено по категориям. Можно посмотреть превью и оставить только нужное.

## Основные возможности
- Упорядоченная галерея: фото, иконки и шрифты показаны на своих вкладках со счётчиками в реальном времени и строкой поиска.
- Точные фильтры: показывайте только элементы шире заданного минимума, например 1200 px, или скрывайте дубликаты.
- Настоящий предпросмотр: увеличивайте графику и воспроизводите медиа. Можно открыть образец шрифта или код с подсветкой синтаксиса.
- Один архив: отметьте нужное и получите единый ZIP с аккуратной структурой папок. Неудачные загрузки повторяются в один клик.
- Скриншот всей страницы: всё прокручивается и склеивается в PNG, JPG или PDF. Можно выделить и отдельную область.
- Запись области: превратите часть экрана в клип GIF, MP4 или WebM.
- Таблицы в электронные таблицы: экспортируйте живые таблицы в Excel или CSV, включая прежние состояния обновляющихся таблиц.
- Офлайн-копия: сохраните сайт как один HTML-документ, который открывается без интернета.
- Пипетка: выберите любой цвет на экране и скопируйте его в HEX, RGB или HSL.

## Как начать
1. Откройте сайт, с которым хотите работать.
2. Нажмите F12 (на Mac — Option + Command + I) и выберите вкладку Source Download. Если её не видно, нажмите » в конце панели вкладок.
3. Держите панель открытой во время загрузки, чтобы ничего не упустить.

Скриншоты, запись и пипетка доступны также в контекстном меню и по кнопке расширения.

## Конфиденциальность

Всё работает на вашем компьютере. Нет аккаунта и аналитики, и ничего из сохранённого не отправляется разработчику. Файлы попадают в вашу обычную папку «Загрузки» через Chrome.

Расширению нужен доступ к посещаемым сайтам, чтобы находить их ресурсы и выполнять свои функции.

Соблюдайте авторские права и условия использования и сохраняйте только тот контент, на который у вас есть право.

## Установка и быстрый старт

### Способ 1: прямая установка из Chrome Web Store (рекомендуется)
1. Откройте официальную [страницу Source Download в Chrome Web Store](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd).
2. Нажмите **Установить** (Add to Chrome) и предоставьте разрешения.
3. Откройте Chrome DevTools (`F12` или `Ctrl+Shift+I` / `Cmd+Option+I` на macOS) и перейдите на вкладку **Source Download** либо щёлкните правой кнопкой мыши в любом месте страницы.

### Способ 2: загрузка распакованного расширения из исходников (режим разработчика)
1. Клонируйте официальный репозиторий GitHub:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Откройте Google Chrome и перейдите по адресу `chrome://extensions`.
3. Включите переключатель **Режим разработчика** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** и выберите клонированную папку проекта `source-download`.
