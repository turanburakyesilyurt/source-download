## ನಿಮಗೇಕೆ ಇದು ಬೇಕು
ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಸಾಕಾಗುವುದಿಲ್ಲ. ಚಪ್ಪಟೆಯಾದ ಚಿತ್ರವಲ್ಲ, ನಿಜವಾದ ಫೈಲ್‌ಗಳನ್ನು ಪಡೆಯಿರಿ — ಪೂರ್ಣ ರೆಸಲ್ಯೂಶನ್ ಚಿತ್ರಗಳು, ನಿಜವಾದ ವೀಡಿಯೊ ಸ್ಟ್ರೀಮ್‌ಗಳು, ಮೂಲ ಸ್ಟೈಲ್‌ಶೀಟ್‌ಗಳು ಮತ್ತು ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು.

DevTools ಕಷ್ಟಕರವೆನಿಸುತ್ತದೆ. Source Download ಅದೇ ನೆಟ್‌ವರ್ಕ್ ಡೇಟಾವನ್ನು ಹುಡುಕಾಟ, ಫಿಲ್ಟರ್‌ಗಳು ಮತ್ತು ಒಂದೇ ಕ್ಲಿಕ್ ಡೌನ್‌ಲೋಡ್‌ಗಳೊಂದಿಗೆ ಸ್ವಚ್ಛ, ವರ್ಗೀಕೃತ ಗ್ಯಾಲರಿಯಲ್ಲಿ ನಿಮ್ಮ ಮುಂದಿಡುತ್ತದೆ.

SPA ಎಲ್ಲವನ್ನೂ ಮರೆಮಾಡುತ್ತದೆ. ಡೈನಾಮಿಕ್ ಅಪ್ಲಿಕೇಶನ್‌ಗಳು ಪುಟದ ಮೂಲದಲ್ಲಿ ನೀವು ಎಂದಿಗೂ ನೋಡದ ಸಂಪನ್ಮೂಲಗಳು ಮತ್ತು API ಕರೆಗಳನ್ನು ರಚಿಸುತ್ತವೆ. Source Download ಅವುಗಳನ್ನು ಮಧ್ಯಂತರ ಸ್ಥಿತಿಗಳು ಸೇರಿದಂತೆ ಸಂಭವಿಸುತ್ತಿರುವಂತೆಯೇ ಸೆರೆಹಿಡಿಯುತ್ತದೆ.

## ಇದು ಏನು ಮಾಡುತ್ತದೆ
### ಎಲ್ಲವನ್ನೂ ಪತ್ತೆಹಚ್ಚಿ
- ಮೀಡಿಯಾ ಫೈಲ್‌ಗಳು, ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು, ಸ್ಟೈಲ್‌ಶೀಟ್‌ಗಳು ಮತ್ತು ಎಂಬೆಡ್ ಮಾಡಿದ ಫ್ರೇಮ್‌ಗಳು ಸೇರಿದಂತೆ ಎಲ್ಲಾ ದೃಶ್ಯ ಮತ್ತು ರಚನಾತ್ಮಕ ಅಂಶಗಳಿಗಾಗಿ ನೆಟ್‌ವರ್ಕ್ ಸೆರೆಹಿಡಿಯುವಿಕೆ (HAR + ಲೈವ್ ವಿನಂತಿಗಳು) ಮತ್ತು DOM ಸ್ಕ್ಯಾನ್ ಅನ್ನು ಸಂಯೋಜಿಸುತ್ತದೆ.
- **CSS-ಅರಿವು:** url(...) ಮತ್ತು @import ನಿಯಮಗಳೊಳಗಿನ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಪುನರಾವರ್ತಿತವಾಗಿ ಅನುಸರಿಸಲಾಗುತ್ತದೆ, ಆದ್ದರಿಂದ ಆಮದು ಮಾಡಿದ ಸ್ಟೈಲ್‌ಶೀಟ್‌ಗಳಲ್ಲಿ ಹುದುಗಿರುವ ಫಾಂಟ್‌ಗಳೂ ಸಿಗುತ್ತವೆ.
- **ವಿಷಯ ಸ್ನಿಫಿಂಗ್:** ಅಜ್ಞಾತ ಫೈಲ್‌ಗಳ ಕೆಲವು ಬೈಟ್‌ಗಳನ್ನು ಓದಿ ಅವುಗಳ ನಿಜವಾದ ಫೈಲ್ ಪ್ರಕಾರದ ವರ್ಗಕ್ಕೆ ಬಡ್ತಿ ನೀಡಲಾಗುತ್ತದೆ.
- **17 ಲೈವ್-ಎಣಿಕೆ ವರ್ಗಗಳು:** ಸೆರೆಹಿಡಿದ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಮೀಡಿಯಾ, ಕೋಡ್, ಡೇಟಾ, API ಕರೆಗಳು, ಕುಕೀಗಳು, ಸಂಗ್ರಹಣೆ ಮತ್ತು ಡಾಕ್ಯುಮೆಂಟ್‌ಗಳಿಗಾಗಿ ಮೀಸಲಾದ ಟ್ಯಾಬ್‌ಗಳಲ್ಲಿ ಅಚ್ಚುಕಟ್ಟಾಗಿ ಜೋಡಿಸಲಾಗುತ್ತದೆ.

### ಫಿಲ್ಟರ್, ಹುಡುಕಿ, ಪರಿಶೀಲಿಸಿ
- ಫೈಲ್ ಹೆಸರುಗಳು, URL ಗಳು, MIME ಪ್ರಕಾರಗಳು, alt ಪಠ್ಯ ಮತ್ತು ಫೈಲ್ ವಿಷಯಗಳಲ್ಲೂ Regex ಚಾಲಿತ ಹುಡುಕಾಟ.
- **ಪ್ರತಿ ವರ್ಗಕ್ಕೆ ಫಿಲ್ಟರ್‌ಗಳು:** ಕನಿಷ್ಠ/ಗರಿಷ್ಠ ಗಾತ್ರ, ಮತ್ತು ಮೀಡಿಯಾಗೆ ಕನಿಷ್ಠ/ಗರಿಷ್ಠ ಅಗಲ ಮತ್ತು ಎತ್ತರ — ಉದಾಹರಣೆಗೆ "≥ 1200px ಇರುವ ಹೀರೋ ಚಿತ್ರಗಳು ಮಾತ್ರ". API ಕರೆಗಳನ್ನು HTTP ವಿಧಾನ ಮತ್ತು ವಿನಂತಿ ಪ್ರಕಾರದ ಮೂಲಕ ಫಿಲ್ಟರ್ ಮಾಡಿ.
- ಪಟ್ಟಿ ಅಥವಾ ಗ್ರಿಡ್ ವೀಕ್ಷಣೆ, ವಿಂಗಡಿಸಬಹುದಾದ, ಲೈವ್ ಥಂಬ್‌ನೇಲ್ ಗೋಡೆಯೊಂದಿಗೆ.
- **ನಿಜವಾದ ಪೂರ್ವವೀಕ್ಷಣೆಗಳೊಂದಿಗೆ ಬಹು-ಟ್ಯಾಬ್ ಇನ್‌ಸ್ಪೆಕ್ಟರ್:** ಜೂಮ್ ಮಾಡಬಹುದಾದ ಲೈಟ್‌ಬಾಕ್ಸ್, ವೀಡಿಯೊ ಮತ್ತು ಆಡಿಯೋ ಪ್ಲೇಬ್ಯಾಕ್, ಲೈವ್ ಫಾಂಟ್ ಮಾದರಿ, SVG ವೀಕ್ಷಕ, ಸಾಲು ಸಂಖ್ಯೆಗಳೊಂದಿಗೆ ಸಿಂಟ್ಯಾಕ್ಸ್-ಹೈಲೈಟ್ ಮಾಡಿದ ಕೋಡ್ ಮತ್ತು ಸುಂದರಗೊಳಿಸು ಟಾಗಲ್.
- **API ವಿಭಜಿತ ವೀಕ್ಷಣೆ:** ಎಡಭಾಗದಲ್ಲಿ ಪ್ರತಿಕ್ರಿಯೆ, ಬಲಭಾಗದಲ್ಲಿ ವಿಧಾನ, ಸ್ಥಿತಿ, ಕ್ವೆರಿ ಪ್ಯಾರಾಮೀಟರ್‌ಗಳು ಮತ್ತು ವಿನಂತಿ ಬಾಡಿ.

### ಸರಿಯಾಗಿ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ
- ಡೌನ್‌ಲೋಡ್ ಆಯ್ಕೆ ಮಾಡಲಾಗಿದೆ — ನೀವು ಗುರುತಿಸಿದ ಫೈಲ್‌ಗಳು ಮಾತ್ರ.
- ಡೌನ್‌ಲೋಡ್ ವೀಕ್ಷಣೆ — ಪ್ರಸ್ತುತ ಫಿಲ್ಟರ್‌ಗಳು ಮತ್ತು ಹುಡುಕಾಟದ ನಂತರ ಕಾಣುವ ಎಲ್ಲವೂ.
- ಎಲ್ಲವನ್ನೂ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ — ಸ್ವಯಂಚಾಲಿತ ನಕಲು ತೆಗೆಯುವಿಕೆಯೊಂದಿಗೆ ಸೆರೆಹಿಡಿದ ಪ್ರತಿಯೊಂದು ಸಂಪನ್ಮೂಲವೂ ಫೋಲ್ಡರ್ ರಚನೆಯ ZIP ಆಗಿ.
- ಬ್ಯಾಚ್ ಡೌನ್‌ಲೋಡ್‌ಗಳು ಮಿತಿಯ ಸಮಕಾಲಿಕತೆ ಮತ್ತು ಲೈವ್ ಪ್ರಗತಿ ಪಟ್ಟಿಯೊಂದಿಗೆ ಚಲಿಸುತ್ತವೆ; ವಿಫಲವಾದವುಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಮತ್ತು ಸಂದರ್ಭ ಮೆನುವಿನಿಂದ ಮರುಪ್ರಯತ್ನಿಸಲಾಗುತ್ತದೆ.

### HLS ಮತ್ತು ಕ್ಲಿಷ್ಟ ವೀಡಿಯೊ
- ಬ್ರೌಸರ್ ಸ್ವಾಭಾವಿಕವಾಗಿ ಪ್ಲೇ ಮಾಡಲಾಗದ ಸ್ಟ್ರೀಮ್‌ಗಳು (HLS .m3u8, DASH .mpd, ಅಜ್ಞಾತ ಕೋಡೆಕ್‌ಗಳು) ಕಪ್ಪು ಪ್ಲೇಯರ್ ಬದಲು ಸ್ಮಾರ್ಟ್ ಪರ್ಯಾಯವನ್ನು ತೋರಿಸುತ್ತವೆ.
- ವಿಭಾಗಗಳನ್ನು ವಿಲೀನಗೊಳಿಸಿ ಮತ್ತು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ HLS ಸ್ಟ್ರೀಮ್ ಅನ್ನು ಪ್ಯಾನೆಲ್‌ನಲ್ಲೇ ಒಂದೇ ಪ್ಲೇ ಮಾಡಬಹುದಾದ ಫೈಲ್ ಆಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ.

### ಪಠ್ಯ ವರ್ಕ್‌ಬೆಂಚ್ (SPA ವಿಷಯ ಟೂಲ್‌ಕಿಟ್)
- **ಪಠ್ಯ ಟ್ಯಾಬ್ ಒಂದು ಲೈವ್ ವಿಷಯ ವೀಕ್ಷಕ:** ಪಠ್ಯವನ್ನು ಹೊಂದಿರುವ ಪ್ರತಿಯೊಂದು ಅಂಶವೂ — ಶೀರ್ಷಿಕೆಗಳು, ಪ್ಯಾರಾಗ್ರಾಫ್‌ಗಳು, ಪಟ್ಟಿ ಐಟಂಗಳು, ಬಟನ್‌ಗಳು, div, span — DOM ಕ್ರಮದಲ್ಲಿ ಸೆರೆಹಿಡಿಯಲಾಗುತ್ತದೆ.
- ಡೈನಾಮಿಕ್ ಟೇಬಲ್‌ಗಳು ಮಿತಿಯ ಸ್ನ್ಯಾಪ್‌ಶಾಟ್ ಇತಿಹಾಸವನ್ನು ಇಟ್ಟುಕೊಳ್ಳುತ್ತವೆ (ಉದಾ. "8 ಸ್ನ್ಯಾಪ್‌ಶಾಟ್‌ಗಳು · 124 ವಿಶಿಷ್ಟ ಸಾಲುಗಳು"), ಆದ್ದರಿಂದ ಸ್ವಯಂ-ರಿಫ್ರೆಶ್ ಆಗುವ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ಗಳು ಮಧ್ಯಂತರ ಸ್ಥಿತಿಗಳನ್ನು ಎಂದಿಗೂ ಕಳೆದುಕೊಳ್ಳುವುದಿಲ್ಲ.
- Markdown ಆಗಿ ರಫ್ತು ಮಾಡಿ, ಅಥವಾ ಟೇಬಲ್‌ಗಳನ್ನು CSV, HTML ಅಥವಾ ನಮ್ಮದೇ ಕೈಯಿಂದ ಬರೆದ XLSX ರೈಟರ್ ನಿರ್ಮಿಸಿದ ನಿಜವಾದ ಬಹು-ಶೀಟ್ XLSX ವರ್ಕ್‌ಬುಕ್ ಆಗಿ ರಫ್ತು ಮಾಡಿ.

## ಬಳಸುವ ವಿಧಾನ
1. Source Download ಸ್ಥಾಪಿಸಿ, ನಂತರ ಯಾವುದೇ ಪುಟದಲ್ಲಿ F12 ಒತ್ತಿ.
2. DevTools ಟೂಲ್‌ಬಾರ್‌ನಲ್ಲಿ Source Download ಟ್ಯಾಬ್ ಕ್ಲಿಕ್ ಮಾಡಿ (ವಿಸ್ತರಣೆಗಳು DevTools ಅನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ತೆರೆಯಲು Chrome ಅನುಮತಿಸುವುದಿಲ್ಲ — ಅದಕ್ಕಾಗಿಯೇ ಇದು ಅಲ್ಲಿದೆ).
3. ವರ್ಗ ಟ್ಯಾಬ್‌ಗಳನ್ನು ಬ್ರೌಸ್ ಮಾಡಿ, ಹುಡುಕಿ, ಫಿಲ್ಟರ್ ಮಾಡಿ, ಬಲಭಾಗದ ಪ್ಯಾನೆಲ್‌ನಲ್ಲಿ ಯಾವುದನ್ನಾದರೂ ಪರಿಶೀಲಿಸಿ.
4. ನಿಮಗೆ ಬೇಕಾದ ಫೈಲ್‌ಗಳನ್ನು ಗುರುತಿಸಿ ಮತ್ತು ಡೌನ್‌ಲೋಡ್ ಆಯ್ಕೆ ಮಾಡಲಾಗಿದೆ, ಡೌನ್‌ಲೋಡ್ ವೀಕ್ಷಣೆ ಅಥವಾ ಎಲ್ಲವನ್ನೂ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ ಒತ್ತಿ.
5. ಪ್ರತಿ ನೆಟ್‌ವರ್ಕ್ ವಿನಂತಿಯನ್ನು ಸೆರೆಹಿಡಿಯಲು ಪುಟ ಲೋಡ್ ಆಗುವಾಗ DevTools ಪ್ಯಾನೆಲ್ ತೆರೆದಿರಲಿ.

## ನೈಜ ಬಳಕೆಯ ಸಂದರ್ಭಗಳು
- **ಸ್ಪರ್ಧಿಗಳ ವಿಶ್ಲೇಷಣೆ:** ಯಾವುದೇ ಚಾನಲ್‌ನ ವೀಡಿಯೊ ಥಂಬ್‌ನೇಲ್‌ಗಳನ್ನು — ಕನಿಷ್ಠ ಅಗಲ ಫಿಲ್ಟರ್‌ನೊಂದಿಗೆ — ಒಂದೇ ಫೋಲ್ಡರ್‌ಗೆ ಸಂಗ್ರಹಿಸಿ.
- **ಕೋಡ್ ಇಲ್ಲದೆ ವೆಬ್ ಸ್ಕ್ರೇಪಿಂಗ್:** SPA ಯ API ಕರೆಗಳನ್ನು ಗಮನಿಸಿ, ನಿಮಗೆ ಬೇಕಾದ ಎಂಡ್‌ಪಾಯಿಂಟ್‌ಗೆ ಫಿಲ್ಟರ್ ಮಾಡಿ, ಅದರ ನಿಖರವಾದ JSON ಪ್ರತಿಕ್ರಿಯೆಗಳನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ.
- **ಟೈಪೋಗ್ರಫಿ ವಿಶ್ಲೇಷಣೆ:** ಸೈಟ್ ನಿಜವಾಗಿ ಯಾವ ಫಾಂಟ್ ಬಳಸುತ್ತದೆ ಎಂದು ಕಂಡುಹಿಡಿದು ನಿಜವಾದ ಫಾಂಟ್ ಫೈಲ್‌ಗಳನ್ನು ಪಡೆಯಿರಿ.
- **ಬಗ್ ಮರುಸೃಷ್ಟಿ:** ಬಗ್ ಸಂಭವಿಸಿದಾಗ ಬಿಡುಗಡೆಯಾಗಿದ್ದ ನಿಖರವಾದ CSS/JS ಆವೃತ್ತಿಗಳನ್ನು ಇಟ್ಟುಕೊಳ್ಳಿ.
- **ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಡೇಟಾ ರಫ್ತು:** ಸ್ವಯಂ-ರಿಫ್ರೆಶ್ ಆಗುವ ಟೇಬಲ್ ಅನ್ನು ಇತಿಹಾಸ ಸಹಿತ ಬಹು-ಶೀಟ್ Excel ವರ್ಕ್‌ಬುಕ್‌ಗೆ ರಫ್ತು ಮಾಡಿ.
- **QA ಪರೀಕ್ಷೆ:** ಪ್ರತಿ A/B ಕಾನ್ಫಿಗರೇಶನ್‌ನಲ್ಲಿ ಯಾವ ವೀಡಿಯೊ/ಆಡಿಯೋ ರೂಪಾಂತರ ಒದಗಿಸಲಾಗುತ್ತದೆ ಎಂದು ಪರಿಶೀಲಿಸಿ.
