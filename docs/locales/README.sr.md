## Шта све ради
### Открива све
- Комбинује мрежно снимање (HAR + захтеви уживо) са DOM скенирањем свих визуелних и структурних елемената, укључујући медијске датотеке, скрипте, стилове и уграђене оквире.
- **Разуме CSS:** ресурси унутар url(...) и @import правила прате се рекурзивно, па се проналазе чак и фонтови скривени у увезеним стиловима.
- **Препознавање садржаја:** непознате датотеке се читају у првих неколико бајтова и премештају у категорију свог стварног типа.
- **17 категорија са бројачем уживо:** ухваћени ресурси су уредно распоређени по посебним картицама за медије, код, податке, API позиве, колачиће, складиште и документе.

### Филтрирајте, претражујте, проверавајте
- Претрага помоћу регуларних израза по називима датотека, URL-овима, MIME типовима, алт тексту, па чак и по садржају датотека.
- **Филтери по категорији:** минимална/максимална величина, а за медије и минимална/максимална ширина и висина – на пример „само главне слике ≥ 1200px“. API позиви се филтрирају по HTTP методи и типу захтева.
- Приказ листе или мреже, са сортирањем и зидом сличица уживо.
- **Инспектор са више картица и правим прегледима:** лајтбокс са зумирањем, репродукција видеа и звука, узорак фонта уживо, SVG приказивач, истакнута синтакса кода са бројевима редова и прекидач Улепшај.
- **API подељени приказ:** одговор лево, метода, статус, параметри упита и тело захтева десно.

### Преузимајте како треба
- Преузми изабрано – само датотеке које сте означили.
- Преузми приказ – све што је видљиво након тренутних филтера и претраге.
- Преузми све – сваки ухваћени ресурс у ZIP са структуром фасцикли и аутоматским уклањањем дупликата.
- Групна преузимања раде са ограниченом истовременошћу и траком напретка уживо; неуспеси се аутоматски понављају, а могу и из контекстног менија.

### HLS и незгодни видео снимци
- Токови које прегледач не може изворно да пусти (HLS .m3u8, DASH .mpd, непознати кодеци) добијају паметну алтернативу уместо црног плејера.
- Споји сегменте и преузми претвара HLS ток у једну датотеку која се може пустити, директно у панелу.

### Текстуална радионица (скуп алата за садржај SPA-ова)
- **Картица Текст је приказивач садржаја уживо:** сваки елемент који садржи текст – наслови, пасуси, ставке листе, дугмад, div и span елементи – бележи се DOM редоследом.
- Динамичке табеле чувају ограничену историју снимака (нпр. „8 снимака · 124 јединствена реда“), па контролне табле које се аутоматски освежавају никада не губе међустања.
- Извоз као Markdown, а табела као CSV, HTML или права XLSX радна свеска са више листова, направљена нашим ручно писаним XLSX писцем.

## Како се користи
1. Инсталирајте Source Download, а затим притисните F12 на било којој страници.
2. Кликните на картицу Source Download у траци са алаткама DevTools-а (Chrome не дозвољава проширењима да аутоматски отварају DevTools – зато се налази ту).
3. Прегледајте картице категорија, претражујте, филтрирајте и проверавајте све у десном панелу.
4. Означите датотеке које желите и кликните на Преузми изабрано, Преузми приказ или Преузми све.
5. Држите DevTools панел отвореним док се страница учитава да бисте ухватили сваки мрежни захтев.

## Примери из праксе
- **Анализа конкуренције:** прикупите сличице видео снимака са било ког канала – уз филтер минималне ширине – у једну фасциклу.
- **Веб скрејпинг без кода:** пратите API позиве једног SPA-а, филтрирајте до крајње тачке која вам треба и преузмите њене тачне JSON одговоре.
- **Анализа типографије:** сазнајте који фонт сајт заиста користи и преузмите праве датотеке фонта.
- **Репродукција грешака:** сачувајте тачне верзије CSS/JS-а које су биле објављене када је грешка настала.
- **Извоз података са контролних табли:** извезите табелу која се аутоматски освежава у Excel радну свеску са више листова, уз историју.
- **QA тестирање:** проверите која се видео/аудио варијанта испоручује у свакој A/B конфигурацији.

## Приватност
- Ради 100% локално. Нема сервера, нема аналитике, ниједан податак не напушта ваш рачунар.
- **Тражи само оно што му треба:** складиште (ваша подешавања), клипборд (копирање URL-ова и боја), преузимања (чување датотека преко Chrome-а), контекстне меније, скриптовање и приступ сајтовима (за скенирање страница и преузимање садржаја датотека).
- Датотеке се чувају преко уобичајеног Chrome-овог тока преузимања – без тихих преузимања.

## Инсталација и брзи почетак

### Метод 1: Директна инсталација из Chrome Web Store-а (препоручено)
1. Посетите званичну [страницу Source Download у Chrome Web Store-у](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd).
2. Кликните на **Додај у Chrome** и одобрите дозволе.
3. Отворите Chrome DevTools (`F12` или `Ctrl+Shift+I` / `Cmd+Option+I` на macOS-у) и кликните на картицу **Source Download**, или кликните десним тастером миша било где на страници.

### Метод 2: Учитавање распакованог проширења из изворног кода (режим за програмере)
1. Клонирајте званични GitHub репозиторијум:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Отворите Google Chrome и идите на `chrome://extensions`.
3. Укључите прекидач **Режим за програмере** у горњем десном углу.
4. Кликните на **Учитај распаковано** и изаберите клонирану фасциклу пројекта `source-download`.
