Source Download — это панель Chrome DevTools, которая находит, изучает и скачивает каждый ресурс, загружаемый веб-страницей. Нужны медиафайлы, скрипты разработчика, файлы стилей или сетевые ответы — сохраняйте их по отдельности или в аккуратном ZIP-архиве со структурой папок.

Создан с нуля без сторонних зависимостей: ZIP-упаковщик, генератор XLSX, объединитель HLS и форматировщики кода написаны вручную на чистом JavaScript. Никаких фреймворков, этапа сборки и телеметрии. Всё работает локально в вашем браузере.

## Что нового в v1.16.0
- Полная многоязычная поддержка на 54 языках с локализацией DevTools и страницы в магазине.
- 17 отдельных категорий ресурсов с живыми счётчиками: медиа, код, API, хранилище и документы.
- Сшитые скриншоты всей страницы и скриншоты произвольной области с умным подавлением закреплённых шапок.
- Запись видео с экрана (MP4) и лёгкий движок экспорта анимированных GIF без артефактов по краям.
- Извлечение DOM-таблиц в реальном времени в многолистовой файл Microsoft Excel (.XLSX) и CSV, а также DOM Zapper для скрытия элементов.
- Пипетка цвета на экране с мгновенным копированием hex/rgb/hsl и встроенный форматировщик кода.
- Более стабильный перехват в DevTools и высокопараллельный сетевой конвейер.

## Зачем он нужен
Скриншота недостаточно. Забирайте настоящие файлы — изображения в полном разрешении, реальные видеопотоки, оригинальные стили и скрипты, а не плоскую картинку.

DevTools перегружен. Source Download показывает те же сетевые данные в понятной галерее по категориям — с поиском, фильтрами и скачиванием в один клик.

SPA скрывают всё. Динамические приложения создают ресурсы и API-запросы, которых нет в исходном коде страницы. Source Download перехватывает их по мере появления, включая промежуточные состояния.

## Что он умеет
### Находить всё
- Сочетает сетевой перехват (HAR и живые запросы) со сканированием DOM для всех визуальных и структурных элементов, включая медиафайлы, скрипты, стили и встроенные фреймы.
- **Понимает CSS:** ресурсы внутри url(...) и правил @import обрабатываются рекурсивно, поэтому находятся даже шрифты, спрятанные в импортированных стилях.
- **Определение по содержимому:** неизвестные файлы читаются на несколько байт и переносятся в категорию их фактического типа.
- **17 категорий с живыми счётчиками:** найденные ресурсы аккуратно разложены по отдельным вкладкам — медиа, код, данные, API-запросы, cookie, хранилище и документы.

### Фильтры, поиск, просмотр
- Поиск по регулярным выражениям по именам файлов, URL, MIME-типам, alt-тексту и даже содержимому файлов.
- **Фильтры по категориям:** минимальный/максимальный размер, а для медиа — ещё и ширина и высота, например «только крупные изображения ≥ 1200px». API-запросы фильтруются по HTTP-методу и типу запроса.
- Список или сетка, сортировка и живая стена миниатюр.
- **Многовкладочный инспектор с настоящим предпросмотром:** масштабируемый лайтбокс, воспроизведение видео и аудио, живой образец шрифта, просмотр SVG, код с подсветкой синтаксиса и номерами строк и переключатель Beautify.
- **Разделённый вид API:** ответ слева, метод, статус, параметры запроса и тело запроса справа.

### Скачивание как надо
- Скачать выбранные — только отмеченные файлы.
- Скачать видимые — всё, что осталось после текущих фильтров и поиска.
- Скачать все — каждый найденный ресурс в ZIP-архив со структурой папок и автоматическим удалением дубликатов.
- Пакетное скачивание идёт с ограниченной параллельностью и живым индикатором прогресса; сбои повторяются автоматически, а повторить можно и из контекстного меню.

### HLS и сложное видео
- Потоки, которые браузер не может воспроизвести сам (HLS .m3u8, DASH .mpd, неизвестные кодеки), получают умную замену вместо чёрного плеера.
- Кнопка «Объединить сегменты и скачать» превращает поток HLS в один воспроизводимый файл прямо в панели.

### Рабочее место Text (инструментарий для контента SPA)
- **Вкладка Text — это живой просмотрщик контента:** каждый элемент с текстом — заголовки, абзацы, пункты списков, кнопки, div, span — фиксируется в порядке DOM.
- Динамические таблицы хранят ограниченную историю снимков (например, «8 снимков · 124 уникальные строки»), поэтому автообновляемые дашборды не теряют промежуточные состояния.
- Экспорт в Markdown, а таблиц — в CSV, HTML или настоящую многолистовую книгу XLSX, созданную нашим собственным XLSX-генератором, написанным вручную.

## Как пользоваться
1. Установите Source Download и нажмите F12 на любой странице.
2. Откройте вкладку Source Download на панели инструментов DevTools (Chrome не позволяет расширениям открывать DevTools автоматически, поэтому панель находится там).
3. Переключайте вкладки категорий, ищите, фильтруйте и изучайте что угодно на правой панели.
4. Отметьте нужные файлы и нажмите «Скачать выбранные», «Скачать видимые» или «Скачать все».
5. Держите панель DevTools открытой во время загрузки страницы, чтобы перехватить каждый сетевой запрос.

## Реальные сценарии использования
- **Анализ конкурентов:** соберите превью видео с любого канала — с фильтром по минимальной ширине — в одну папку.
- **Веб-скрейпинг без кода:** следите за API-запросами SPA, отфильтруйте нужный эндпоинт и скачайте его точные JSON-ответы.
- **Разбор типографики:** узнайте, какой шрифт сайт использует на самом деле, и заберите реальные файлы шрифтов.
- **Воспроизведение багов:** сохраните точные версии CSS/JS, которые работали в момент появления ошибки.
- **Экспорт данных дашборда:** выгрузите автообновляемую таблицу в многолистовую книгу Excel вместе с историей.
- **QA-тестирование:** проверьте, какой вариант видео/аудио отдаётся в каждой A/B-конфигурации.

## Конфиденциальность
- Работает на 100% локально. Нет сервера, нет аналитики, никакие данные не покидают ваш компьютер.
- **Запрашивает только необходимое:** хранилище (ваши настройки), буфер обмена (копирование URL и цветов), загрузки (сохранение файлов через Chrome), контекстные меню, скрипты и доступ к сайтам (для сканирования страниц и получения содержимого файлов).
- Файлы сохраняются через обычный механизм загрузки Chrome — никаких скрытых скачиваний.

## Установка и быстрый старт

### Способ 1: прямая установка из Chrome Web Store (рекомендуется)
1. Откройте официальную [страницу Source Download в Chrome Web Store](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd).
2. Нажмите **Установить** (Add to Chrome) и предоставьте разрешения.
3. Откройте Chrome DevTools (`F12` или `Ctrl+Shift+I` / `Cmd+Option+I` на macOS) и перейдите на вкладку **Source Download** либо щёлкните правой кнопкой мыши в любом месте страницы.

### Способ 2: загрузка распакованного расширения из исходников (режим разработчика)
1. Клонируйте официальный репозиторий GitHub:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Откройте Google Chrome и перейдите по адресу `chrome://extensions`.
3. Включите переключатель **Режим разработчика** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** и выберите клонированную папку проекта `source-download`.
