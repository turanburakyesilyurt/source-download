- ஒழுங்கான காட்சியகம்: ஒளிப்படங்கள், ஐகான்கள், எழுத்துருக்கள் நேரடி எண்ணிக்கை மற்றும் தேடல் பெட்டியுடன் தனித் தனிக் கீற்றுகளில் தோன்றும்.
- துல்லியமான வடிகட்டிகள்: குறிப்பிட்ட குறைந்தபட்ச அகலத்தை (எ.கா. 1200 px) விட அகலமானவற்றை மட்டும் காட்டலாம் அல்லது நகல்களை மறைக்கலாம்.
- உண்மையான முன்னோட்டம்: வரைகலையைப் பெரிதாக்கி ஊடகத்தை இயக்கலாம். எழுத்துரு மாதிரியையும் தொடரியல் வண்ணமிட்ட குறியீட்டையும் பார்க்கலாம்.
- ஒரே காப்பகம்: வேண்டியவற்றைக் குறித்து நேர்த்தியான கோப்புறை அமைப்புள்ள ஒரே ZIP-ஐப் பெறுங்கள். தோல்வியடைந்தவற்றை ஒரே கிளிக்கில் மீண்டும் முயலலாம்.
- முழுப் பக்கப் படம்: அனைத்தும் உருட்டப்பட்டு PNG, JPG அல்லது PDF ஆக இணைக்கப்படும். ஒரு பகுதியை மட்டும் தேர்ந்தெடுக்கவும் முடியும்.
- பகுதிப் பதிவு: தெரியும் ஒரு பகுதியை GIF, MP4 அல்லது WebM கிளிப்பாக மாற்றுங்கள்.
- அட்டவணையிலிருந்து விரிதாளுக்கு: நேரடி அட்டவணைகளை Excel அல்லது CSV-க்கு ஏற்றுமதி செய்யுங்கள், புதுப்பிக்கப்படும் அட்டவணைகளின் முந்தைய நிலைகளுடன்.
- ஆஃப்லைன் நகல்: இணையம் இல்லாமல் திறக்கும் ஒரே HTML ஆவணமாகத் தளத்தை வைத்திருங்கள்.
- வண்ணத் தேர்வி: தெரியும் எந்த வண்ணத்தையும் எடுத்து HEX, RGB அல்லது HSL ஆக நகலெடுங்கள்.

## தொடங்குவது எப்படி
1. நீங்கள் வேலை செய்ய விரும்பும் தளத்தைத் திறக்கவும்.
2. F12 அழுத்தவும் (Mac-இல் Option + Command + I), Source Download கீற்றைத் தேர்ந்தெடுக்கவும். தெரியவில்லை என்றால் கீற்றுப் பட்டையின் முடிவிலுள்ள » ஐக் கிளிக் செய்யவும்.
3. ஏற்றும்போது பலகத்தைத் திறந்தே வைத்திருங்கள், எதுவும் விடுபடாது.

திரைப்பிடிப்பு, பதிவு, வண்ணத் தேர்வி ஆகியவை வலது கிளிக் மெனுவிலும் நீட்டிப்புப் பொத்தானிலும் கிடைக்கும்.

## தனியுரிமை

அனைத்தும் உங்கள் கணினியிலேயே இயங்கும். கணக்கும் பகுப்பாய்வும் இல்லை, நீங்கள் சேமிப்பது எதுவும் உருவாக்குநருக்கு அனுப்பப்படாது. சேமித்தவை Chrome வழியாக வழக்கமான பதிவிறக்கக் கோப்புறைக்குச் செல்லும்.

வளங்களைக் கண்டறிந்து தன் பணிகளைச் செய்ய, நீங்கள் பார்வையிடும் தளங்களை அணுகும் அனுமதி நீட்டிப்புக்குத் தேவை.

பதிப்புரிமையையும் பயன்பாட்டு விதிமுறைகளையும் மதித்து, பயன்படுத்த அனுமதியுள்ள உள்ளடக்கத்தை மட்டும் வைத்துக்கொள்ளுங்கள்.

## பதிப்பு 1.17-இல் புதியவை

- ஆஃப்லைன் நகல்களில் இப்போது அனைத்து ஒளிப்படங்களும் பின்னணிகளும் எழுத்துருக்களும் உள்ளன.
- நீண்ட HD கிளிப்புகளிலும் GIF பதிவு நினைவக வரம்புக்குள் இருக்கும்.

## நிறுவல் மற்றும் விரைவுத் தொடக்கம்

### முறை 1: Chrome Web Store இலிருந்து நேரடியாக நிறுவுதல் (பரிந்துரைக்கப்படுகிறது)
1. அதிகாரப்பூர்வ [Source Download Chrome Web Store பக்கத்தைப்](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd) பாருங்கள்.
2. **Chrome இல் சேர்** என்பதைக் கிளிக் செய்து அனுமதிகளை வழங்குங்கள்.
3. Chrome DevTools ஐத் திறந்து (`F12` அல்லது `Ctrl+Shift+I` / macOS இல் `Cmd+Option+I`) **Source Download** தாவலைக் கிளிக் செய்யுங்கள், அல்லது பக்கத்தில் எங்கு வேண்டுமானாலும் வலது-கிளிக் செய்யுங்கள்.

### முறை 2: மூலத்திலிருந்து அன்பேக் செய்த நீட்டிப்பை ஏற்றுதல் (டெவலப்பர் பயன்முறை)
1. அதிகாரப்பூர்வ GitHub களஞ்சியத்தை குளோன் செய்யுங்கள்:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome ஐத் திறந்து `chrome://extensions` க்குச் செல்லுங்கள்.
3. மேல் வலது மூலையில் உள்ள **டெவலப்பர் பயன்முறை** சுவிட்சை இயக்குங்கள்.
4. **அன்பேக் செய்ததை ஏற்று** என்பதைக் கிளிக் செய்து, குளோன் செய்த `source-download` திட்டக் கோப்புறையைத் தேர்ந்தெடுங்கள்.
