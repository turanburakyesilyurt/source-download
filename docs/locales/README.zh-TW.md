> **坦白與開放原始碼承諾:** 商店裡幾乎所有「下載此頁面資源」的工具，都只是一堆第三方函式庫的包裝。這一款不同。Source Download 的每一個位元組——包括 **ZIP 寫入器**、**XLSX 產生器**、**HLS 合併器**、**GIF 編碼器**和**程式碼格式化工具**——都是從零手寫的。沒有框架，沒有外部相依套件，沒有建置步驟，沒有遙測。只有原生 JavaScript，一次坐下來就能讀完並稽核。

Source Download 是一套用來收集網頁內容的工具。它在 Chrome 開發人員工具中新增一個分頁，把網站載入的所有內容依類別整理，方便您預覽並只保留需要的部分。

## 主要功能
- 井然有序的圖庫：相片、圖示和字型分別顯示在各自的分頁中，附有即時數量與搜尋框。
- 精確篩選：只顯示超過最小寬度（例如 1200 px）的項目，或隱藏重複項目。
- 真實預覽：放大圖形並播放媒體，也能查看字型樣本或語法醒目提示的程式碼。
- 一個壓縮檔：勾選想要的內容，就能取得一個資料夾結構整齊的 ZIP。失敗的項目可一鍵重試。
- 整頁截圖：從上到下捲動並拼接成 PNG、JPG 或 PDF。也可以只選取一個區域。
- 區域錄製：把螢幕的一部分錄成 GIF、MP4 或 WebM 片段。
- 表格轉試算表：將即時表格匯出為 Excel 或 CSV，並包含持續更新之表格的先前狀態。
- 離線副本：把網站保存為一個不需連網即可開啟的 HTML 文件。
- 取色器：選取螢幕上的任何顏色，並複製為 HEX、RGB 或 HSL。

## 如何開始
1. 開啟您要處理的網站。
2. 按 F12（Mac 上按 Option + Command + I），選擇 Source Download 分頁。如果沒看到，請按一下分頁列末端的 »。
3. 載入期間保持面板開啟，就不會遺漏任何內容。

截圖、錄製和取色器也能從右鍵選單與擴充功能按鈕使用。

## 隱私權

一切都在您的電腦上執行。不需帳號，也沒有統計分析，您收集的內容不會傳送給開發人員。儲存的內容會透過 Chrome 放進您平常的「下載」資料夾。

擴充功能需要存取您瀏覽的網站，才能找到其中的資源並提供各項功能。

請尊重著作權與使用條款，只保留您有權使用的內容。

## 安裝與快速入門

### 方法一：從 Chrome Web Store 直接安裝（建議）
1. 前往官方 [Source Download Chrome Web Store 頁面](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd)。
2. 按一下**加到 Chrome**並授予權限。
3. 開啟 Chrome DevTools（`F12` 或 `Ctrl+Shift+I` / macOS 上為 `Cmd+Option+I`），按一下 **Source Download** 分頁，或在頁面任意位置按右鍵。

### 方法二：從原始碼載入未封裝的擴充功能（開發人員模式）
1. 複製（clone）官方 GitHub 儲存庫：
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. 開啟 Google Chrome，前往 `chrome://extensions`。
3. 開啟右上角的**開發人員模式**切換開關。
4. 按一下**載入未封裝項目**，選取複製下來的 `source-download` 專案資料夾。
