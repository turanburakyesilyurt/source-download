## तुम्हाला याची गरज का आहे
स्क्रीनशॉट पुरेसा नाही. खऱ्या फाइल्स मिळवा: पूर्ण-रिझोल्यूशन इमेज, प्रत्यक्ष व्हिडिओ स्ट्रीम, मूळ स्टाइलशीट्स आणि स्क्रिप्ट्स — सपाट केलेले चित्र नव्हे.

DevTools अवघड वाटते. Source Download त्याच नेटवर्क डेटासमोर शोध, फिल्टर आणि एका क्लिकवर डाउनलोडसह स्वच्छ, वर्गीकृत गॅलरी ठेवते.

SPA सर्वकाही लपवतात. डायनॅमिक ॲप्स असे ॲसेट्स आणि API कॉल तयार करतात जे तुम्हाला पृष्ठ स्रोतात कधीच दिसत नाहीत. Source Download ते घडत असतानाच कॅप्चर करते, मधल्या अवस्थांसह.

## ते काय करते
### सर्वकाही शोधा
- मीडिया फाइल्स, स्क्रिप्ट्स, स्टाइलशीट्स आणि एम्बेड केलेल्या फ्रेम्ससह सर्व दृश्य आणि संरचनात्मक घटकांसाठी नेटवर्क कॅप्चर (HAR + थेट विनंत्या) आणि DOM स्कॅन एकत्र करते.
- **CSS-जागरूक:** url(...) आणि @import नियमांमधील ॲसेट्सचा पुनरावर्ती पाठपुरावा केला जातो, त्यामुळे इम्पोर्ट केलेल्या स्टाइलशीट्समध्ये दडलेले फॉन्टदेखील सापडतात.
- **कंटेंट स्निफिंग:** अज्ञात फाइल्सचे काही बाइट्स परत वाचले जातात आणि त्यांना त्यांच्या खऱ्या फाइल प्रकार श्रेणीत नेले जाते.
- **17 थेट-मोजणी श्रेणी:** कॅप्चर केलेले ॲसेट्स मीडिया, कोड, डेटा, API कॉल, कुकीज, स्टोरेज आणि दस्तऐवजांसाठी समर्पित टॅबमध्ये नीटनेटके आयोजित केले जातात.

### फिल्टर करा, शोधा, तपासा
- फाइलनावे, URL, MIME प्रकार, alt मजकूर आणि फाइलच्या मजकुरातदेखील regex-आधारित शोध.
- **प्रति श्रेणी फिल्टर:** किमान/कमाल आकार, आणि मीडियासाठी किमान/कमाल रुंदी व उंचीदेखील — उदाहरणार्थ "फक्त ≥ 1200px हीरो इमेज". API कॉल HTTP पद्धत आणि विनंती प्रकारानुसार फिल्टर होतात.
- सूची किंवा ग्रिड दृश्य, क्रमवारी लावता येणारे, थेट थंबनेल भिंतीसह.
- **खऱ्या पूर्वावलोकनांसह बहु-टॅब इन्स्पेक्टर:** झूम करता येणारा लाइटबॉक्स, व्हिडिओ आणि ऑडिओ प्लेबॅक, थेट फॉन्ट नमुना, SVG व्ह्यूअर, सिंटॅक्स-हायलाइट केलेला कोड ओळ क्रमांकांसह आणि सुशोभित करा टॉगल.
- **API स्प्लिट व्ह्यू:** डावीकडे प्रतिसाद, उजवीकडे पद्धत, स्टेटस, क्वेरी पॅरामीटर्स आणि विनंती बॉडी.

### योग्य प्रकारे डाउनलोड करा
- डाउनलोड निवडले — फक्त तुम्ही निवडलेल्या फाइल्स.
- पहा डाउनलोड करा — सध्याच्या फिल्टर आणि शोधानंतर दिसणारे सर्वकाही.
- सर्व डाउनलोड करा — कॅप्चर केलेले प्रत्येक संसाधन स्वयंचलित डी-डुप्लिकेशनसह फोल्डर-रचना असलेल्या ZIP मध्ये.
- बॅच डाउनलोड मर्यादित समवर्तितेसह आणि थेट प्रगती पट्टीसह चालतात; अयशस्वी डाउनलोड स्वयंचलितपणे आणि संदर्भ मेनूमधूनही पुन्हा प्रयत्न केले जातात.

### HLS आणि अवघड व्हिडिओ
- ब्राउझर मूळतः प्ले करू शकत नाही अशा स्ट्रीम (HLS .m3u8, DASH .mpd, अज्ञात कोडेक) काळ्या प्लेयरऐवजी स्मार्ट पर्याय दाखवतात.
- विभाग विलीन करा आणि डाउनलोड करा हे HLS स्ट्रीमचे थेट पॅनेलमध्येच एका प्ले करता येणाऱ्या फाइलमध्ये रूपांतर करते.

### मजकूर वर्कबेंच (SPA कंटेंट टूलकिट)
- **मजकूर टॅब हा थेट कंटेंट व्ह्यूअर आहे:** मजकूर असलेला प्रत्येक घटक — शीर्षके, परिच्छेद, सूची आयटम, बटणे, div, span — DOM क्रमाने कॅप्चर केला जातो.
- डायनॅमिक टेबल मर्यादित स्नॅपशॉट इतिहास ठेवतात (उदा. "8 स्नॅपशॉट · 124 अद्वितीय ओळी"), त्यामुळे आपोआप रिफ्रेश होणारे डॅशबोर्ड मधल्या अवस्था कधीच गमावत नाहीत.
- Markdown म्हणून एक्सपोर्ट करा, किंवा टेबल CSV, HTML किंवा आमच्या स्वतःच्या हाताने लिहिलेल्या XLSX रायटरने बनवलेल्या खऱ्या बहु-शीट XLSX वर्कबुक म्हणून.

4. हव्या असलेल्या फाइल्स निवडा आणि डाउनलोड निवडले, पहा डाउनलोड करा किंवा सर्व डाउनलोड करा दाबा.
5. प्रत्येक नेटवर्क विनंती कॅप्चर करण्यासाठी पृष्ठ लोड होत असताना DevTools पॅनेल उघडे ठेवा.
