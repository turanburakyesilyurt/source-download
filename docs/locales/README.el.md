Το Source Download είναι ένα πάνελ του Chrome DevTools που εντοπίζει, επιθεωρεί και κατεβάζει κάθε πόρο που φορτώνει μια ιστοσελίδα. Είτε χρειάζεστε αρχεία πολυμέσων, σενάρια ανάπτυξης, στοιχεία στυλ ή αποκρίσεις δικτύου, μπορείτε να τα αποθηκεύσετε ως μεμονωμένα αρχεία ή ως ένα τακτοποιημένο ZIP με δομή φακέλων.

Φτιαγμένο από το μηδέν, χωρίς εξαρτήσεις τρίτων: η μονάδα εγγραφής ZIP, ο δημιουργός XLSX, ο συγχωνευτής HLS και οι μορφοποιητές κώδικα είναι όλα χειρόγραφη vanilla JavaScript. Χωρίς frameworks, χωρίς βήμα μεταγλώττισης, χωρίς τηλεμετρία. Όλα εκτελούνται τοπικά στο πρόγραμμα περιήγησής σας.

## Τι νέο υπάρχει στην v1.16.0
- Πλήρης πολύγλωσση υποστήριξη σε 54 γλώσσες, με πλήρη μετάφραση του DevTools και της σελίδας του καταστήματος.
- 17 αποκλειστικές κατηγορίες πόρων με ζωντανή καταμέτρηση, που καλύπτουν όλα τα πολυμέσα, τον κώδικα, τα API, την αποθήκευση και τα έγγραφα.
- Στιγμιότυπα οθόνης ολόκληρης της σελίδας με συρραφή και λήψη προσαρμοσμένης περιοχής, με έξυπνη καταστολή των σταθερών κεφαλίδων.
- Εγγραφή βίντεο οθόνης (MP4) και ελαφριά μηχανή εξαγωγής κινούμενων GIF χωρίς περιθώρια στις άκρες.
- Ζωντανή εξαγωγή πινάκων DOM σε Microsoft Excel (.XLSX) πολλών φύλλων και σε CSV, με το εργαλείο αφαίρεσης στοιχείων DOM Zapper.
- Σταγονόμετρο χρώματος στην οθόνη με άμεση αντιγραφή hex/rgb/hsl και ενσωματωμένο εργαλείο ομορφοποίησης κώδικα.
- Βελτιωμένη σταθερότητα του sniffer στο DevTools και δικτυακή διοχέτευση υψηλής ταυτόχρονης επεξεργασίας.

## Γιατί το χρειάζεστε
Το στιγμιότυπο οθόνης δεν αρκεί. Πάρτε τα πραγματικά αρχεία — εικόνες πλήρους ανάλυσης, αυθεντικές ροές βίντεο, πρωτότυπα φύλλα στυλ και σενάρια — όχι μια επίπεδη εικόνα.

Το DevTools μπορεί να είναι συντριπτικό. Το Source Download σάς δίνει μια καθαρή γκαλερί με κατηγορίες πάνω στα ίδια δεδομένα δικτύου, με αναζήτηση, φίλτρα και λήψη με ένα κλικ.

Οι SPA κρύβουν τα πάντα. Οι δυναμικές εφαρμογές δημιουργούν πόρους και κλήσεις API που δεν βλέπετε ποτέ στον πηγαίο κώδικα της σελίδας. Το Source Download τα καταγράφει καθώς συμβαίνουν, μαζί με τις ενδιάμεσες καταστάσεις.

## Τι κάνει
### Εντοπίστε τα πάντα
- Συνδυάζει καταγραφή δικτύου (HAR + ζωντανά αιτήματα) με σάρωση του DOM για όλα τα οπτικά και δομικά στοιχεία, συμπεριλαμβανομένων αρχείων πολυμέσων, σεναρίων, φύλλων στυλ και ενσωματωμένων πλαισίων.
- **Με επίγνωση του CSS:** οι πόροι μέσα σε url(...) και σε κανόνες @import ακολουθούνται αναδρομικά, ώστε να βρίσκονται ακόμη και οι γραμματοσειρές που κρύβονται σε εισαγόμενα φύλλα στυλ.
- **Ανίχνευση περιεχομένου:** τα άγνωστα αρχεία διαβάζονται για λίγα byte και μεταφέρονται στην κατηγορία του πραγματικού τύπου τους.
- **17 κατηγορίες με ζωντανή καταμέτρηση:** οι πόροι που καταγράφονται οργανώνονται σε αποκλειστικές καρτέλες για πολυμέσα, κώδικα, δεδομένα, κλήσεις API, cookies, αποθήκευση και έγγραφα.

### Φιλτράρετε, αναζητήστε, επιθεωρήστε
- Αναζήτηση με κανονικές εκφράσεις σε ονόματα αρχείων, URL, τύπους MIME, εναλλακτικό κείμενο, ακόμη και στο περιεχόμενο των αρχείων.
- **Φίλτρα ανά κατηγορία:** ελάχιστο/μέγιστο μέγεθος και, για τα πολυμέσα, ελάχιστο/μέγιστο πλάτος και ύψος — για παράδειγμα «μόνο κύριες εικόνες ≥ 1200px». Οι κλήσεις API φιλτράρονται ανά μέθοδο HTTP και τύπο αιτήματος.
- Προβολή λίστας ή πλέγματος, με δυνατότητα ταξινόμησης και ζωντανό τοίχο μικρογραφιών.
- **Επιθεωρητής με πολλαπλές καρτέλες και πραγματικές προεπισκοπήσεις:** lightbox με ζουμ, αναπαραγωγή βίντεο και ήχου, ζωντανό δείγμα γραμματοσειράς, πρόγραμμα προβολής SVG, κώδικας με επισήμανση σύνταξης και αρίθμηση γραμμών, και διακόπτης Ομορφοποίησης.
- **Διαχωρισμένη προβολή API:** η απόκριση στα αριστερά, η μέθοδος, η κατάσταση, οι παράμετροι ερωτήματος και το σώμα του αιτήματος στα δεξιά.

### Λήψη όπως πρέπει
- Λήψη επιλεγμένων — μόνο τα αρχεία που έχετε επιλέξει.
- Λήψη προβολής — ό,τι φαίνεται μετά τα τρέχοντα φίλτρα και την αναζήτηση.
- Λήψη όλων — κάθε πόρος που καταγράφηκε, σε ένα ZIP με δομή φακέλων και αυτόματη αφαίρεση διπλοτύπων.
- Οι μαζικές λήψεις εκτελούνται με περιορισμένη ταυτόχρονη επεξεργασία και ζωντανή γραμμή προόδου· οι αποτυχίες επαναλαμβάνονται αυτόματα και μέσα από το μενού περιβάλλοντος.

### HLS και δύσκολα βίντεο
- Οι ροές που το πρόγραμμα περιήγησης δεν μπορεί να αναπαραγάγει εγγενώς (HLS .m3u8, DASH .mpd, άγνωστοι κωδικοποιητές) εμφανίζουν μια έξυπνη εναλλακτική αντί για μαύρο πρόγραμμα αναπαραγωγής.
- Η επιλογή «Συγχώνευση τμημάτων και λήψη» μετατρέπει μια ροή HLS σε ένα ενιαίο αρχείο που αναπαράγεται, απευθείας μέσα στο πάνελ.

### Ο πάγκος εργασίας κειμένου (εργαλειοθήκη περιεχομένου για SPA)
- **Η καρτέλα Κείμενο είναι ένα ζωντανό πρόγραμμα προβολής περιεχομένου:** κάθε στοιχείο που περιέχει κείμενο — επικεφαλίδες, παράγραφοι, στοιχεία λίστας, κουμπιά, div, span — καταγράφεται με τη σειρά του DOM.
- Οι δυναμικοί πίνακες διατηρούν περιορισμένο ιστορικό στιγμιοτύπων (π.χ. «8 στιγμιότυπα · 124 μοναδικές γραμμές»), ώστε τα πάνελ που ανανεώνονται αυτόματα να μη χάνουν ποτέ ενδιάμεσες καταστάσεις.
- Εξαγωγή ως Markdown ή, για τους πίνακες, ως CSV, HTML ή πραγματικό βιβλίο XLSX πολλών φύλλων, φτιαγμένο από τη δική μας χειρόγραφη μονάδα εγγραφής XLSX.

## Πώς να το χρησιμοποιήσετε
1. Εγκαταστήστε το Source Download και πατήστε F12 σε οποιαδήποτε σελίδα.
2. Κάντε κλικ στην καρτέλα Source Download στη γραμμή εργαλείων του DevTools (το Chrome δεν επιτρέπει στις επεκτάσεις να ανοίγουν αυτόματα το DevTools — γι' αυτό βρίσκεται εκεί).
3. Περιηγηθείτε στις καρτέλες κατηγοριών, κάντε αναζήτηση, φιλτράρετε, επιθεωρήστε οτιδήποτε στο δεξί πάνελ.
4. Επιλέξτε τα αρχεία που θέλετε και πατήστε Λήψη επιλεγμένων, Λήψη προβολής ή Λήψη όλων.
5. Κρατήστε ανοιχτό το πάνελ του DevTools ενώ φορτώνει η σελίδα, για να καταγραφούν όλα τα αιτήματα δικτύου.

## Πραγματικές περιπτώσεις χρήσης
- **Ανάλυση ανταγωνισμού:** συγκεντρώστε σε έναν φάκελο τις μικρογραφίες βίντεο από οποιοδήποτε κανάλι, με φίλτρο ελάχιστου πλάτους.
- **Web scraping χωρίς κώδικα:** παρακολουθήστε τις κλήσεις API μιας SPA, φιλτράρετε μέχρι το endpoint που χρειάζεστε και κατεβάστε τις ακριβείς αποκρίσεις JSON.
- **Ανατομία τυπογραφίας:** ανακαλύψτε ποια γραμματοσειρά χρησιμοποιεί πραγματικά ένας ιστότοπος και πάρτε τα πραγματικά αρχεία της.
- **Αναπαραγωγή σφαλμάτων:** κρατήστε τις ακριβείς εκδόσεις CSS/JS που ήταν σε λειτουργία όταν εμφανίστηκε το σφάλμα.
- **Εξαγωγή δεδομένων πίνακα ελέγχου:** εξαγάγετε έναν πίνακα που ανανεώνεται αυτόματα σε βιβλίο Microsoft Excel πολλών φύλλων, μαζί με το ιστορικό.
- **Δοκιμές QA:** επαληθεύστε ποια παραλλαγή βίντεο/ήχου εξυπηρετείται σε κάθε ρύθμιση A/B.

## Απόρρητο
- Λειτουργεί 100% τοπικά. Χωρίς διακομιστή, χωρίς analytics, κανένα δεδομένο δεν φεύγει από τη συσκευή σας.

```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Ανοίξτε το Google Chrome και μεταβείτε στο `chrome://extensions`.
3. Ενεργοποιήστε τον διακόπτη **Λειτουργία προγραμματιστή** στην επάνω δεξιά γωνία.
4. Κάντε κλικ στο **Φόρτωση αποσυσκευασμένης** και επιλέξτε τον κλωνοποιημένο φάκελο του έργου `source-download`.
