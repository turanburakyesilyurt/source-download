Source Download је скуп алатки за чување веб-садржаја. У Chrome алатке за програмере додаје засебну картицу. Тамо је све што је сајт учитао разврстано по категоријама да бисте то прегледали и задржали само потребно.

## Главне функције
- Уредна галерија: фотографије, иконе и фонтови приказују се на сопственим картицама са бројачима уживо и пољем за претрагу.
- Прецизни филтери: прикажите само ставке шире од задатог минимума (нпр. 1200 px) или сакријте дупликате.
- Прави преглед: увеличајте графику и пустите медије. Можете видети и узорак фонта или кôд са истицањем синтаксе.
- Једна архива: означите шта желите и добијте један ZIP са уредном структуром фасцикли. Неуспеле ставке понављате једним кликом.
- Снимак целе странице: све се помера и спаја у PNG, JPG или PDF. Можете изабрати и само једну област.
- Снимање области: претворите део екрана у клип GIF, MP4 или WebM.
- Из табеле у табеларни прорачун: извезите живе табеле у Excel или CSV заједно са ранијим стањима табела које се освежавају.
- Офлајн копија: сачувајте сајт као један HTML документ који се отвара без интернета.
- Бирач боја: изаберите било коју боју на екрану и копирајте је као HEX, RGB или HSL.

## Како почети
1. Отворите сајт са којим желите да радите.
2. Притисните F12 (на Mac-у Option + Command + I) и изаберите картицу Source Download. Ако је не видите, кликните » на крају траке картица.
3. Држите панел отвореним током учитавања да ништа не промакне.

Снимци екрана, снимање и бирач боја доступни су и у менију десног клика и на дугмету проширења.

## Инсталација и брзи почетак

### Метод 1: Директна инсталација из Chrome Web Store-а (препоручено)
1. Посетите званичну [страницу Source Download у Chrome Web Store-у](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd).
2. Кликните на **Додај у Chrome** и одобрите дозволе.
3. Отворите Chrome DevTools (`F12` или `Ctrl+Shift+I` / `Cmd+Option+I` на macOS-у) и кликните на картицу **Source Download**, или кликните десним тастером миша било где на страници.

### Метод 2: Учитавање распакованог проширења из изворног кода (режим за програмере)
1. Клонирајте званични GitHub репозиторијум:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Отворите Google Chrome и идите на `chrome://extensions`.
3. Укључите прекидач **Режим за програмере** у горњем десном углу.
4. Кликните на **Учитај распаковано** и изаберите клонирану фасциклу пројекта `source-download`.
