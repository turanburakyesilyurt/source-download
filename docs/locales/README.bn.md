Source Download একটি Chrome DevTools প্যানেল, যা ওয়েব পেজ লোড করা প্রতিটি রিসোর্স খুঁজে বের করে, পরীক্ষা করে এবং ডাউনলোড করে। মিডিয়া ফাইল, ডেভেলপার স্ক্রিপ্ট, স্টাইল অ্যাসেট বা নেটওয়ার্ক রেসপন্স—যা-ই দরকার হোক, আপনি সেগুলো আলাদা ফাইল হিসেবে বা ফোল্ডার কাঠামোসহ গোছানো ZIP হিসেবে সংরক্ষণ করতে পারবেন।

কোনো থার্ড-পার্টি নির্ভরতা ছাড়াই শুরু থেকে তৈরি: ZIP রাইটার, XLSX বিল্ডার, HLS মার্জার এবং কোড ফরম্যাটার—সবই হাতে লেখা ভ্যানিলা JavaScript। কোনো ফ্রেমওয়ার্ক নেই, বিল্ড স্টেপ নেই, টেলিমেট্রি নেই। সবকিছু আপনার ব্রাউজারেই লোকালি চলে।

## v1.16.0-এ নতুন যা আছে
- 54টি ভাষায় পূর্ণ বহুভাষিক সমর্থন, সঙ্গে DevTools ও স্টোরের সম্পূর্ণ লোকালাইজেশন।
- লাইভ কাউন্টসহ 17টি নির্দিষ্ট অ্যাসেট ক্যাটাগরি, যা সব মিডিয়া, কোড, API, স্টোরেজ ও ডকুমেন্ট কভার করে।
- স্মার্ট স্টিকি হেডার দমনসহ পুরো পেজের স্টিচ করা স্ক্রিনশট এবং কাস্টম এলাকা ক্যাপচার।
- স্ক্রিন ভিডিও রেকর্ডিং (MP4) এবং কোনো বাড়তি প্রান্ত ছাড়া হালকা অ্যানিমেটেড GIF এক্সপোর্ট ইঞ্জিন।
- লাইভ DOM টেবিল এক্সট্র্যাক্টর, যা মাল্টি-শিট Microsoft Excel (.XLSX) ও CSV-তে এক্সপোর্ট করে, সঙ্গে এলিমেন্ট সরানোর DOM Zapper।
- তাৎক্ষণিক hex/rgb/hsl কপিসহ স্ক্রিন কালার আইড্রপার টুল এবং ইন্টিগ্রেটেড কোড বিউটিফায়ার।
- DevTools স্নিফারের উন্নত স্থিতিশীলতা এবং উচ্চ-কনকারেন্সি নেটওয়ার্ক পাইপলাইন।

## কেন এটি আপনার দরকার
স্ক্রিনশট যথেষ্ট নয়। আসল ফাইলগুলো নিন—পূর্ণ রেজোলিউশনের ছবি, আসল ভিডিও স্ট্রিম, মূল স্টাইলশিট ও স্ক্রিপ্ট—একটি চ্যাপ্টা ছবি নয়।

DevTools অনেক সময় জটিল লাগে। Source Download একই নেটওয়ার্ক ডেটা আপনার সামনে সাজানো, ক্যাটাগরিভিত্তিক গ্যালারিতে দেখায়—সঙ্গে সার্চ, ফিল্টার এবং এক ক্লিকে ডাউনলোড।

SPA সবকিছু লুকিয়ে রাখে। ডায়নামিক অ্যাপ এমন অ্যাসেট ও API কল তৈরি করে, যা পেজ সোর্সে কখনো দেখা যায় না। Source Download সেগুলো ঘটার মুহূর্তেই ধরে ফেলে, মধ্যবর্তী অবস্থাসহ।

## এটি কী করে
### সবকিছু খুঁজে বের করুন
- নেটওয়ার্ক ক্যাপচার (HAR + লাইভ রিকোয়েস্ট) এবং সব দৃশ্যমান ও কাঠামোগত এলিমেন্টের DOM স্ক্যান একসঙ্গে করে—এর মধ্যে আছে মিডিয়া ফাইল, স্ক্রিপ্ট, স্টাইলশিট ও এমবেড করা ফ্রেম।
- **CSS-সচেতন:** url(...) ও @import রুলের ভেতরের অ্যাসেট পুনরাবৃত্তভাবে অনুসরণ করা হয়, ফলে ইমপোর্ট করা স্টাইলশিটে লুকানো ফন্টও পাওয়া যায়।
- **কনটেন্ট স্নিফিং:** অজানা ফাইলের কয়েক বাইট পড়ে সেগুলোকে তাদের প্রকৃত ফাইল টাইপের ক্যাটাগরিতে উন্নীত করা হয়।
- **17টি লাইভ-কাউন্ট ক্যাটাগরি:** ক্যাপচার করা অ্যাসেট মিডিয়া, কোড, ডেটা, API কল, কুকি, স্টোরেজ ও ডকুমেন্টের জন্য আলাদা ট্যাবে সুন্দরভাবে সাজানো থাকে।

### ফিল্টার, সার্চ, পরীক্ষা
- ফাইলের নাম, URL, MIME টাইপ, alt টেক্সট এমনকি ফাইলের ভেতরের কনটেন্ট জুড়ে Regex-চালিত সার্চ।
- **প্রতিটি ক্যাটাগরির জন্য ফিল্টার:** সর্বনিম্ন/সর্বোচ্চ সাইজ, আর মিডিয়ার ক্ষেত্রে সর্বনিম্ন/সর্বোচ্চ প্রস্থ ও উচ্চতাও—যেমন «শুধু ≥ 1200px হিরো ইমেজ»। API কল HTTP মেথড ও রিকোয়েস্টের ধরন অনুযায়ী ফিল্টার করা যায়।
- লিস্ট বা গ্রিড ভিউ, সাজানোর সুবিধাসহ এবং লাইভ থাম্বনেইল ওয়াল।
- **আসল প্রিভিউসহ মাল্টি-ট্যাব ইন্সপেক্টর:** জুম করা যায় এমন লাইটবক্স, ভিডিও ও অডিও প্লেব্যাক, লাইভ ফন্ট স্পেসিমেন, SVG ভিউয়ার, সিনট্যাক্স হাইলাইট ও লাইন নম্বরসহ কোড এবং Beautify টগল।
- **API স্প্লিট ভিউ:** বামে রেসপন্স, ডানে মেথড, স্ট্যাটাস, কোয়েরি প্যারামিটার ও রিকোয়েস্ট বডি।

### সঠিকভাবে ডাউনলোড করুন
- ডাউনলোড নির্বাচিত — শুধু আপনার টিক দেওয়া ফাইলগুলো।
- ভিউ ডাউনলোড — বর্তমান ফিল্টার ও সার্চের পর যা কিছু দেখা যাচ্ছে সব।
- সব ডাউনলোড করুন — ক্যাপচার করা প্রতিটি রিসোর্স স্বয়ংক্রিয় ডুপ্লিকেট অপসারণসহ ফোল্ডার কাঠামোর ZIP-এ।
- ব্যাচ ডাউনলোড সীমিত কনকারেন্সি ও লাইভ প্রোগ্রেস বারসহ চলে; ব্যর্থ ডাউনলোড স্বয়ংক্রিয়ভাবে এবং কনটেক্সট মেনু থেকে আবার চেষ্টা করা হয়।

### HLS ও জটিল ভিডিও
- যে স্ট্রিম ব্রাউজার নিজে চালাতে পারে না (HLS .m3u8, DASH .mpd, অজানা কোডেক), সেগুলোর জন্য কালো প্লেয়ারের বদলে স্মার্ট ফলব্যাক দেখানো হয়।
- সেগমেন্ট মার্জ করে ডাউনলোড একটি HLS স্ট্রিমকে প্যানেলের ভেতরেই একটিমাত্র চালানোযোগ্য ফাইলে পরিণত করে।

### টেক্সট ওয়ার্কবেঞ্চ (SPA কনটেন্ট টুলকিট)
- **টেক্সট ট্যাব একটি লাইভ কনটেন্ট ভিউয়ার:** টেক্সট বহনকারী প্রতিটি এলিমেন্ট—হেডিং, প্যারাগ্রাফ, লিস্ট আইটেম, বাটন, div, span—DOM ক্রমে ক্যাপচার করা হয়।
- ডায়নামিক টেবিল সীমিত স্ন্যাপশট ইতিহাস রাখে (যেমন «8টি স্ন্যাপশট · 124টি অনন্য সারি»), তাই নিজে থেকে রিফ্রেশ হওয়া ড্যাশবোর্ড কখনো মধ্যবর্তী অবস্থা হারায় না।
- Markdown হিসেবে এক্সপোর্ট করুন, অথবা টেবিল CSV, HTML বা আমাদের নিজস্ব হাতে লেখা XLSX রাইটারে তৈরি আসল মাল্টি-শিট XLSX ওয়ার্কবুক হিসেবে।

## কীভাবে ব্যবহার করবেন
1. Source Download ইনস্টল করুন, তারপর যেকোনো পেজে F12 চাপুন।
2. DevTools টুলবারে Source Download ট্যাবে ক্লিক করুন (Chrome এক্সটেনশনকে স্বয়ংক্রিয়ভাবে DevTools খুলতে দেয় না—এ কারণেই এটি সেখানে থাকে)।
3. ক্যাটাগরি ট্যাব ব্রাউজ করুন, সার্চ ও ফিল্টার করুন, ডান দিকের প্যানেলে যেকোনো কিছু পরীক্ষা করুন।
4. পছন্দের ফাইলগুলোতে টিক দিন এবং ডাউনলোড নির্বাচিত, ভিউ ডাউনলোড বা সব ডাউনলোড করুন চাপুন।
5. প্রতিটি নেটওয়ার্ক রিকোয়েস্ট ধরতে পেজ লোড হওয়ার সময় DevTools প্যানেল খোলা রাখুন।

## বাস্তব ব্যবহারের ক্ষেত্র
- **প্রতিদ্বন্দ্বী বিশ্লেষণ:** সর্বনিম্ন প্রস্থ ফিল্টার দিয়ে যেকোনো চ্যানেলের ভিডিও থাম্বনেইল একটি ফোল্ডারে সংগ্রহ করুন।
- **কোড ছাড়া ওয়েব স্ক্র্যাপিং:** কোনো SPA-র API কল দেখুন, দরকারি এন্ডপয়েন্টে ফিল্টার করুন, তার হুবহু JSON রেসপন্স ডাউনলোড করুন।
- **টাইপোগ্রাফি বিশ্লেষণ:** একটি সাইট আসলে কোন ফন্ট ব্যবহার করে তা জানুন এবং আসল ফন্ট ফাইল নিয়ে নিন।
- **বাগ পুনরুৎপাদন:** বাগ ঘটার সময় যে CSS/JS সংস্করণ চালু ছিল, হুবহু সেটি সংরক্ষণ করুন।
- **ড্যাশবোর্ড ডেটা এক্সপোর্ট:** নিজে থেকে রিফ্রেশ হওয়া টেবিল ইতিহাসসহ মাল্টি-শিট Excel ওয়ার্কবুকে এক্সপোর্ট করুন।
- **QA টেস্টিং:** প্রতিটি A/B কনফিগারেশনে কোন ভিডিও/অডিও ভ্যারিয়েন্ট পরিবেশিত হচ্ছে তা যাচাই করুন।

3. Chrome DevTools খুলুন (`F12` বা macOS-এ `Ctrl+Shift+I` / `Cmd+Option+I`) এবং **Source Download** ট্যাবে ক্লিক করুন, অথবা পেজের যেকোনো জায়গায় রাইট-ক্লিক করুন।

### পদ্ধতি 2: সোর্স থেকে আনপ্যাকড এক্সটেনশন লোড করুন (ডেভেলপার মোড)
1. অফিসিয়াল GitHub রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome খুলে `chrome://extensions`-এ যান।
3. উপরের ডান কোণে **ডেভেলপার মোড** টগল চালু করুন।
4. **আনপ্যাকড লোড করুন**-এ ক্লিক করুন এবং ক্লোন করা `source-download` প্রজেক্ট ফোল্ডারটি নির্বাচন করুন।
