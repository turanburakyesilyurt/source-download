Source Download هو لوحة ضمن Chrome DevTools تكتشف كل مورد تحمّله صفحة الويب وتفحصه وتحمّله. سواء كنت تحتاج إلى ملفات وسائط أو سكربتات برمجية أو موارد التنسيق أو استجابات الشبكة، يمكنك حفظها كملفات فردية أو في ملف ZIP مرتّب بهيكل مجلدات.

بُني من الصفر دون أي اعتماديات خارجية: كاتب ZIP ومُنشئ XLSX ودامج HLS ومنسّقات الأكواد كلها مكتوبة يدويًا بجافاسكربت خالصة. بلا أطر عمل، وبلا خطوة بناء، وبلا أي تتبّع. كل شيء يعمل محليًا داخل متصفحك.

## ما الجديد في v1.16.0
- دعم متعدد اللغات بالكامل لـ 54 لغة مع ترجمة كاملة لـ DevTools والمتجر.
- 17 فئة مخصصة للموارد بعدّادات مباشرة تغطي كل الوسائط والأكواد وواجهات API والتخزين والمستندات.
- لقطات شاشة مدمجة للصفحة كاملة والتقاط منطقة محددة مع إخفاء ذكي للرؤوس الثابتة.
- تسجيل فيديو للشاشة (MP4) ومحرك خفيف لتصدير GIF متحرك دون حواف زائدة.
- مستخرج مباشر لجداول DOM إلى Microsoft Excel (.XLSX) متعدد الأوراق وCSV مع أداة DOM Zapper لإزالة العناصر.
- أداة انتقاء ألوان من الشاشة مع نسخ فوري بصيغ hex/rgb/hsl ومنسّق أكواد مدمج.
- استقرار أفضل لمستكشف DevTools وخط شبكة عالي التزامن.

## لماذا تحتاج إليه
لقطة الشاشة لا تكفي. احصل على الملفات الحقيقية — صور بدقتها الكاملة، وتدفقات فيديو فعلية، وأوراق أنماط وسكربتات أصلية — لا مجرد صورة مسطّحة.

DevTools قد يبدو مربكًا. يضع Source Download أمامك معرضًا مرتبًا ومصنّفًا لبيانات الشبكة نفسها، مع بحث ومرشحات وتحميل بنقرة واحدة.

تطبيقات SPA تُخفي كل شيء. التطبيقات الديناميكية تنشئ موارد وطلبات API لا تراها في مصدر الصفحة. يلتقطها Source Download لحظة حدوثها، بما في ذلك الحالات الوسيطة.

### اكتشف كل شيء
- يجمع بين التقاط الشبكة (HAR + الطلبات المباشرة) وفحص DOM لكل العناصر المرئية والبنيوية، بما فيها ملفات الوسائط والسكربتات وأوراق الأنماط والإطارات المضمّنة.
- **يدعم CSS:** تُتتبَّع الموارد داخل url(...) وقواعد @import بشكل تكراري، فيُعثر حتى على الخطوط المدفونة في أوراق الأنماط المستوردة.
- **فحص المحتوى:** تُقرأ بضعة بايتات من الملفات المجهولة ثم تُنقل إلى فئة نوع الملف الفعلي.
- **17 فئة بعدّادات مباشرة:** تُنظَّم الموارد الملتقطة بدقة في علامات تبويب مخصصة للوسائط والأكواد والبيانات واستدعاءات API وملفات تعريف الارتباط والتخزين والمستندات.

### صفِّ وابحث وافحص
- بحث بالتعبيرات النمطية في أسماء الملفات وعناوين URL وأنواع MIME والنص البديل وحتى محتويات الملفات.
- **مرشحات لكل فئة:** الحد الأدنى/الأقصى للحجم، وللوسائط أيضًا الحد الأدنى/الأقصى للعرض والارتفاع — مثل «صور الواجهة الرئيسية التي لا يقل عرضها عن 1200px فقط». تُصفّى استدعاءات API حسب طريقة HTTP ونوع الطلب.
- عرض قائمة أو شبكة، قابل للفرز، مع جدار مصغّرات مباشر.
- **مفتش متعدد علامات التبويب بمعاينات حقيقية:** عارض صور قابل للتكبير، وتشغيل فيديو وصوت، وعينة خط حية، وعارض SVG، وأكواد بإبراز الصياغة وأرقام الأسطر ومفتاح تبديل Beautify.
- **عرض API مقسّم:** الاستجابة على اليسار، والطريقة والحالة ومعاملات الاستعلام وجسم الطلب على اليمين.

### حمّل بالطريقة الصحيحة
- تحميل المحدد — الملفات التي حددتها فقط.
- تحميل عرض — كل ما يظهر بعد تطبيق المرشحات والبحث الحاليين.
- تحميل الكل — كل مورد ملتقط في ملف ZIP بهيكل مجلدات مع إزالة تلقائية للتكرار.
- تعمل التحميلات الدفعية بتزامن محدود مع شريط تقدم مباشر؛ وتُعاد محاولة الإخفاقات تلقائيًا ومن قائمة السياق.

### HLS والفيديو المعقّد
- التدفقات التي لا يستطيع المتصفح تشغيلها محليًا (HLS .m3u8 وDASH .mpd وترميزات غير معروفة) تعرض بديلًا ذكيًا بدل مشغّل أسود.
- «دمج المقاطع والتحميل» يحوّل تدفق HLS إلى ملف واحد قابل للتشغيل، مباشرة داخل اللوحة.

### ورشة النصوص (أدوات محتوى SPA)
- **علامة التبويب «النص» عارض محتوى مباشر:** كل عنصر يحمل نصًا — العناوين والفقرات وعناصر القوائم والأزرار وdiv وspan — يُلتقط بترتيب DOM.
- تحتفظ الجداول الديناميكية بسجل لقطات محدود (مثل «8 لقطات · 124 صفًا فريدًا»)، فلا تفقد لوحات المعلومات ذاتية التحديث حالاتها الوسيطة.
- صدّر بصيغة Markdown، أو الجداول بصيغة CSV أو HTML أو مصنف XLSX حقيقي متعدد الأوراق يبنيه كاتب XLSX الخاص بنا المكتوب يدويًا.

## طريقة الاستخدام
1. ثبّت Source Download، ثم اضغط F12 في أي صفحة.
2. انقر علامة تبويب Source Download في شريط أدوات DevTools (لا يسمح Chrome للإضافات بفتح DevTools تلقائيًا — لهذا السبب توجد هناك).
3. تصفّح علامات تبويب الفئات، وابحث وصفِّ وافحص أي شيء في اللوحة اليمنى.
4. حدّد الملفات التي تريدها ثم اضغط تحميل المحدد أو تحميل عرض أو تحميل الكل.
5. أبقِ لوحة DevTools مفتوحة أثناء تحميل الصفحة لالتقاط كل طلبات الشبكة.

## حالات استخدام واقعية
- **تحليل المنافسين:** اجمع صور الفيديو المصغّرة من أي قناة — مع مرشح حد أدنى للعرض — في مجلد واحد.
- **استخراج بيانات الويب دون كتابة كود:** راقب استدعاءات API لتطبيق SPA، وصفِّ حتى نقطة النهاية التي تحتاجها، وحمّل استجابات JSON الدقيقة.
- **تفكيك الخطوط:** اكتشف الخط الذي يستخدمه الموقع فعلًا واحصل على ملفات الخط الأصلية.
- **إعادة إنتاج الأخطاء:** احتفظ بإصدارات CSS/JS الدقيقة التي نُشرت عند حدوث الخطأ.
- **تصدير بيانات لوحات المعلومات:** صدّر جدولًا ذاتي التحديث إلى مصنف Excel متعدد الأوراق، مع السجل الكامل.
- **اختبار الجودة:** تحقق من متغير الفيديو/الصوت المقدَّم في كل إعداد A/B.

## الخصوصية
- يعمل محليًا بنسبة 100%. بلا خادم، وبلا تحليلات، ولا تغادر أي بيانات جهازك.
- **يطلب فقط ما يحتاج إليه:** التخزين (تفضيلاتك)، والحافظة (نسخ عناوين URL والألوان)، والتنزيلات (حفظ الملفات عبر Chrome)، وقوائم السياق، والسكربتات، والوصول إلى المضيف (لفحص الصفحات وجلب محتوى الملفات).

## التثبيت والبدء السريع

### الطريقة 1: التثبيت المباشر من متجر Chrome الإلكتروني (موصى بها)
1. زر [صفحة Source Download الرسمية في متجر Chrome الإلكتروني](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd).
2. انقر **إضافة إلى Chrome** ومنح الأذونات.
3. افتح Chrome DevTools (`F12` أو `Ctrl+Shift+I` / `Cmd+Option+I` على macOS) وانقر علامة التبويب **Source Download**، أو انقر بزر الماوس الأيمن في أي مكان بالصفحة.

### الطريقة 2: تحميل الإضافة غير المحزّمة من المصدر (وضع المطوّر)
1. انسخ مستودع GitHub الرسمي:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. افتح Google Chrome وانتقل إلى `chrome://extensions`.
3. فعّل مفتاح **وضع المطوّر** في الزاوية العلوية.
4. انقر **تحميل إضافة غير مضغوطة** وحدد مجلد المشروع المنسوخ `source-download`.
