## Entwickelt von Turan Burak Yeşilyurt

Als Entwickler für Web-Scraping, QA-Automatisierung und Datenanalyse stieß ich immer wieder auf dieselbe Hürde: Einzelne Medien und Datensätze moderner SPAs lassen sich oft nur mühsam speichern, und die Chrome DevTools sind für schnelle Aufgaben oft überdimensioniert. **Source Download** wurde entwickelt, um dieses Problem sauber, lokal und kompromisslos zu lösen.

Vernetzen Sie sich gern auf [**LinkedIn**](https://www.linkedin.com/in/turan-burak-yesilyurt/) oder besuchen Sie [**2run.dev**](https://2run.dev).

> **Chrome Web Store:** [Source Download im Chrome Web Store installieren](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd)

---

> **Das Open-Source-Versprechen:** Viele ähnliche Erweiterungen sind schwere Hüllen um fremde Bibliotheken. Bei Source Download ist jedes Byte — von der **ZIP-Engine** über den **XLSX-Builder** und **HLS-Merger** bis zum **GIF-Encoder** — von Grund auf in reinem JavaScript handgeschrieben. Keine Frameworks, keine Abhängigkeiten, kein Build-Schritt, keine Telemetrie.

Untersuchen und laden Sie Webinhalte, die eine Seite lädt, nahtlos als ZIP-Datei herunter.

Source Download — Alle Inhalte einer Seite mit einem Klick erreichbar
Source Download ist ein Chrome DevTools-Panel, das alle von einer Webseite geladenen Ressourcen erkennt, überprüft und herunterlädt. Ob Mediendateien, Skripte, Stylesheets oder Netzwerkantworten – Sie können diese einzeln oder in einem strukturierten ZIP-Archiv speichern.

Von Grund auf ohne Drittanbieter-Bibliotheken entwickelt: ZIP-Writer, XLSX-Builder, HLS-Merger und Code-Formatierer sind in reinem Vanilla-JavaScript geschrieben. Keine Frameworks, kein Build-Schritt, keine Telemetrie. Alles läuft lokal in Ihrem Browser.

Neu in Version 1.15.0
- Nahtlose scrollende Ganzseiten-Screenshots und Erfassung benutzerdefinierter Bereiche.
- Bildschirm-Videoaufnahme und Export kompakter animierter GIFs.
- Farbpipette zur direkten Übernahme von Farbcodes in die Zwischenablage.
- Performance-Optimierungen und gesteigerte Stabilität bei der Ressourcenerkennung.
- Erweiterte Sprachunterstützung: 4 neue Sprachen (Französisch, Italienisch, Koreanisch, Brasilianisches Portugiesisch) hinzugefügt — jetzt 11 vollständig lokalisierte Sprachen in UI und Handbuch.
- Upgrade auf 17 dedizierte Live-Ressourcenkategorien mit Echtzeitzählern.

Warum Sie es brauchen
Ein einfacher Screenshot reicht oft nicht aus. Holen Sie sich die echten Dateien – hochauflösende Bilder, echte Videostreams, originale Stylesheets und Skripte – statt einer flachen Abbildung.

DevTools können unübersichtlich sein. Source Download stellt eine saubere, kategorisierte Galerie vor dieselben Netzwerkdaten, inklusive Suche, Filter und Ein-Klick-Downloads.

SPAs verbergen viele Inhalte. Moderne Webanwendungen laden Ressourcen und API-Aufrufe dynamisch nach. Source Download erfasst sie direkt beim Laden, einschließlich aller Zwischenzustände.

Funktionsumfang
Umfassende Erkennung
Kombiniert Netzwerkerfassung mit einem DOM-Scan für alle sichtbaren und strukturellen Elemente, einschließlich Mediendateien, Skripte, Stylesheets und eingebetteter Frames.

CSS-Erkennung: Ressourcen in url(...)- und @import-Regeln werden rekursiv verfolgt, sodass auch tief eingebettete Schriftarten zuverlässig gefunden werden.

Inhaltsprüfung: Unbekannte Dateitypen werden anhand ihrer ersten Bytes analysiert und der passenden Kategorie zugeordnet.

17 Live-Kategorien: Erkannte Inhalte werden übersichtlich in Reitern für Medien, Code, Daten, Schnittstellenaufrufe und Dokumente sortiert.

Filtern, Suchen, Prüfen
Regex-gestützte Suche über Dateinamen, URLs, Inhaltstypen und Datei-Inhalte.

Kategoriespezifische Filter für Dateigrößen sowie Bildbreiten und -höhen.

Listen- oder Rasteransicht mit dynamischer Vorschauwand.

Inspektor mit echten Vorschauen: Zoom-Lightbox, Audio- und Videowiedergabe, Schriftarten-Vorschau, SVG-Ansicht und formatierter Quelltext mit Syntax-Highlighting.

API-Detailansicht mit Status, Kopfzeilen, Abfrageparametern und Antwortdaten.

Zuverlässiger Download
Ausgewählte herunterladen — Nur die markierten Elemente.

Ansicht herunterladen — Alles, was durch die aktuellen Filter sichtbar ist.

Alle herunterladen — Sämtliche Ressourcen in einer sauberen ZIP-Struktur mit automatischer Duplikat-Bereinigung.

HLS-Videostreams
Streams, die der Browser nicht nativ abspielen kann, werden erkannt und können direkt im Panel zu einer einzelnen Datei zusammengeführt werden.

Tabellen & Text-Werkzeuge
Erfasst Textelemente und Tabellen im DOM. Dynamische Tabellen behalten ihren Verlauf bei und können als Markdown, CSV oder mehrblättrige XLSX-Arbeitsmappe exportiert werden.

## Installation & Schnellstart

### Methode 1: Installation über den Chrome Web Store (Empfohlen)
1. Öffnen Sie die offizielle Seite im [Chrome Web Store](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd).
2. Klicken Sie auf **Hinzufügen**.
3. Öffnen Sie die Chrome DevTools (`F12` oder `Cmd+Option+I` auf macOS) und wechseln Sie zum Tab **Source Download**.

### Methode 2: Entwicklermodus (Unpacked) aus Quellcode
1. Repository lokal klonen:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Navigieren Sie in Chrome zu `chrome://extensions`.
3. Aktivieren Sie oben rechts den **Entwicklermodus**.
4. Klicken Sie auf **Entpackte Erweiterung laden** und wählen Sie den Projektordner aus.
