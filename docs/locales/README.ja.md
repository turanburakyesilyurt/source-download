Source Downloadは、Webページが読み込むあらゆるリソースを検出・検査・保存するChrome DevToolsパネルです。メディアファイル、開発用スクリプト、スタイルアセット、ネットワークレスポンスなど、必要なものを個別のファイルとして、またはフォルダ構造を保ったZIPとしてすっきり保存できます。

サードパーティの依存関係ゼロでゼロから構築：ZIPライター、XLSXビルダー、HLSマージャー、コードフォーマッターはすべて手書きのバニラJavaScriptです。フレームワークなし、ビルド工程なし、テレメトリなし。すべてブラウザ内でローカルに実行されます。

## v1.16.0の新機能
- 54言語に完全対応し、DevToolsとストアの表示もすべてローカライズ。

- DevToolsスニッファーの安定性と、高並列ネットワークパイプラインを強化。

## こんなときに役立ちます
スクリーンショットだけでは足りません。平坦化された画像ではなく、本物のファイル — 原寸大の画像、実際の動画ストリーム、元のスタイルシートやスクリプト — を手に入れましょう。

DevToolsは複雑で圧倒されがちです。Source Downloadは同じネットワークデータを、検索・フィルター・ワンクリック保存付きのすっきり分類されたギャラリーで表示します。

SPAはすべてを隠してしまいます。動的なアプリは、ページのソースには現れないアセットやAPI呼び出しを生成します。Source Downloadは、途中の状態も含めて、発生した瞬間にそれらを捕捉します。

## 主な機能
### すべてを見つける
- ネットワークキャプチャ（HAR＋ライブリクエスト）とDOMスキャンを組み合わせ、メディアファイル、スクリプト、スタイルシート、埋め込みフレームを含むすべての視覚的・構造的要素を検出します。
- **CSS対応：** url(...)や@importルール内のアセットを再帰的にたどるため、インポートされたスタイルシートの奥に埋もれたフォントも見つかります。
- **コンテンツスニッフィング：** 不明なファイルは先頭の数バイトを読み取り、実際のファイル形式のカテゴリに振り分けます。
- **17のリアルタイム件数付きカテゴリ：** キャプチャしたアセットは、メディア、コード、データ、API呼び出し、Cookie、ストレージ、ドキュメントの専用タブに整理されます。

### 絞り込み・検索・検査
- ファイル名、URL、MIMEタイプ、代替テキスト、さらにはファイルの中身まで対象にした正規表現検索。
- **カテゴリごとのフィルター：** サイズの最小/最大、メディアでは幅と高さの最小/最大も指定可能 — 例：「1200px以上のヒーロー画像のみ」。API呼び出しはHTTPメソッドとリクエスト種別で絞り込めます。
- リスト表示とグリッド表示、並べ替え対応、リアルタイムのサムネイルウォール付き。
- **本物のプレビューを備えたマルチタブインスペクター：** ズーム可能なライトボックス、動画・音声の再生、ライブのフォント見本、SVGビューアー、行番号付きのシンタックスハイライトコード、そして整形の切り替え。
- **API分割ビュー：** 左にレスポンス、右にメソッド、ステータス、クエリパラメーター、リクエストボディを表示。

### きちんと保存
- 選択項目を保存 — チェックを入れたファイルだけを保存。
- 表示中を保存 — 現在のフィルターと検索の結果、表示されているものすべてを保存。
- すべて一括保存 — キャプチャしたすべてのリソースを、重複を自動排除してフォルダ構造のZIPにまとめて保存。
- 一括ダウンロードは同時実行数を制限しつつ、リアルタイムの進行バー付きで実行。失敗したものは自動的に、またコンテキストメニューからも再試行されます。

### HLSと扱いの難しい動画
- ブラウザがネイティブ再生できないストリーム（HLSの.m3u8、DASHの.mpd、不明なコーデック）は、真っ黒なプレーヤーではなくスマートなフォールバック表示になります。
- セグメントを結合して保存すると、HLSストリームを再生可能な1つのファイルに変換します。パネル内でそのまま実行できます。

### テキストワークベンチ（SPAコンテンツツールキット）
- テキストタブはライブのコンテンツビューアーです。見出し、段落、リスト項目、ボタン、div、spanなど、テキストを持つすべての要素がDOM順にキャプチャされます。
- 動的テーブルは上限付きのスナップショット履歴を保持します（例：「8スナップショット · 124件の一意な行」）。自動更新されるダッシュボードでも途中の状態が失われません。
- Markdownとして書き出せるほか、テーブルはCSV、HTML、または当社の手書きXLSXライターで作成する本格的な複数シートのXLSXブックとして書き出せます。

## 使い方
1. Source Downloadをインストールし、任意のページでF12キーを押します。
2. DevToolsのツールバーにあるSource Downloadタブをクリックします（Chromeでは拡張機能がDevToolsを自動で開くことができないため、ここに配置されています）。
3. カテゴリタブを閲覧し、検索・絞り込みを行い、右側のパネルで何でも検査できます。
4. 必要なファイルにチェックを入れ、選択項目を保存、表示中を保存、またはすべて一括保存を押します。
5. すべてのネットワークリクエストをキャプチャするため、ページの読み込み中はDevToolsパネルを開いたままにしてください。

## 実際の活用例
- **競合分析：** 任意のチャンネルの動画サムネイルを、最小幅フィルターを使って1つのフォルダに収集。
- **コード不要のWebスクレイピング：** SPAのAPI呼び出しを監視し、必要なエンドポイントに絞り込んで、正確なJSONレスポンスを保存。
- **タイポグラフィの分析：** サイトが実際に使っているフォントを突き止め、実際のフォントファイルを入手。
- **バグの再現：** バグが発生したときに公開されていたCSS/JSの正確なバージョンを保管。
- **ダッシュボードデータの書き出し：** 自動更新されるテーブルを、履歴ごと複数シートのExcelブックに書き出し。
- **QAテスト：** A/Bの各構成でどの動画/音声バリアントが配信されているかを検証。

## プライバシー
- 100%ローカルで動作。サーバーなし、アナリティクスなし、データがお使いのマシンの外に出ることはありません。
- **必要な権限のみを要求：** ストレージ（設定の保存）、クリップボード（URLや色のコピー）、ダウンロード（Chrome経由でのファイル保存）、コンテキストメニュー、スクリプティング、ホストアクセス（ページのスキャンとファイル本体の取得）。
- ファイルはChrome標準のダウンロードの流れで保存され、無断でのダウンロードは行われません。

## 動作要件
- Chrome 116以降（Manifest V3）。
- ネットワークキャプチャはページの読み込み中に行われるため、パネルを開いたまま読み込むと最良の結果が得られます。

## インストールとクイックスタート

### 方法1：Chrome ウェブストアから直接インストール（推奨）
1. 公式の[Source Download Chrome ウェブストアのページ](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd)にアクセスします。
2. **Chrome に追加**をクリックし、権限を許可します。
3. Chrome DevTools（`F12`、または macOS では `Ctrl+Shift+I` / `Cmd+Option+I`）を開いて **Source Download** タブをクリックするか、ページ上の任意の場所を右クリックします。

### 方法2：ソースからパッケージ化されていない拡張機能を読み込む（デベロッパーモード）
1. 公式のGitHubリポジトリをクローンします：
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chromeを開き、`chrome://extensions` に移動します。
3. 右上の**デベロッパーモード**のトグルをオンにします。
4. **パッケージ化されていない拡張機能を読み込む**をクリックし、クローンした `source-download` プロジェクトフォルダを選択します。
