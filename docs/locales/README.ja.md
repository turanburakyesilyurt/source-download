Source Download は、Web の内容をまとめて取り込むためのツールです。Chrome デベロッパー ツールに専用タブを追加し、サイトが読み込んだものをカテゴリ別に整理します。プレビューして必要なものだけを手元に残せます。

## 主な機能
- 整理されたギャラリー：写真やアイコン、フォントがそれぞれのタブに並び、件数がリアルタイムで表示されます。検索ボックスもあります。
- 細かな絞り込み：幅 1200 px 以上など、最小サイズを満たす項目だけを表示したり、重複を隠したりできます。
- 本物のプレビュー：グラフィックの拡大やメディアの再生ができます。フォント見本の表示や、構文が色分けされたコードの閲覧も可能です。
- ひとつのアーカイブ：欲しいものにチェックを入れると、フォルダー構成の整った ZIP がひとつ手に入ります。失敗した項目はワンクリックで再試行できます。
- ページ全体のスクリーンショット：上から下までスクロールしてつなぎ合わせ、PNG / JPG / PDF にします。一部分だけの選択もできます。
- 範囲の録画：画面の一部を GIF / MP4 / WebM のクリップにします。
- 表をスプレッドシートへ：表示中の表を Excel または CSV に書き出せます。更新され続ける表の過去の状態も含まれます。
- オフライン コピー：サイトを 1 つの HTML 文書として残し、インターネットなしで開けます。
- カラーピッカー：画面上の好きな色を選び、HEX / RGB / HSL でコピーできます。

## 使い方
1. 作業したい Web サイトを開きます。
2. F12（Mac では Option + Command + I）を押して Source Download タブを選びます。見当たらないときはタブバーの端の » をクリックします。
3. 読み込みの間はパネルを開いたままにすると、取りこぼしがありません。

スクリーンショットと録画、カラーピッカーは右クリック メニューと拡張機能のボタンからも使えます。

## プライバシー

すべてお使いのパソコン上で動作します。アカウント登録も分析もなく、取り込んだ内容が開発者に送られることはありません。保存したものは Chrome を通じていつもの「ダウンロード」フォルダーに入ります。

リソースを見つけて機能を提供するため、拡張機能は閲覧中のサイトへのアクセスを必要とします。

著作権と利用規約を守り、利用が認められたコンテンツだけを保存してください。

## インストールとクイックスタート

### 方法1：Chrome ウェブストアから直接インストール（推奨）
1. 公式の[Source Download Chrome ウェブストアのページ](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd)にアクセスします。
2. **Chrome に追加**をクリックし、権限を許可します。
3. Chrome DevTools（`F12`、または macOS では `Ctrl+Shift+I` / `Cmd+Option+I`）を開いて **Source Download** タブをクリックするか、ページ上の任意の場所を右クリックします。

### 方法2：ソースからパッケージ化されていない拡張機能を読み込む（デベロッパーモード）
1. 公式のGitHubリポジトリをクローンします：
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chromeを開き、`chrome://extensions` に移動します。
3. 右上の**デベロッパーモード**のトグルをオンにします。
4. **パッケージ化されていない拡張機能を読み込む**をクリックし、クローンした `source-download` プロジェクトフォルダを選択します。
