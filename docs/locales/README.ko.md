## v1.16.0의 새로운 기능
- 54개 언어를 완벽하게 지원하며 DevTools와 스토어 모두 현지화되었습니다.
- 미디어, 코드, API, 저장소, 문서를 모두 아우르는 17개의 전용 카테고리에 실시간 개수가 표시됩니다.
- 전체 페이지 이어 붙임 스크린샷과 사용자 지정 영역 캡처를 지원하며, 고정 헤더를 똑똑하게 숨깁니다.
- 화면 동영상 녹화(MP4)와 가벼운 애니메이션 GIF 내보내기 엔진을 제공하며, 가장자리 번짐이 없습니다.
- 실시간 DOM 표 추출기로 여러 시트의 Microsoft Excel(.XLSX)과 CSV로 내보내며, DOM 요소 숨기기 도구도 함께 제공합니다.
- 화면 색상 스포이트로 hex/rgb/hsl 값을 즉시 복사하고, 통합 코드 정렬 기능을 사용할 수 있습니다.
- DevTools 스니퍼 안정성과 고동시성 네트워크 파이프라인이 개선되었습니다.

## 왜 필요할까요
스크린샷으로는 부족합니다. 평면 이미지가 아니라 원본 해상도 이미지, 실제 동영상 스트림, 원본 스타일시트와 스크립트 같은 진짜 파일을 가져오세요.

DevTools는 부담스럽습니다. Source Download는 같은 네트워크 데이터를 깔끔하게 분류된 갤러리로 보여 주며, 검색, 필터, 원클릭 다운로드를 지원합니다.

SPA는 모든 것을 숨깁니다. 동적 앱이 만드는 리소스와 API 호출은 페이지 소스에 나타나지 않습니다. Source Download는 중간 상태까지 포함해 발생하는 즉시 캡처합니다.

## 주요 기능
### 모든 것을 찾아냅니다
- 네트워크 캡처(HAR + 실시간 요청)와 DOM 스캔을 결합해 미디어 파일, 스크립트, 스타일시트, 임베디드 프레임을 포함한 모든 시각 요소와 구조 요소를 찾습니다.
- **CSS 인식:** url(...)과 @import 규칙 안의 리소스를 재귀적으로 따라가므로, 가져온 스타일시트 깊숙이 있는 글꼴도 찾아냅니다.
- **콘텐츠 스니핑:** 알 수 없는 파일은 몇 바이트를 읽어 실제 파일 유형 카테고리로 분류합니다.
- **실시간 개수가 표시되는 17개 카테고리:** 캡처한 리소스가 미디어, 코드, 데이터, API 호출, 쿠키, 저장소, 문서 탭으로 깔끔하게 정리됩니다.

### 필터, 검색, 검사
- 파일 이름, URL, MIME 유형, 대체 텍스트, 심지어 파일 내용까지 정규식으로 검색합니다.
- **카테고리별 필터:** 최소/최대 크기, 미디어는 최소/최대 너비와 높이까지 지원합니다. 예를 들어 "1200px 이상의 히어로 이미지만" 볼 수 있습니다. API 호출은 HTTP 메서드와 요청 유형으로 필터링합니다.
- 목록 또는 그리드 보기, 정렬 가능, 실시간 썸네일 월 제공.
- **정확한 미리보기를 갖춘 멀티 탭 검사기:** 확대 가능한 라이트박스, 비디오 및 오디오 재생, 실시간 글꼴 견본, SVG 뷰어, 줄 번호가 있는 구문 강조 코드, 정렬 토글.
- **API 분할 보기:** 왼쪽에는 응답, 오른쪽에는 메서드, 상태, 쿼리 매개변수, 요청 본문이 표시됩니다.

### 제대로 다운로드
- 선택 항목 다운로드 — 체크한 파일만 받습니다.
- 현재 화면 다운로드 — 현재 필터와 검색 결과로 보이는 모든 항목을 받습니다.
- 전체 다운로드 — 캡처한 모든 리소스를 자동 중복 제거와 함께 폴더 구조가 있는 ZIP으로 받습니다.
- 일괄 다운로드는 동시 실행 수를 제한하고 실시간 진행률 표시줄을 보여 주며, 실패한 항목은 자동으로 재시도하고 컨텍스트 메뉴에서도 다시 시도할 수 있습니다.

### HLS 및 까다로운 동영상
- 브라우저가 기본으로 재생할 수 없는 스트림(HLS .m3u8, DASH .mpd, 알 수 없는 코덱)은 검은 플레이어 대신 스마트 대체 화면을 보여 줍니다.
- 세그먼트 병합 및 다운로드는 HLS 스트림을 패널 안에서 바로 재생 가능한 단일 파일로 만들어 줍니다.

### 텍스트 워크벤치 (SPA 콘텐츠 도구)
- 텍스트 탭은 실시간 콘텐츠 뷰어입니다. 제목, 단락, 목록 항목, 버튼, div, span 등 텍스트가 있는 모든 요소를 DOM 순서대로 캡처합니다.
- 동적 표는 제한된 스냅샷 기록을 보관하므로(예: "스냅샷 8개 · 고유 행 124개") 자동으로 새로고침되는 대시보드도 중간 상태를 잃지 않습니다.
- Markdown으로 내보내거나, 표는 CSV, HTML 또는 직접 만든 XLSX 작성기로 생성한 여러 시트의 XLSX 통합 문서로 내보낼 수 있습니다.

## 사용 방법
1. Source Download를 설치한 뒤 아무 페이지에서나 F12를 누르세요.
2. DevTools 도구 모음에서 Source Download 탭을 클릭하세요(Chrome은 확장 프로그램이 DevTools를 자동으로 열도록 허용하지 않기 때문에 이 위치에 있습니다).
3. 카테고리 탭을 둘러보고, 검색하고, 필터링하고, 오른쪽 패널에서 원하는 항목을 검사하세요.
4. 원하는 파일을 체크한 뒤 선택 항목 다운로드, 현재 화면 다운로드 또는 전체 다운로드를 누르세요.
5. 모든 네트워크 요청을 캡처하려면 페이지가 로드되는 동안 DevTools 패널을 열어 두세요.

## 실제 활용 사례
- **경쟁사 분석:** 최소 너비 필터를 적용해 어떤 채널의 동영상 썸네일이든 하나의 폴더에 모읍니다.
- **코드 없는 웹 스크래핑:** SPA의 API 호출을 지켜보고, 필요한 엔드포인트만 필터링해 정확한 JSON 응답을 다운로드합니다.
- **타이포그래피 분석:** 사이트가 실제로 사용하는 글꼴을 알아내고 실제 글꼴 파일을 가져옵니다.
- **버그 재현:** 버그가 발생했을 때 배포된 CSS/JS의 정확한 버전을 보관합니다.
- **대시보드 데이터 내보내기:** 자동 새로고침 표를 기록까지 포함해 여러 시트의 Excel 통합 문서로 내보냅니다.
- **QA 테스트:** A/B 구성마다 어떤 비디오/오디오 변형이 제공되는지 확인합니다.

## 설치 및 빠른 시작

### 방법 1: Chrome 웹 스토어에서 바로 설치 (권장)
1. 공식 [Source Download Chrome 웹 스토어 페이지](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd)를 방문하세요.
2. **Chrome에 추가**를 클릭하고 권한을 허용하세요.
3. Chrome DevTools(`F12` 또는 macOS에서는 `Ctrl+Shift+I` / `Cmd+Option+I`)를 열고 **Source Download** 탭을 클릭하거나, 페이지의 아무 곳에서나 마우스 오른쪽 버튼을 클릭하세요.

### 방법 2: 소스에서 압축 해제된 확장 프로그램 로드 (개발자 모드)
1. 공식 GitHub 저장소를 복제하세요:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome을 열고 `chrome://extensions`로 이동하세요.
3. 오른쪽 상단의 **개발자 모드** 토글을 켜세요.
4. **압축해제된 확장 프로그램을 로드합니다**를 클릭하고 복제한 `source-download` 프로젝트 폴더를 선택하세요.
