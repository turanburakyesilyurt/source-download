## ዋና ዋና ባህሪያት
- የተደራጀ ማዕከለ-ስዕላት፦ ፎቶዎች፣ አዶዎች እና ቅርጸ-ቁምፊዎች በራሳቸው ትሮች ከቀጥታ ቆጣሪዎች እና የፍለጋ ሳጥን ጋር ይታያሉ።
- ትክክለኛ ማጣሪያዎች፦ ከተወሰነ ዝቅተኛ ስፋት (ለምሳሌ 1200 px) የሚሰፉትን ብቻ ያሳዩ ወይም ተደጋጋሚዎችን ይደብቁ።
- እውነተኛ ቅድመ እይታ፦ ግራፊክስን ያጉሉ እና ሚዲያ ያጫውቱ። የቅርጸ-ቁምፊ ናሙና ወይም የአገባብ ቀለም ያለው ኮድም ማየት ይችላሉ።
- አንድ ማህደር፦ የሚፈልጉትን ምልክት ያድርጉ እና ንጹህ የአቃፊ መዋቅር ያለው አንድ ZIP ያግኙ። ያልተሳካው በአንድ ጠቅታ እንደገና ይሞከራል።
- የሙሉ ገጽ ቅጽበታዊ እይታ፦ ሁሉም ተሸብልሎ በPNG፣ JPG ወይም PDF ይቀላቀላል። አንድ አካባቢ ብቻም መምረጥ ይችላሉ።
- የአካባቢ ቀረጻ፦ የሚታየውን አንድ ክፍል ወደ GIF፣ MP4 ወይም WebM ክሊፕ ይቀይሩ።
- ከሰንጠረዥ ወደ የተመን ሉህ፦ ቀጥታ ሰንጠረዦችን ወደ Excel ወይም CSV ይላኩ፤ የሚታደሱ ሰንጠረዦች ቀደምት ሁኔታዎችም ይካተታሉ።
- ከመስመር ውጭ ቅጂ፦ ጣቢያውን ያለ በይነመረብ የሚከፈት አንድ የHTML ሰነድ አድርገው ያስቀምጡ።
- ቀለም መራጭ፦ የሚታየውን ማንኛውንም ቀለም ይምረጡ እና እንደ HEX፣ RGB ወይም HSL ይቅዱት።

## እንዴት እንደሚጀምሩ
1. መሥራት የሚፈልጉበትን ጣቢያ ይክፈቱ።
2. F12 ይጫኑ (በMac ላይ Option + Command + I) እና የSource Download ትርን ይምረጡ። ካላዩት በትር አሞሌው መጨረሻ ያለውን » ጠቅ ያድርጉ።
3. በመጫን ጊዜ ፓነሉን ክፍት ያድርጉት፤ ምንም አያመልጥዎትም።

ቅጽበታዊ እይታ፣ ቀረጻ እና ቀለም መራጭ በቀኝ-ጠቅታ ምናሌ እና በቅጥያው አዝራር ላይም ይገኛሉ።

## ግላዊነት

ሁሉም ነገር በኮምፒውተርዎ ላይ ይሰራል። መለያም ትንታኔም የለም፤ ያስቀመጡት ምንም ነገር ወደ ገንቢው አይላክም። የተቀመጡት ንጥሎች በChrome በኩል ወደ ተለመደው የውርዶች አቃፊ ይሄዳሉ።

ቅጥያው ሀብቶችን ለማግኘት እና ተግባሩን ለማከናወን የሚጎበኟቸውን ጣቢያዎች መድረስ ያስፈልገዋል።

እባክዎ የቅጂ መብትን እና የአጠቃቀም ደንቦችን ያክብሩ፤ እንዲጠቀሙበት የተፈቀደልዎትን ይዘት ብቻ ያስቀምጡ።

## ጭነት እና ፈጣን ጅምር

### ዘዴ 1፦ ከChrome ድር መደብር በቀጥታ መጫን (የሚመከር)
1. ይፋዊውን [የSource Download Chrome ድር መደብር ገጽ](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd) ይጎብኙ።
2. **ወደ Chrome አክል**ን ጠቅ ያድርጉ እና ፈቃዶችን ይስጡ።
3. Chrome DevToolsን ይክፈቱ (`F12` ወይም በmacOS ላይ `Ctrl+Shift+I` / `Cmd+Option+I`) እና **Source Download** ትርን ጠቅ ያድርጉ፣ ወይም በገጹ ላይ በማንኛውም ቦታ በቀኝ ጠቅ ያድርጉ።

### ዘዴ 2፦ ያልታሸገ ቅጥያን ከምንጭ መጫን (የገንቢ ሁነታ)
1. ይፋዊውን የGitHub ማከማቻ ይቅዱ፦
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chromeን ይክፈቱ እና ወደ `chrome://extensions` ይሂዱ።
3. በላይኛው ቀኝ ጥግ ላይ ያለውን **የገንቢ ሁነታ** መቀያየሪያ ያብሩ።
4. **ያልታሸገ ጫን**ን ጠቅ ያድርጉ እና የተቀዳውን `source-download` የፕሮጀክት አቃፊ ይምረጡ።
