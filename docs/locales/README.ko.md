Source Download는 웹 콘텐츠를 담아 두는 도구 모음입니다. Chrome 개발자 도구에 전용 탭을 추가해, 사이트가 불러온 모든 것을 카테고리별로 정리합니다. 미리 보고 꼭 필요한 것만 남길 수 있습니다.

## 주요 기능
- 정리된 갤러리: 사진과 아이콘, 글꼴이 각자의 탭에 실시간 개수와 함께 표시되며 검색창도 있습니다.
- 정밀한 필터: 1200px처럼 최소 너비를 넘는 항목만 보거나 중복 항목을 숨길 수 있습니다.
- 실제 미리보기: 그래픽을 확대하고 미디어를 재생하며, 글꼴 견본이나 구문이 강조된 코드를 볼 수 있습니다.
- 하나의 압축 파일: 원하는 항목을 선택하면 폴더가 정돈된 ZIP 하나로 받습니다. 실패한 항목은 클릭 한 번으로 다시 시도합니다.
- 전체 페이지 스크린샷: 처음부터 끝까지 스크롤해 이어 붙인 뒤 PNG, JPG 또는 PDF로 만듭니다. 원하는 영역만 선택할 수도 있습니다.
- 영역 녹화: 화면의 일부를 GIF, MP4 또는 WebM 클립으로 만듭니다.
- 표를 스프레드시트로: 실시간 표를 Excel이나 CSV로 내보내며, 계속 갱신되는 표의 이전 상태도 포함됩니다.
- 오프라인 사본: 사이트를 인터넷 없이 열리는 HTML 문서 하나로 보관합니다.
- 색상 선택기: 화면의 어떤 색이든 골라 HEX, RGB 또는 HSL로 복사합니다.

## 시작하는 방법
1. 작업할 웹사이트를 엽니다.
2. F12(Mac에서는 Option + Command + I)를 누르고 Source Download 탭을 선택합니다. 보이지 않으면 탭 표시줄 끝의 »를 클릭하세요.
3. 로딩되는 동안 패널을 열어 두면 빠짐없이 담깁니다.

스크린샷과 녹화, 색상 선택기는 오른쪽 클릭 메뉴와 확장 프로그램 버튼에서도 쓸 수 있습니다.

## 설치 및 빠른 시작

### 방법 1: Chrome 웹 스토어에서 바로 설치 (권장)
1. 공식 [Source Download Chrome 웹 스토어 페이지](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd)를 방문하세요.
2. **Chrome에 추가**를 클릭하고 권한을 허용하세요.
3. Chrome DevTools(`F12` 또는 macOS에서는 `Ctrl+Shift+I` / `Cmd+Option+I`)를 열고 **Source Download** 탭을 클릭하거나, 페이지의 아무 곳에서나 마우스 오른쪽 버튼을 클릭하세요.

### 방법 2: 소스에서 압축 해제된 확장 프로그램 로드 (개발자 모드)
1. 공식 GitHub 저장소를 복제하세요:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome을 열고 `chrome://extensions`로 이동하세요.
3. 오른쪽 상단의 **개발자 모드** 토글을 켜세요.
4. **압축해제된 확장 프로그램을 로드합니다**를 클릭하고 복제한 `source-download` 프로젝트 폴더를 선택하세요.
