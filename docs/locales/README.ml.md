Source Download എന്നത് ഒരു വെബ് പേജ് ലോഡ് ചെയ്യുന്ന എല്ലാ റിസോഴ്സുകളും കണ്ടെത്തുകയും പരിശോധിക്കുകയും ഡൗൺലോഡ് ചെയ്യുകയും ചെയ്യുന്ന Chrome DevTools പാനലാണ്. മീഡിയ ഫയലുകളോ ഡെവലപ്പർ സ്ക്രിപ്റ്റുകളോ സ്റ്റൈൽ അസറ്റുകളോ നെറ്റ്‌വർക്ക് പ്രതികരണങ്ങളോ ആവശ്യമായാലും, അവ വ്യക്തിഗത ഫയലുകളായോ ഫോൾഡർ ഘടനയുള്ള ചിട്ടയായ ZIP ആയോ സേവ് ചെയ്യാം.

മൂന്നാം കക്ഷി ആശ്രയങ്ങളൊന്നുമില്ലാതെ തുടക്കം മുതൽ നിർമ്മിച്ചത്: ZIP റൈറ്റർ, XLSX ബിൽഡർ, HLS മെർജർ, കോഡ് ഫോർമാറ്ററുകൾ എന്നിവയെല്ലാം കൈകൊണ്ട് എഴുതിയ വാനില്ല JavaScript ആണ്. ഫ്രെയിംവർക്കുകളില്ല, ബിൽഡ് സ്റ്റെപ്പില്ല, ടെലിമെട്രിയില്ല. എല്ലാം നിങ്ങളുടെ ബ്രൗസറിൽ ലോക്കലായി പ്രവർത്തിക്കുന്നു.

## v1.16.0 ലെ പുതിയ കാര്യങ്ങൾ
- DevTools, സ്റ്റോർ എന്നിവയുടെ പൂർണ്ണ ലോക്കലൈസേഷനോടെ 54 ഭാഷകളിൽ പൂർണ്ണ ബഹുഭാഷാ പിന്തുണ.
- എല്ലാ മീഡിയയും കോഡും API-കളും സ്റ്റോറേജും ഡോക്യുമെന്റുകളും ഉൾക്കൊള്ളുന്ന, തത്സമയ എണ്ണമുള്ള 17 പ്രത്യേക അസറ്റ് വിഭാഗങ്ങൾ.
- സ്മാർട്ട് സ്റ്റിക്കി ഹെഡർ ഒഴിവാക്കലോടെ പേജ് മുഴുവനുള്ള സ്റ്റിച്ച് ചെയ്ത സ്ക്രീൻഷോട്ടുകളും ഇഷ്ടാനുസൃത ഏരിയ ക്യാപ്ചറും.
- സ്ക്രീൻ വീഡിയോ റെക്കോർഡിംഗും (MP4) അരികുകളിൽ ചോർച്ചയില്ലാത്ത ഭാരം കുറഞ്ഞ ആനിമേറ്റഡ് GIF എക്സ്പോർട്ട് എഞ്ചിനും.
- DOM Zapper ഘടകം നീക്കംചെയ്യൽ സഹിതം, തത്സമയ DOM ടേബിളുകളെ ഒന്നിലധികം ഷീറ്റുള്ള Microsoft Excel (.XLSX), CSV എന്നിവയിലേക്ക് മാറ്റുന്ന എക്‌സ്‌ട്രാക്ടർ.
- hex/rgb/hsl തൽക്ഷണം പകർത്താവുന്ന സ്ക്രീൻ കളർ ഐഡ്രോപ്പർ ടൂളും സംയോജിത കോഡ് ബ്യൂട്ടിഫയറും.
- മെച്ചപ്പെടുത്തിയ DevTools സ്നിഫർ സ്ഥിരതയും ഉയർന്ന കൺകറൻസിയുള്ള നെറ്റ്‌വർക്ക് പൈപ്പ്‌ലൈനും.

## എന്തുകൊണ്ട് നിങ്ങൾക്കിത് വേണം
സ്ക്രീൻഷോട്ട് മതിയാകില്ല. യഥാർത്ഥ ഫയലുകൾ നേടൂ: പൂർണ്ണ റെസല്യൂഷൻ ചിത്രങ്ങൾ, യഥാർത്ഥ വീഡിയോ സ്ട്രീമുകൾ, ഒറിജിനൽ സ്റ്റൈൽഷീറ്റുകളും സ്ക്രിപ്റ്റുകളും — പരത്തിയ ഒരു ചിത്രമല്ല.

DevTools ബുദ്ധിമുട്ടായി തോന്നും. അതേ നെറ്റ്‌വർക്ക് ഡാറ്റയ്ക്ക് മുന്നിൽ, തിരയൽ, ഫിൽട്ടറുകൾ, ഒറ്റ ക്ലിക്ക് ഡൗൺലോഡുകൾ എന്നിവയോടെ വൃത്തിയുള്ള, വിഭാഗം തിരിച്ച ഗാലറി Source Download നൽകുന്നു.

SPA-കൾ എല്ലാം മറയ്ക്കുന്നു. ഡൈനാമിക് ആപ്പുകൾ പേജ് സോഴ്സിൽ നിങ്ങൾ ഒരിക്കലും കാണാത്ത അസറ്റുകളും API കോളുകളും സൃഷ്ടിക്കുന്നു. ഇടക്കാല അവസ്ഥകളടക്കം അവ സംഭവിക്കുമ്പോൾ തന്നെ Source Download ക്യാപ്ചർ ചെയ്യുന്നു.

## ഇത് എന്തു ചെയ്യുന്നു
### എല്ലാം കണ്ടെത്തുക
- മീഡിയ ഫയലുകൾ, സ്ക്രിപ്റ്റുകൾ, സ്റ്റൈൽഷീറ്റുകൾ, എംബെഡ് ചെയ്ത ഫ്രെയിമുകൾ എന്നിവയുൾപ്പെടെ എല്ലാ ദൃശ്യ, ഘടനാ ഘടകങ്ങൾക്കുമായി നെറ്റ്‌വർക്ക് ക്യാപ്ചറും (HAR + തത്സമയ അഭ്യർത്ഥനകൾ) DOM സ്കാനും സംയോജിപ്പിക്കുന്നു.
- **CSS-അവബോധമുള്ളത്:** url(...), @import നിയമങ്ങൾക്കുള്ളിലെ അസറ്റുകൾ ആവർത്തനക്രമത്തിൽ പിന്തുടരുന്നതിനാൽ ഇമ്പോർട്ട് ചെയ്ത സ്റ്റൈൽഷീറ്റുകളിൽ ഒളിഞ്ഞിരിക്കുന്ന ഫോണ്ടുകൾ പോലും കണ്ടെത്തുന്നു.
- **കണ്ടന്റ് സ്നിഫിംഗ്:** അജ്ഞാത ഫയലുകളുടെ ഏതാനും ബൈറ്റുകൾ തിരികെ വായിച്ച് അവയുടെ യഥാർത്ഥ ഫയൽ തരം വിഭാഗത്തിലേക്ക് മാറ്റുന്നു.
- **തത്സമയ എണ്ണമുള്ള 17 വിഭാഗങ്ങൾ:** ക്യാപ്ചർ ചെയ്ത അസറ്റുകൾ മീഡിയ, കോഡ്, ഡാറ്റ, API കോളുകൾ, കുക്കികൾ, സ്റ്റോറേജ്, ഡോക്യുമെന്റുകൾ എന്നിവയ്ക്കുള്ള പ്രത്യേക ടാബുകളിൽ ചിട്ടയായി ക്രമീകരിക്കുന്നു.

### ഫിൽട്ടർ ചെയ്യുക, തിരയുക, പരിശോധിക്കുക
- ഫയൽ പേരുകൾ, URL-കൾ, MIME തരങ്ങൾ, alt ടെക്സ്റ്റ്, ഫയൽ ഉള്ളടക്കം എന്നിവയിൽ പോലും regex അടിസ്ഥാനമാക്കിയ തിരയൽ.
- **ഓരോ വിഭാഗത്തിനുമുള്ള ഫിൽട്ടറുകൾ:** കുറഞ്ഞ/കൂടിയ വലുപ്പം, മീഡിയയ്ക്ക് കുറഞ്ഞ/കൂടിയ വീതിയും ഉയരവും — ഉദാഹരണത്തിന് "≥ 1200px ഉള്ള ഹീറോ ചിത്രങ്ങൾ മാത്രം". API കോളുകൾ HTTP രീതിയും അഭ്യർത്ഥന തരവും അനുസരിച്ച് ഫിൽട്ടർ ചെയ്യാം.
- ലിസ്റ്റ് അല്ലെങ്കിൽ ഗ്രിഡ് കാഴ്ച, ക്രമീകരിക്കാവുന്നത്, തത്സമയ തംബ്‌നെയിൽ വാളോടെ.
- **യഥാർത്ഥ പ്രിവ്യൂകളുള്ള മൾട്ടി-ടാബ് ഇൻസ്പെക്ടർ:** സൂം ചെയ്യാവുന്ന ലൈറ്റ്ബോക്സ്, വീഡിയോ, ഓഡിയോ പ്ലേബാക്ക്, തത്സമയ ഫോണ്ട് സ്പെസിമെൻ, SVG വ്യൂവർ, ലൈൻ നമ്പറുകളോടെ സിന്റാക്സ് ഹൈലൈറ്റ് ചെയ്ത കോഡ്, മനോഹരമാക്കുക ടോഗിൾ.
- **API സ്പ്ലിറ്റ് വ്യൂ:** ഇടതുവശത്ത് പ്രതികരണം, വലതുവശത്ത് രീതി, സ്റ്റാറ്റസ്, ക്വറി പാരാമീറ്ററുകൾ, അഭ്യർത്ഥനാ ബോഡി.

### ശരിയായി ഡൗൺലോഡ് ചെയ്യുക
- ഡൗൺലോഡ് തിരഞ്ഞെടുത്തു — നിങ്ങൾ ചെക്ക് ചെയ്ത ഫയലുകൾ മാത്രം.
- ഡൗൺലോഡ് കാഴ്ച — നിലവിലെ ഫിൽട്ടറുകൾക്കും തിരയലിനും ശേഷം ദൃശ്യമാകുന്ന എല്ലാം.
- എല്ലാം ഡൗൺലോഡ് ചെയ്യുക — ക്യാപ്ചർ ചെയ്ത എല്ലാ റിസോഴ്സുകളും സ്വയമേവയുള്ള ഡീ-ഡ്യൂപ്ലിക്കേഷനോടെ ഫോൾഡർ ഘടനയുള്ള ZIP-ലേക്ക്.
- ബാച്ച് ഡൗൺലോഡുകൾ പരിമിത കൺകറൻസിയോടെയും തത്സമയ പ്രോഗ്രസ് ബാറോടെയും പ്രവർത്തിക്കുന്നു; പരാജയങ്ങൾ സ്വയമേവയും കോൺടെക്സ്റ്റ് മെനുവിൽ നിന്നും വീണ്ടും ശ്രമിക്കുന്നു.

### HLS, സങ്കീർണ്ണമായ വീഡിയോകൾ
- ബ്രൗസറിന് നേറ്റീവായി പ്ലേ ചെയ്യാനാകാത്ത സ്ട്രീമുകൾ (HLS .m3u8, DASH .mpd, അജ്ഞാത കോഡെക്കുകൾ) കറുത്ത പ്ലെയറിനു പകരം സ്മാർട്ട് ഫാൾബാക്ക് കാണിക്കുന്നു.
- സെഗ്‌മെൻ്റുകൾ ലയിപ്പിച്ച് ഡൗൺലോഡ് ചെയ്യുക എന്നത് ഒരു HLS സ്ട്രീമിനെ പാനലിൽ തന്നെ പ്ലേ ചെയ്യാവുന്ന ഒറ്റ ഫയലാക്കി മാറ്റുന്നു.

### വാചക വർക്ക്ബെഞ്ച് (SPA ഉള്ളടക്ക ടൂൾകിറ്റ്)
- **വാചകം ടാബ് ഒരു തത്സമയ ഉള്ളടക്ക വ്യൂവറാണ്:** തലക്കെട്ടുകൾ, ഖണ്ഡികകൾ, ലിസ്റ്റ് ഇനങ്ങൾ, ബട്ടണുകൾ, div, span എന്നിങ്ങനെ വാചകമുള്ള ഓരോ ഘടകവും DOM ക്രമത്തിൽ ക്യാപ്ചർ ചെയ്യുന്നു.
- ഡൈനാമിക് ടേബിളുകൾ പരിമിതമായ സ്നാപ്ഷോട്ട് ചരിത്രം സൂക്ഷിക്കുന്നു (ഉദാ. "8 സ്നാപ്ഷോട്ടുകൾ · 124 അദ്വിതീയ വരികൾ"), അതിനാൽ സ്വയം റിഫ്രഷ് ആകുന്ന ഡാഷ്‌ബോർഡുകൾക്ക് ഇടക്കാല അവസ്ഥകൾ നഷ്ടമാകില്ല.
- Markdown ആയി എക്സ്പോർട്ട് ചെയ്യുക, അല്ലെങ്കിൽ ടേബിളുകൾ CSV, HTML, അല്ലെങ്കിൽ ഞങ്ങളുടെ സ്വന്തം കൈകൊണ്ട് എഴുതിയ XLSX റൈറ്റർ നിർമ്മിക്കുന്ന യഥാർത്ഥ ഒന്നിലധികം ഷീറ്റുള്ള XLSX വർക്ക്ബുക്ക് ആയി.

## എങ്ങനെ ഉപയോഗിക്കാം
1. Source Download ഇൻസ്റ്റാൾ ചെയ്യുക, തുടർന്ന് ഏതെങ്കിലും പേജിൽ F12 അമർത്തുക.
2. DevTools ടൂൾബാറിലെ Source Download ടാബിൽ ക്ലിക്ക് ചെയ്യുക (എക്സ്റ്റൻഷനുകൾക്ക് DevTools സ്വയം തുറക്കാൻ Chrome അനുവദിക്കുന്നില്ല — അതുകൊണ്ടാണ് ഇത് അവിടെ ഉള്ളത്).
3. വിഭാഗ ടാബുകൾ ബ്രൗസ് ചെയ്യുക, തിരയുക, ഫിൽട്ടർ ചെയ്യുക, വലതുവശത്തെ പാനലിൽ എന്തും പരിശോധിക്കുക.
4. ആവശ്യമുള്ള ഫയലുകൾ ചെക്ക് ചെയ്ത് ഡൗൺലോഡ് തിരഞ്ഞെടുത്തു, ഡൗൺലോഡ് കാഴ്ച അല്ലെങ്കിൽ എല്ലാം ഡൗൺലോഡ് ചെയ്യുക അമർത്തുക.
5. എല്ലാ നെറ്റ്‌വർക്ക് അഭ്യർത്ഥനകളും ക്യാപ്ചർ ചെയ്യാൻ പേജ് ലോഡ് ചെയ്യുമ്പോൾ DevTools പാനൽ തുറന്നു വയ്ക്കുക.

## യഥാർത്ഥ ഉപയോഗ സാഹചര്യങ്ങൾ
- **എതിരാളി വിശകലനം:** ഏതെങ്കിലും ചാനലിലെ വീഡിയോ തംബ്‌നെയിലുകൾ — കുറഞ്ഞ വീതി ഫിൽട്ടറോടെ — ഒരു ഫോൾഡറിലേക്ക് ശേഖരിക്കുക.
- **കോഡ് ഇല്ലാതെ വെബ് സ്ക്രാപ്പിംഗ്:** ഒരു SPA-യുടെ API കോളുകൾ നിരീക്ഷിക്കുക, ആവശ്യമുള്ള എൻഡ്‌പോയിന്റിലേക്ക് ഫിൽട്ടർ ചെയ്യുക, അതിന്റെ കൃത്യമായ JSON പ്രതികരണങ്ങൾ ഡൗൺലോഡ് ചെയ്യുക.
- **ടൈപ്പോഗ്രഫി വിശകലനം:** ഒരു സൈറ്റ് യഥാർത്ഥത്തിൽ ഉപയോഗിക്കുന്ന ഫോണ്ട് കണ്ടെത്തി യഥാർത്ഥ ഫോണ്ട് ഫയലുകൾ നേടുക.
- **ബഗ് പുനഃസൃഷ്ടിക്കൽ:** ബഗ് ഉണ്ടായപ്പോൾ പുറത്തിറങ്ങിയ കൃത്യമായ CSS/JS പതിപ്പുകൾ സൂക്ഷിക്കുക.
- **ഡാഷ്‌ബോർഡ് ഡാറ്റ എക്സ്പോർട്ട്:** സ്വയം റിഫ്രഷ് ആകുന്ന ടേബിൾ ചരിത്രം ഉൾപ്പെടെ ഒന്നിലധികം ഷീറ്റുള്ള Excel വർക്ക്ബുക്കിലേക്ക് എക്സ്പോർട്ട് ചെയ്യുക.
- **QA പരിശോധന:** ഓരോ A/B കോൺഫിഗറേഷനിലും ഏത് വീഡിയോ/ഓഡിയോ വകഭേദമാണ് നൽകുന്നതെന്ന് പരിശോധിക്കുക.

### രീതി 1: Chrome Web Store-ൽ നിന്ന് നേരിട്ട് ഇൻസ്റ്റാൾ ചെയ്യുക (ശുപാർശ ചെയ്യുന്നത്)
1. ഔദ്യോഗിക [Source Download Chrome Web Store പേജ്](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd) സന്ദർശിക്കുക.
2. **Chrome-ലേക്ക് ചേർക്കുക** ക്ലിക്ക് ചെയ്ത് അനുമതികൾ നൽകുക.
3. Chrome DevTools തുറക്കുക (`F12` അല്ലെങ്കിൽ macOS-ൽ `Ctrl+Shift+I` / `Cmd+Option+I`) ശേഷം **Source Download** ടാബിൽ ക്ലിക്ക് ചെയ്യുക, അല്ലെങ്കിൽ പേജിൽ എവിടെയെങ്കിലും റൈറ്റ്-ക്ലിക്ക് ചെയ്യുക.

### രീതി 2: സോഴ്സിൽ നിന്ന് അൺപാക്ക് ചെയ്ത എക്സ്റ്റൻഷൻ ലോഡ് ചെയ്യുക (ഡെവലപ്പർ മോഡ്)
1. ഔദ്യോഗിക GitHub റിപ്പോസിറ്ററി ക്ലോൺ ചെയ്യുക:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome തുറന്ന് `chrome://extensions` എന്നതിലേക്ക് പോകുക.
3. മുകളിൽ വലതുവശത്തെ മൂലയിലെ **ഡെവലപ്പർ മോഡ്** ടോഗിൾ ഓണാക്കുക.
4. **അൺപാക്ക് ചെയ്തത് ലോഡ് ചെയ്യുക** ക്ലിക്ക് ചെയ്ത് ക്ലോൺ ചെയ്ത `source-download` പ്രോജക്റ്റ് ഫോൾഡർ തിരഞ്ഞെടുക്കുക.
