สร้างขึ้นจากศูนย์โดยไม่พึ่งพาไลบรารีของบุคคลที่สาม: ตัวเขียน ZIP ตัวสร้าง XLSX ตัวรวม HLS และตัวจัดรูปแบบโค้ด ล้วนเป็น JavaScript ล้วน ๆ ที่เขียนด้วยมือทั้งหมด ไม่มีเฟรมเวิร์ก ไม่มีขั้นตอนบิลด์ ไม่มีเทเลเมทรี ทุกอย่างทำงานในเครื่องของคุณผ่านเบราว์เซอร์

## มีอะไรใหม่ใน v1.16.0
- รองรับหลายภาษาเต็มรูปแบบ 54 ภาษา พร้อมการแปล DevTools และหน้าร้านค้าครบถ้วน
- 17 หมวดหมู่ทรัพยากรเฉพาะพร้อมตัวนับสด ครอบคลุมสื่อ โค้ด API ที่เก็บข้อมูล และเอกสารทั้งหมด
- ภาพหน้าจอเต็มหน้าแบบเย็บต่อและการจับภาพพื้นที่ที่กำหนดเอง พร้อมการระงับส่วนหัวแบบติดหนึบอย่างชาญฉลาด
- การบันทึกวิดีโอหน้าจอ (MP4) และเอนจินส่งออก GIF แบบเคลื่อนไหวน้ำหนักเบาโดยไม่มีขอบเกิน
- ตัวดึงตาราง DOM สดไปยัง Microsoft Excel (.XLSX) หลายชีต และ CSV พร้อมตัวลบองค์ประกอบ DOM Zapper
- เครื่องมือเลือกสีบนหน้าจอ คัดลอก hex/rgb/hsl ได้ทันที พร้อมตัวจัดรูปแบบโค้ดในตัว
- เพิ่มความเสถียรของ sniffer ใน DevTools และไปป์ไลน์เครือข่ายที่รองรับการทำงานพร้อมกันสูง

## ทำไมคุณถึงต้องใช้
ภาพหน้าจอไม่เพียงพอ รับไฟล์จริง — รูปภาพความละเอียดเต็ม สตรีมวิดีโอจริง สไตล์ชีตและสคริปต์ต้นฉบับ — ไม่ใช่ภาพแบนราบ

DevTools ดูซับซ้อนเกินไป Source Download แสดงข้อมูลเครือข่ายชุดเดียวกันในแกลเลอรีที่สะอาดตาและแบ่งตามหมวดหมู่ พร้อมการค้นหา ตัวกรอง และดาวน์โหลดคลิกเดียว

SPA ซ่อนทุกอย่าง แอปแบบไดนามิกสร้างทรัพยากรและการเรียก API ที่คุณไม่เคยเห็นในซอร์สของหน้า Source Download จับสิ่งเหล่านั้นได้ทันทีที่เกิดขึ้น รวมถึงสถานะระหว่างทาง

## ทำอะไรได้บ้าง
### ค้นพบทุกอย่าง
- รวมการจับข้อมูลเครือข่าย (HAR + คำขอสด) เข้ากับการสแกน DOM สำหรับองค์ประกอบทางภาพและโครงสร้างทั้งหมด รวมถึงไฟล์สื่อ สคริปต์ สไตล์ชีต และเฟรมที่ฝังอยู่
- **เข้าใจ CSS:** ทรัพยากรภายใน url(...) และกฎ @import จะถูกติดตามแบบเรียกซ้ำ จึงพบแม้แต่ฟอนต์ที่ซ่อนอยู่ในสไตล์ชีตที่นำเข้า
- **ตรวจจับจากเนื้อหา:** ไฟล์ที่ไม่รู้จักจะถูกอ่านไม่กี่ไบต์แล้วจัดไปอยู่ในหมวดหมู่ประเภทไฟล์จริง
- **17 หมวดหมู่พร้อมตัวนับสด:** ทรัพยากรที่จับได้ถูกจัดเรียงอย่างเป็นระเบียบในแท็บเฉพาะสำหรับสื่อ โค้ด ข้อมูล การเรียก API คุกกี้ ที่เก็บข้อมูล และเอกสาร

### กรอง ค้นหา ตรวจสอบ
- ค้นหาด้วย Regex ในชื่อไฟล์ URL ประเภท MIME ข้อความ alt และแม้แต่เนื้อหาในไฟล์
- **ตัวกรองรายหมวดหมู่:** ขนาดต่ำสุด/สูงสุด และสำหรับสื่อมีความกว้างและความสูงต่ำสุด/สูงสุดด้วย — เช่น "เฉพาะภาพหลักที่ ≥ 1200px" การเรียก API กรองตามเมธอด HTTP และประเภทคำขอ
- มุมมองรายการหรือตาราง จัดเรียงได้ พร้อมกำแพงภาพขนาดย่อแบบสด
- **ตัวตรวจสอบหลายแท็บพร้อมตัวอย่างจริง:** ไลต์บ็อกซ์ที่ซูมได้ การเล่นวิดีโอและเสียง ตัวอย่างฟอนต์สด ตัวดู SVG โค้ดไฮไลต์ไวยากรณ์พร้อมเลขบรรทัด และสวิตช์จัดรูปแบบโค้ดให้สวย (Beautify)
- **มุมมองแยก API:** การตอบกลับทางซ้าย เมธอด สถานะ พารามิเตอร์คำค้น และเนื้อหาคำขอทางขวา

### ดาวน์โหลดอย่างถูกวิธี
- ดาวน์โหลดที่เลือก — เฉพาะไฟล์ที่คุณติ๊กเลือก
- ดาวน์โหลดมุมมอง — ทุกอย่างที่มองเห็นหลังใช้ตัวกรองและการค้นหาปัจจุบัน
- ดาวน์โหลดทั้งหมด — ทุกทรัพยากรที่จับได้ในไฟล์ ZIP ที่จัดโครงสร้างโฟลเดอร์พร้อมกำจัดไฟล์ซ้ำอัตโนมัติ
- การดาวน์โหลดแบบกลุ่มทำงานด้วยการทำงานพร้อมกันที่จำกัดและแถบความคืบหน้าสด รายการที่ล้มเหลวจะลองใหม่อัตโนมัติ และลองใหม่ได้จากเมนูบริบท

### HLS และวิดีโอที่ยุ่งยาก
- สตรีมที่เบราว์เซอร์เล่นเองไม่ได้ (HLS .m3u8, DASH .mpd, โคเดกที่ไม่รู้จัก) จะแสดงทางเลือกอัจฉริยะแทนเครื่องเล่นสีดำ
- รวมเซกเมนต์และดาวน์โหลด แปลงสตรีม HLS เป็นไฟล์เดียวที่เล่นได้ ภายในแผงนี้เลย

### พื้นที่ทำงานข้อความ (ชุดเครื่องมือเนื้อหา SPA)
- **แท็บข้อความคือตัวดูเนื้อหาสด:** ทุกองค์ประกอบที่มีข้อความ — หัวเรื่อง ย่อหน้า รายการ ปุ่ม div span — ถูกจับตามลำดับ DOM
- ตารางไดนามิกเก็บประวัติสแนปช็อตแบบจำกัด (เช่น "8 สแนปช็อต · 124 แถวที่ไม่ซ้ำ") แดชบอร์ดที่รีเฟรชอัตโนมัติจึงไม่สูญเสียสถานะระหว่างทาง
- ส่งออกเป็น Markdown หรือตารางเป็น CSV, HTML หรือเวิร์กบุ๊ก XLSX หลายชีตจริงที่สร้างโดยตัวเขียน XLSX ที่เราเขียนเอง

## วิธีใช้งาน
1. ติดตั้ง Source Download แล้วกด F12 บนหน้าเว็บใดก็ได้
2. คลิกแท็บ Source Download ในแถบเครื่องมือ DevTools (Chrome ไม่อนุญาตให้ส่วนขยายเปิด DevTools อัตโนมัติ — จึงต้องอยู่ที่นั่น)
3. เรียกดูแท็บหมวดหมู่ ค้นหา กรอง ตรวจสอบทุกอย่างในแผงด้านขวา
4. เลือกไฟล์ที่ต้องการแล้วกด ดาวน์โหลดที่เลือก ดาวน์โหลดมุมมอง หรือ ดาวน์โหลดทั้งหมด
5. เปิดแผง DevTools ไว้ขณะหน้าเว็บโหลดเพื่อจับทุกคำขอเครือข่าย

## กรณีใช้งานจริง
- **วิเคราะห์คู่แข่ง:** รวบรวมภาพขนาดย่อของวิดีโอจากช่องใดก็ได้ — พร้อมตัวกรองความกว้างขั้นต่ำ — ไว้ในโฟลเดอร์เดียว
- **สแครปเว็บโดยไม่ต้องเขียนโค้ด:** ดูการเรียก API ของ SPA กรองเอนด์พอยต์ที่ต้องการ แล้วดาวน์โหลดการตอบกลับ JSON ที่ตรงเป๊ะ
- **วิเคราะห์ไทโปกราฟี:** ดูว่าเว็บไซต์ใช้ฟอนต์อะไรจริง ๆ และรับไฟล์ฟอนต์จริง
- **จำลองบั๊ก:** เก็บ CSS/JS เวอร์ชันที่ใช้งานจริงตอนเกิดบั๊กไว้
- **ส่งออกข้อมูลแดชบอร์ด:** ส่งออกตารางที่รีเฟรชอัตโนมัติเป็นเวิร์กบุ๊ก Excel หลายชีต พร้อมประวัติ
- **ทดสอบ QA:** ตรวจสอบว่ามีการเสิร์ฟวิดีโอ/เสียงรุ่นใดในแต่ละการตั้งค่า A/B

## ความเป็นส่วนตัว
- ทำงานในเครื่อง 100% ไม่มีเซิร์ฟเวอร์ ไม่มีระบบวิเคราะห์ ไม่มีข้อมูลใดออกจากเครื่องของคุณ
- **ขอเฉพาะสิ่งที่จำเป็น:** ที่เก็บข้อมูล (การตั้งค่าของคุณ) คลิปบอร์ด (คัดลอก URL และสี) การดาวน์โหลด (บันทึกไฟล์ผ่าน Chrome) เมนูบริบท การเขียนสคริปต์ และการเข้าถึงโฮสต์ (เพื่อสแกนหน้าเว็บและดึงเนื้อหาไฟล์)
- ไฟล์ถูกบันทึกผ่านขั้นตอนดาวน์โหลดปกติของ Chrome — ไม่มีการดาวน์โหลดแบบเงียบ

## การติดตั้งและเริ่มต้นอย่างรวดเร็ว

### วิธีที่ 1: ติดตั้งโดยตรงจาก Chrome Web Store (แนะนำ)
1. เข้าชม[หน้า Source Download บน Chrome Web Store](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd)อย่างเป็นทางการ
2. คลิก **เพิ่มลงใน Chrome** และอนุญาตสิทธิ์
3. เปิด Chrome DevTools (`F12` หรือ `Ctrl+Shift+I` / `Cmd+Option+I` บน macOS) แล้วคลิกแท็บ **Source Download** หรือคลิกขวาที่ใดก็ได้บนหน้าเว็บ

### วิธีที่ 2: โหลดส่วนขยายที่ยังไม่ได้แพ็กจากซอร์ส (โหมดนักพัฒนา)
1. โคลนรีโพซิทอรี GitHub อย่างเป็นทางการ:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. เปิด Google Chrome แล้วไปที่ `chrome://extensions`
3. เปิดสวิตช์ **โหมดนักพัฒนาซอฟต์แวร์** ที่มุมขวาบน
4. คลิก **โหลดส่วนขยายที่ไม่ได้แพ็ก** แล้วเลือกโฟลเดอร์โปรเจกต์ `source-download` ที่โคลนมา
