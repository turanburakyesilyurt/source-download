## તમને તેની શા માટે જરૂર છે
સ્ક્રીનશૉટથી કામ નહીં ચાલે. અસલી ફાઇલો મેળવો — પૂર્ણ રિઝોલ્યુશનવાળી છબીઓ, વાસ્તવિક વીડિયો સ્ટ્રીમ, મૂળ સ્ટાઇલશીટ અને સ્ક્રિપ્ટ — સપાટ ચિત્ર નહીં.

DevTools ભારે લાગે છે. Source Download એ જ નેટવર્ક ડેટા સર્ચ, ફિલ્ટર અને એક-ક્લિક ડાઉનલોડ સાથે સ્વચ્છ, શ્રેણીબદ્ધ ગૅલરીમાં તમારી સામે મૂકે છે.

SPA બધું છુપાવે છે. ડાયનેમિક ઍપ એવી એસેટ અને API કૉલ બનાવે છે જે પેજ સોર્સમાં ક્યારેય દેખાતા નથી. Source Download તેને બનતાની સાથે જ કેપ્ચર કરે છે, વચગાળાની સ્થિતિઓ સહિત.

## તે શું કરે છે
### બધું શોધો
- નેટવર્ક કેપ્ચર (HAR + લાઇવ રિક્વેસ્ટ) ને બધા દૃશ્ય અને માળખાકીય એલિમેન્ટના DOM સ્કેન સાથે જોડે છે, જેમાં મીડિયા ફાઇલો, સ્ક્રિપ્ટ, સ્ટાઇલશીટ અને એમ્બેડ કરેલ ફ્રેમનો સમાવેશ થાય છે.
- **CSS-અવેર:** url(...) અને @import નિયમો અંદરની એસેટ રિકર્સિવ રીતે અનુસરાય છે, તેથી ઇમ્પોર્ટ કરેલ સ્ટાઇલશીટમાં છુપાયેલા ફોન્ટ પણ મળી આવે છે.
- **કન્ટેન્ટ સ્નિફિંગ:** અજાણી ફાઇલોના થોડા બાઇટ પાછા વાંચવામાં આવે છે અને તેમને તેમના વાસ્તવિક ફાઇલ પ્રકારની શ્રેણીમાં મૂકવામાં આવે છે.
- **17 લાઇવ-કાઉન્ટ કેટેગરી:** કેપ્ચર કરેલ એસેટ મીડિયા, કોડ, ડેટા, API કૉલ, કૂકી, સ્ટોરેજ અને દસ્તાવેજો માટેના સમર્પિત ટૅબમાં વ્યવસ્થિત ગોઠવાય છે.

### ફિલ્ટર કરો, શોધો, તપાસો
- ફાઇલનામ, URL, MIME પ્રકાર, alt ટેક્સ્ટ અને ફાઇલની સામગ્રીમાં પણ રેગેક્સ-આધારિત શોધ.
- **દરેક કેટેગરી માટે ફિલ્ટર:** ન્યૂનતમ/મહત્તમ કદ, અને મીડિયા માટે ન્યૂનતમ/મહત્તમ પહોળાઈ અને ઊંચાઈ પણ — દા.ત. "માત્ર ≥ 1200px ની હીરો છબીઓ". API કૉલ HTTP મેથડ અને રિક્વેસ્ટ પ્રકાર પ્રમાણે ફિલ્ટર થાય છે.
- લિસ્ટ અથવા ગ્રિડ વ્યૂ, સૉર્ટ કરી શકાય તેવું, લાઇવ થંબનેલ વૉલ સાથે.
- **સાચા પ્રીવ્યૂ સાથેનું મલ્ટી-ટૅબ ઇન્સ્પેક્ટર:** ઝૂમ થતું લાઇટબૉક્સ, વીડિયો અને ઑડિઓ પ્લેબૅક, લાઇવ ફોન્ટ સ્પેસિમેન, SVG વ્યૂઅર, લાઇન નંબર સાથે સિન્ટેક્સ-હાઇલાઇટ કરેલ કોડ અને સુશોભિત કરો ટૉગલ.
- **API સ્પ્લિટ વ્યૂ:** ડાબી બાજુ રિસ્પૉન્સ, જમણી બાજુ મેથડ, સ્ટેટસ, ક્વેરી પૅરામીટર અને રિક્વેસ્ટ બૉડી.

### યોગ્ય રીતે ડાઉનલોડ કરો
- પસંદ કરેલ ડાઉનલોડ કરો — માત્ર તમે ટિક કરેલી ફાઇલો.
- વ્યૂ ડાઉનલોડ કરો — હાલના ફિલ્ટર અને સર્ચ પછી દેખાતું બધું.
- બધા ડાઉનલોડ કરો — કેપ્ચર કરેલ દરેક સંસાધન, ઑટોમેટિક ડી-ડુપ્લિકેશન સાથે ફોલ્ડર-માળખાવાળી ZIP માં.
- બૅચ ડાઉનલોડ મર્યાદિત કન્કરન્સી અને લાઇવ પ્રોગ્રેસ બાર સાથે ચાલે છે; નિષ્ફળ ડાઉનલોડ આપમેળે અને કૉન્ટેક્સ્ટ મેનૂમાંથી ફરી પ્રયાસ કરાય છે.

### HLS અને મુશ્કેલ વીડિયો
- જે સ્ટ્રીમ બ્રાઉઝર જાતે ચલાવી શકતું નથી (HLS .m3u8, DASH .mpd, અજાણ્યા કોડેક), તેમના માટે કાળા પ્લેયરને બદલે સ્માર્ટ ફૉલબૅક દેખાય છે.
- સેગમેન્ટ મર્જ કરો અને ડાઉનલોડ કરો HLS સ્ટ્રીમને સીધા પેનલમાં એક જ ચાલી શકે તેવી ફાઇલમાં ફેરવે છે.

### ટેક્સ્ટ વર્કબેન્ચ (SPA કન્ટેન્ટ ટૂલકિટ)
- **ટેક્સ્ટ ટૅબ લાઇવ કન્ટેન્ટ વ્યૂઅર છે:** ટેક્સ્ટ ધરાવતો દરેક એલિમેન્ટ — હેડિંગ, ફકરા, લિસ્ટ આઇટમ, બટન, div, span — DOM ક્રમમાં કેપ્ચર થાય છે.
- ડાયનેમિક ટેબલ મર્યાદિત સ્નૅપશૉટ ઇતિહાસ રાખે છે (દા.ત. "8 સ્નૅપશૉટ · 124 અનન્ય હરોળ"), તેથી આપમેળે રિફ્રેશ થતા ડેશબોર્ડ ક્યારેય વચગાળાની સ્થિતિ ગુમાવતા નથી.
- Markdown તરીકે એક્સપોર્ટ કરો, અથવા ટેબલ CSV, HTML કે અમારા હાથથી લખેલ XLSX રાઇટર દ્વારા બનેલ સાચી મલ્ટી-શીટ XLSX વર્કબુક તરીકે.

- **ફક્ત જરૂરી પરવાનગીઓ જ માગે છે:** સ્ટોરેજ (તમારી પસંદગીઓ), ક્લિપબોર્ડ (URL અને રંગ કૉપિ કરવા), ડાઉનલોડ (Chrome દ્વારા ફાઇલો સેવ કરવા), કૉન્ટેક્સ્ટ મેનૂ, સ્ક્રિપ્ટિંગ અને હોસ્ટ ઍક્સેસ (પેજ સ્કેન કરવા અને ફાઇલની સામગ્રી મેળવવા).
- ફાઇલો Chrome ના સામાન્ય ડાઉનલોડ ફ્લો દ્વારા સેવ થાય છે — કોઈ છૂપા ડાઉનલોડ નહીં.

## જરૂરિયાતો
- Chrome 116 કે તેનાથી નવું (Manifest V3).
- શ્રેષ્ઠ પરિણામ ત્યારે મળે છે જ્યારે પેજ લોડ થતી વખતે પેનલ ખુલ્લું હોય, કારણ કે નેટવર્ક કેપ્ચર ત્યારે જ થાય છે.

Source Download એક ઓપન-સોર્સ પ્રોજેક્ટ છે — પ્રતિસાદ, વિચારો અને પુલ રિક્વેસ્ટનું સ્વાગત છે.

## ઇન્સ્ટૉલેશન અને ઝડપી શરૂઆત

### પદ્ધતિ 1: Chrome Web Store પરથી સીધું ઇન્સ્ટૉલ કરો (ભલામણ કરેલ)
1. અધિકૃત [Source Download Chrome Web Store લિસ્ટિંગ](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd) ની મુલાકાત લો.
2. **Chrome માં ઉમેરો** પર ક્લિક કરો અને પરવાનગીઓ આપો.
3. Chrome DevTools ખોલો (`F12` અથવા `Ctrl+Shift+I` / macOS પર `Cmd+Option+I`) અને **Source Download** ટૅબ પર ક્લિક કરો, અથવા પેજ પર ગમે ત્યાં રાઇટ-ક્લિક કરો.

### પદ્ધતિ 2: સોર્સમાંથી અનપૅક્ડ એક્સ્ટેન્શન લોડ કરો (ડેવલપર મોડ)
1. અધિકૃત GitHub રિપોઝિટરી ક્લોન કરો:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome ખોલો અને `chrome://extensions` પર જાઓ.
3. ઉપર જમણા ખૂણામાં **ડેવલપર મોડ** ટૉગલ ચાલુ કરો.
4. **અનપૅક્ડ લોડ કરો** પર ક્લિક કરો અને ક્લોન કરેલ `source-download` પ્રોજેક્ટ ફોલ્ડર પસંદ કરો.
