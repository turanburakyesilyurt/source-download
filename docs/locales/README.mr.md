- ऑफलाइन प्रत: साइट इंटरनेटशिवाय उघडणाऱ्या एका HTML दस्तऐवजाच्या रूपात ठेवा.
- कलर पिकर: दिसणारा कोणताही रंग निवडा आणि तो HEX, RGB किंवा HSL म्हणून कॉपी करा.

## सुरुवात कशी करावी
1. ज्या साइटवर काम करायचे आहे ती उघडा.
2. F12 दाबा (Mac वर Option + Command + I) आणि Source Download टॅब निवडा. तो दिसत नसल्यास टॅब बारच्या शेवटी » वर क्लिक करा.
3. लोड होत असताना पॅनेल उघडे ठेवा म्हणजे काहीही सुटणार नाही.

स्क्रीनशॉट, रेकॉर्डिंग आणि कलर पिकर राइट-क्लिक मेनू आणि एक्स्टेंशन बटणातूनही मिळतात.

## गोपनीयता

सर्व काही तुमच्या संगणकावर चालते. खाते किंवा विश्लेषण नाही, आणि तुम्ही ठेवलेले काहीही डेव्हलपरला पाठवले जात नाही. सेव्ह केलेल्या गोष्टी Chrome द्वारे तुमच्या नेहमीच्या डाउनलोड फोल्डरमध्ये जातात.

संसाधने शोधून आपले काम करण्यासाठी एक्स्टेंशनला तुम्ही भेट देत असलेल्या साइट्सचा प्रवेश लागतो.

कृपया कॉपीराइट आणि वापराच्या अटींचा आदर करा आणि वापरण्याची परवानगी असलेलीच सामग्री ठेवा.

## इन्स्टॉलेशन आणि जलद सुरुवात

### पद्धत 1: Chrome Web Store वरून थेट इन्स्टॉल करा (शिफारस केलेली)
1. अधिकृत [Source Download Chrome Web Store पृष्ठाला](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd) भेट द्या.
2. **Chrome मध्ये जोडा** वर क्लिक करा आणि परवानग्या द्या.
3. Chrome DevTools उघडा (`F12` किंवा `Ctrl+Shift+I` / macOS वर `Cmd+Option+I`) आणि **Source Download** टॅबवर क्लिक करा, किंवा पृष्ठावर कुठेही राइट-क्लिक करा.

### पद्धत 2: स्रोतावरून अनपॅक्ड एक्सटेन्शन लोड करा (डेव्हलपर मोड)
1. अधिकृत GitHub रेपॉझिटरी क्लोन करा:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome उघडा आणि `chrome://extensions` वर जा.
3. वरच्या उजव्या कोपऱ्यातील **डेव्हलपर मोड** टॉगल सुरू करा.
4. **अनपॅक्ड लोड करा** वर क्लिक करा आणि क्लोन केलेला `source-download` प्रकल्प फोल्डर निवडा.
