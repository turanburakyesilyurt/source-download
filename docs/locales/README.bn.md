- একটি আর্কাইভ: যা চান তাতে টিক দিন এবং গোছানো ফোল্ডার কাঠামোসহ একটি ZIP পান। যা ব্যর্থ হয় তা এক ক্লিকে আবার চেষ্টা করুন।
- পুরো পৃষ্ঠার স্ক্রিনশট: সবকিছু স্ক্রল করে PNG, JPG বা PDF-এ জোড়া লাগানো হয়। চাইলে শুধু একটি অংশও বেছে নিতে পারেন।
- অংশ রেকর্ডিং: দৃশ্যমান কোনো অংশকে GIF, MP4 বা WebM ক্লিপে পরিণত করুন।
- টেবিল থেকে স্প্রেডশিট: লাইভ টেবিল Excel বা CSV-তে এক্সপোর্ট করুন, হালনাগাদ হতে থাকা টেবিলের আগের অবস্থাসহ।
- অফলাইন কপি: একটি সাইটকে একক HTML নথি হিসেবে রাখুন, যা ইন্টারনেট ছাড়াই খোলে।
- কালার পিকার: দৃশ্যমান যেকোনো রং বেছে নিয়ে HEX, RGB বা HSL হিসেবে কপি করুন।

## কীভাবে শুরু করবেন
1. যে সাইটে কাজ করতে চান সেটি খুলুন।
2. F12 চাপুন (Mac-এ Option + Command + I) এবং Source Download ট্যাব বেছে নিন। দেখা না গেলে ট্যাব বারের শেষে » এ ক্লিক করুন।
3. লোড হওয়ার সময় প্যানেল খোলা রাখুন, যাতে কিছু বাদ না পড়ে।

স্ক্রিনশট, রেকর্ডিং ও কালার পিকার রাইট-ক্লিক মেনু এবং এক্সটেনশন বোতাম থেকেও পাওয়া যায়।

## গোপনীয়তা

সবকিছু আপনার কম্পিউটারেই চলে। কোনো অ্যাকাউন্ট বা অ্যানালিটিক্স নেই, আর আপনার রাখা কিছুই ডেভেলপারের কাছে পাঠানো হয় না। সংরক্ষিত আইটেম Chrome-এর মাধ্যমে আপনার স্বাভাবিক ডাউনলোড ফোল্ডারে যায়।

এক্সটেনশনটির দেখা সাইটগুলোতে প্রবেশাধিকার দরকার, যাতে সেগুলোর রিসোর্স খুঁজে নিজের কাজ করতে পারে।

অনুগ্রহ করে কপিরাইট ও ব্যবহারের শর্ত মেনে চলুন এবং শুধু সেই বিষয়বস্তু রাখুন যা ব্যবহারের অনুমতি আপনার আছে।

## ইনস্টলেশন ও দ্রুত শুরু

### পদ্ধতি 1: Chrome ওয়েব স্টোর থেকে সরাসরি ইনস্টল (প্রস্তাবিত)
1. অফিসিয়াল [Source Download Chrome ওয়েব স্টোর পেজ](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd) দেখুন।
2. **Chrome-এ যোগ করুন**-এ ক্লিক করুন এবং অনুমতি দিন।
3. Chrome DevTools খুলুন (`F12` বা macOS-এ `Ctrl+Shift+I` / `Cmd+Option+I`) এবং **Source Download** ট্যাবে ক্লিক করুন, অথবা পেজের যেকোনো জায়গায় রাইট-ক্লিক করুন।

### পদ্ধতি 2: সোর্স থেকে আনপ্যাকড এক্সটেনশন লোড করুন (ডেভেলপার মোড)
1. অফিসিয়াল GitHub রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome খুলে `chrome://extensions`-এ যান।
3. উপরের ডান কোণে **ডেভেলপার মোড** টগল চালু করুন।
4. **আনপ্যাকড লোড করুন**-এ ক্লিক করুন এবং ক্লোন করা `source-download` প্রজেক্ট ফোল্ডারটি নির্বাচন করুন।
