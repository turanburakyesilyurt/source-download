Source Download ವೆಬ್ ವಿಷಯವನ್ನು ಉಳಿಸಲು ಉಪಕರಣಗಳ ಒಂದು ಸಂಗ್ರಹ. ಇದು Chrome ಡೆವಲಪರ್ ಟೂಲ್ಸ್‌ಗೆ ತನ್ನದೇ ಟ್ಯಾಬ್ ಸೇರಿಸುತ್ತದೆ. ಅಲ್ಲಿ ಸೈಟ್ ಲೋಡ್ ಮಾಡಿದ ಎಲ್ಲವೂ ವರ್ಗಗಳಾಗಿ ಜೋಡಣೆಯಾಗುತ್ತದೆ. ಹೀಗೆ ಮುನ್ನೋಟ ನೋಡಿ ಬೇಕಾದುದನ್ನು ಮಾತ್ರ ಇಟ್ಟುಕೊಳ್ಳಬಹುದು.

## ಮುಖ್ಯ ವೈಶಿಷ್ಟ್ಯಗಳು
- ವ್ಯವಸ್ಥಿತ ಗ್ಯಾಲರಿ: ಫೋಟೋಗಳು, ಐಕಾನ್‌ಗಳು ಮತ್ತು ಫಾಂಟ್‌ಗಳು ಲೈವ್ ಎಣಿಕೆ ಹಾಗೂ ಹುಡುಕಾಟ ಪೆಟ್ಟಿಗೆಯೊಂದಿಗೆ ತಮ್ಮದೇ ಟ್ಯಾಬ್‌ಗಳಲ್ಲಿ ಕಾಣಿಸುತ್ತವೆ.
- ನಿಖರ ಫಿಲ್ಟರ್‌ಗಳು: ನಿಗದಿತ ಕನಿಷ್ಠ ಅಗಲಕ್ಕಿಂತ (ಉದಾ. 1200 px) ಅಗಲವಾದ ಅಂಶಗಳನ್ನು ಮಾತ್ರ ತೋರಿಸಿ ಅಥವಾ ನಕಲುಗಳನ್ನು ಮರೆಮಾಡಿ.
- ನಿಜವಾದ ಮುನ್ನೋಟ: ಗ್ರಾಫಿಕ್ಸ್ ದೊಡ್ಡದಾಗಿಸಿ ಮತ್ತು ಮೀಡಿಯಾ ಪ್ಲೇ ಮಾಡಿ. ಫಾಂಟ್ ಮಾದರಿ ಅಥವಾ ಸಿಂಟ್ಯಾಕ್ಸ್ ಬಣ್ಣದ ಕೋಡ್ ಕೂಡ ನೋಡಬಹುದು.
- ಒಂದು ಆರ್ಕೈವ್: ಬೇಕಾದುದನ್ನು ಗುರುತಿಸಿ ಅಚ್ಚುಕಟ್ಟಾದ ಫೋಲ್ಡರ್ ರಚನೆಯ ಒಂದೇ ZIP ಪಡೆಯಿರಿ. ವಿಫಲವಾದುದನ್ನು ಒಂದು ಕ್ಲಿಕ್‌ನಲ್ಲಿ ಮತ್ತೆ ಪ್ರಯತ್ನಿಸಿ.
- ಪೂರ್ಣ ಪುಟದ ಸ್ಕ್ರೀನ್‌ಶಾಟ್: ಎಲ್ಲವೂ ಸ್ಕ್ರೋಲ್ ಆಗಿ PNG, JPG ಅಥವಾ PDF ಆಗಿ ಜೋಡಣೆಯಾಗುತ್ತದೆ. ಒಂದೇ ಭಾಗವನ್ನೂ ಆಯ್ಕೆ ಮಾಡಬಹುದು.
- ಭಾಗದ ರೆಕಾರ್ಡಿಂಗ್: ಕಾಣುವ ಯಾವುದೇ ಭಾಗವನ್ನು GIF, MP4 ಅಥವಾ WebM ಕ್ಲಿಪ್ ಆಗಿ ಬದಲಿಸಿ.
- ಕೋಷ್ಟಕದಿಂದ ಸ್ಪ್ರೆಡ್‌ಶೀಟ್‌ಗೆ: ಲೈವ್ ಕೋಷ್ಟಕಗಳನ್ನು Excel ಅಥವಾ CSV ಗೆ ರಫ್ತು ಮಾಡಿ, ನವೀಕರಣಗೊಳ್ಳುವ ಕೋಷ್ಟಕಗಳ ಹಿಂದಿನ ಸ್ಥಿತಿಗಳ ಸಹಿತ.
- ಆಫ್‌ಲೈನ್ ಪ್ರತಿ: ಸೈಟ್ ಅನ್ನು ಇಂಟರ್ನೆಟ್ ಇಲ್ಲದೆ ತೆರೆಯುವ ಒಂದೇ HTML ದಾಖಲೆಯಾಗಿ ಇಟ್ಟುಕೊಳ್ಳಿ.
- ಬಣ್ಣ ಆಯ್ಕೆಗಾರ: ಕಾಣುವ ಯಾವುದೇ ಬಣ್ಣವನ್ನು ಆರಿಸಿ HEX, RGB ಅಥವಾ HSL ಆಗಿ ನಕಲಿಸಿ.

## ಪ್ರಾರಂಭಿಸುವುದು ಹೇಗೆ
1. ನೀವು ಕೆಲಸ ಮಾಡಲು ಬಯಸುವ ಸೈಟ್ ತೆರೆಯಿರಿ.
2. F12 ಒತ್ತಿ (Mac ನಲ್ಲಿ Option + Command + I) ಮತ್ತು Source Download ಟ್ಯಾಬ್ ಆರಿಸಿ. ಕಾಣದಿದ್ದರೆ ಟ್ಯಾಬ್ ಬಾರ್ ಕೊನೆಯ » ಕ್ಲಿಕ್ ಮಾಡಿ.
3. ಲೋಡ್ ಆಗುವಾಗ ಪ್ಯಾನಲ್ ತೆರೆದಿಡಿ, ಏನೂ ತಪ್ಪಿಹೋಗುವುದಿಲ್ಲ.

ಸ್ಕ್ರೀನ್‌ಶಾಟ್, ರೆಕಾರ್ಡಿಂಗ್ ಮತ್ತು ಬಣ್ಣ ಆಯ್ಕೆಗಾರ ರೈಟ್-ಕ್ಲಿಕ್ ಮೆನು ಹಾಗೂ ಎಕ್ಸ್‌ಟೆನ್ಷನ್ ಬಟನ್‌ನಲ್ಲೂ ಲಭ್ಯ.

## ಗೌಪ್ಯತೆ

ಎಲ್ಲವೂ ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲೇ ನಡೆಯುತ್ತದೆ. ಖಾತೆ ಅಥವಾ ವಿಶ್ಲೇಷಣೆ ಇಲ್ಲ, ಮತ್ತು ನೀವು ಉಳಿಸಿದ ಯಾವುದನ್ನೂ ಡೆವಲಪರ್‌ಗೆ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ. ಉಳಿಸಿದವು Chrome ಮೂಲಕ ನಿಮ್ಮ ಸಾಮಾನ್ಯ ಡೌನ್‌ಲೋಡ್ ಫೋಲ್ಡರ್‌ಗೆ ಹೋಗುತ್ತವೆ.

ಸಂಪನ್ಮೂಲಗಳನ್ನು ಹುಡುಕಿ ತನ್ನ ಕೆಲಸ ಮಾಡಲು ಎಕ್ಸ್‌ಟೆನ್ಷನ್‌ಗೆ ನೀವು ಭೇಟಿ ನೀಡುವ ಸೈಟ್‌ಗಳ ಪ್ರವೇಶ ಬೇಕು.

ದಯವಿಟ್ಟು ಹಕ್ಕುಸ್ವಾಮ್ಯ ಮತ್ತು ಬಳಕೆಯ ನಿಯಮಗಳನ್ನು ಗೌರವಿಸಿ, ಬಳಸಲು ಅನುಮತಿ ಇರುವ ವಿಷಯವನ್ನು ಮಾತ್ರ ಇಟ್ಟುಕೊಳ್ಳಿ.

- ಆಫ್‌ಲೈನ್ ಪ್ರತಿಗಳಲ್ಲಿ ಈಗ ಎಲ್ಲಾ ಫೋಟೋಗಳು, ಹಿನ್ನೆಲೆಗಳು ಮತ್ತು ಫಾಂಟ್‌ಗಳು ಇರುತ್ತವೆ.
- ದೀರ್ಘ HD ಕ್ಲಿಪ್‌ಗಳಲ್ಲೂ GIF ರೆಕಾರ್ಡಿಂಗ್ ಮೆಮೊರಿ ಮಿತಿಯೊಳಗೆ ಇರುತ್ತದೆ.
- ಹೊಸ ಸ್ವಾಗತ ಪುಟ ಮತ್ತು ಎಕ್ಸ್‌ಟೆನ್ಷನ್ ಬಟನ್‌ನಲ್ಲಿ ಶಾರ್ಟ್‌ಕಟ್‌ಗಳು.

## ಸ್ಥಾಪನೆ ಮತ್ತು ತ್ವರಿತ ಪ್ರಾರಂಭ

### ವಿಧಾನ 1: Chrome ವೆಬ್ ಸ್ಟೋರ್‌ನಿಂದ ನೇರ ಸ್ಥಾಪನೆ (ಶಿಫಾರಸು ಮಾಡಲಾಗಿದೆ)
1. ಅಧಿಕೃತ [Source Download Chrome ವೆಬ್ ಸ್ಟೋರ್ ಪಟ್ಟಿ](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd) ಗೆ ಭೇಟಿ ನೀಡಿ.
2. **Chrome ಗೆ ಸೇರಿಸಿ** ಕ್ಲಿಕ್ ಮಾಡಿ ಮತ್ತು ಅನುಮತಿಗಳನ್ನು ನೀಡಿ.
3. Chrome DevTools ತೆರೆಯಿರಿ (`F12` ಅಥವಾ macOS ನಲ್ಲಿ `Ctrl+Shift+I` / `Cmd+Option+I`) ಮತ್ತು **Source Download** ಟ್ಯಾಬ್ ಕ್ಲಿಕ್ ಮಾಡಿ, ಅಥವಾ ಪುಟದಲ್ಲಿ ಎಲ್ಲಿಯಾದರೂ ರೈಟ್-ಕ್ಲಿಕ್ ಮಾಡಿ.

### ವಿಧಾನ 2: ಮೂಲದಿಂದ ಅನ್‌ಪ್ಯಾಕ್ ಮಾಡಿದ ವಿಸ್ತರಣೆಯನ್ನು ಲೋಡ್ ಮಾಡಿ (ಡೆವಲಪರ್ ಮೋಡ್)
1. ಅಧಿಕೃತ GitHub ರೆಪೊಸಿಟರಿಯನ್ನು ಕ್ಲೋನ್ ಮಾಡಿ:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome ತೆರೆದು `chrome://extensions` ಗೆ ಹೋಗಿ.
3. ಮೇಲಿನ ಬಲ ಮೂಲೆಯಲ್ಲಿರುವ **ಡೆವಲಪರ್ ಮೋಡ್** ಟಾಗಲ್ ಅನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಿ.
4. **ಅನ್‌ಪ್ಯಾಕ್ ಮಾಡಿದುದನ್ನು ಲೋಡ್ ಮಾಡಿ** ಕ್ಲಿಕ್ ಮಾಡಿ ಮತ್ತು ಕ್ಲೋನ್ ಮಾಡಿದ `source-download` ಯೋಜನಾ ಫೋಲ್ಡರ್ ಆಯ್ಕೆಮಾಡಿ.
