## મુખ્ય સુવિધાઓ
- વ્યવસ્થિત ગેલેરી: ફોટા, આઇકન અને ફોન્ટ પોતપોતાની ટેબમાં લાઇવ ગણતરી અને શોધ બોક્સ સાથે દેખાય છે.
- ચોક્કસ ફિલ્ટર: નક્કી કરેલી ઓછામાં ઓછી પહોળાઈ (જેમ કે 1200 px)થી પહોળી વસ્તુઓ જ બતાવો અથવા ડુપ્લિકેટ છુપાવો.
- સાચું પૂર્વાવલોકન: ગ્રાફિક્સ મોટાં કરો અને મીડિયા ચલાવો. ફોન્ટનો નમૂનો કે સિન્ટેક્સ હાઇલાઇટ કરેલો કોડ પણ જોઈ શકો છો.
- એક આર્કાઇવ: જોઈતું પસંદ કરો અને સુઘડ ફોલ્ડર માળખાવાળી એક ZIP મેળવો. નિષ્ફળ થયેલું એક ક્લિકમાં ફરી અજમાવો.
- આખા પેજનો સ્ક્રીનશોટ: બધું સ્ક્રોલ થઈને PNG, JPG અથવા PDFમાં જોડાય છે. ફક્ત એક ભાગ પણ પસંદ કરી શકો છો.
- ભાગનું રેકોર્ડિંગ: દેખાતા કોઈ ભાગને GIF, MP4 અથવા WebM ક્લિપમાં ફેરવો.
- ટેબલથી સ્પ્રેડશીટ: લાઇવ ટેબલને Excel અથવા CSVમાં નિકાસ કરો, અપડેટ થતાં ટેબલની અગાઉની સ્થિતિઓ સહિત.
- ઓફલાઇન નકલ: સાઇટને એક HTML દસ્તાવેજ તરીકે રાખો જે ઇન્ટરનેટ વિના ખૂલે છે.
- કલર પિકર: દેખાતો કોઈપણ રંગ પસંદ કરી તેને HEX, RGB અથવા HSL તરીકે કૉપિ કરો.

## શરૂઆત કેવી રીતે કરવી
1. જે સાઇટ પર કામ કરવું છે તે ખોલો.
2. F12 દબાવો (Mac પર Option + Command + I) અને Source Download ટેબ પસંદ કરો. ન દેખાય તો ટેબ બારના છેડે » પર ક્લિક કરો.
3. લોડ થતી વખતે પેનલ ખુલ્લી રાખો જેથી કંઈ ચૂકાય નહીં.

સ્ક્રીનશોટ, રેકોર્ડિંગ અને કલર પિકર રાઇટ-ક્લિક મેનૂ અને એક્સ્ટેન્શન બટનમાંથી પણ મળે છે.

## ગોપનીયતા

બધું તમારા કમ્પ્યુટર પર ચાલે છે. કોઈ એકાઉન્ટ કે એનાલિટિક્સ નથી, અને તમે રાખેલું કંઈ ડેવલપરને મોકલાતું નથી. સાચવેલી વસ્તુઓ Chrome મારફતે તમારા સામાન્ય ડાઉનલોડ ફોલ્ડરમાં જાય છે.

એક્સ્ટેન્શનને જોયેલી સાઇટ્સની ઍક્સેસ જોઈએ, જેથી તે તેમનાં સંસાધનો શોધી પોતાનું કામ કરી શકે.

કૃપા કરીને કૉપિરાઇટ અને ઉપયોગની શરતોનું પાલન કરો અને ફક્ત એ જ સામગ્રી રાખો જે વાપરવાની તમને મંજૂરી છે.

- ઓફલાઇન નકલમાં હવે બધા ફોટા, બેકગ્રાઉન્ડ અને ફોન્ટ સામેલ છે.
- લાંબી HD ક્લિપમાં પણ GIF રેકોર્ડિંગ મેમરીની મર્યાદામાં રહે છે.
- નવું સ્વાગત પેજ અને એક્સ્ટેન્શન બટનમાં શૉર્ટકટ.

## ઇન્સ્ટૉલેશન અને ઝડપી શરૂઆત

### પદ્ધતિ 1: Chrome Web Store પરથી સીધું ઇન્સ્ટૉલ કરો (ભલામણ કરેલ)
1. અધિકૃત [Source Download Chrome Web Store લિસ્ટિંગ](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd) ની મુલાકાત લો.
2. **Chrome માં ઉમેરો** પર ક્લિક કરો અને પરવાનગીઓ આપો.
3. Chrome DevTools ખોલો (`F12` અથવા `Ctrl+Shift+I` / macOS પર `Cmd+Option+I`) અને **Source Download** ટૅબ પર ક્લિક કરો, અથવા પેજ પર ગમે ત્યાં રાઇટ-ક્લિક કરો.

### પદ્ધતિ 2: સોર્સમાંથી અનપૅક્ડ એક્સ્ટેન્શન લોડ કરો (ડેવલપર મોડ)
1. અધિકૃત GitHub રિપોઝિટરી ક્લોન કરો:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome ખોલો અને `chrome://extensions` પર જાઓ.
3. ઉપર જમણા ખૂણામાં **ડેવલપર મોડ** ટૉગલ ચાલુ કરો.
4. **અનપૅક્ડ લોડ કરો** પર ક્લિક કરો અને ક્લોન કરેલ `source-download` પ્રોજેક્ટ ફોલ્ડર પસંદ કરો.
