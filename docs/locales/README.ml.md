Source Download വെബ് ഉള്ളടക്കം സൂക്ഷിക്കാനുള്ള ടൂളുകളുടെ ഒരു കൂട്ടമാണ്. ഇത് Chrome ഡെവലപ്പർ ടൂളുകളിൽ സ്വന്തം ടാബ് ചേർക്കുന്നു. അവിടെ സൈറ്റ് ലോഡ് ചെയ്ത എല്ലാം വിഭാഗങ്ങളായി അടുക്കുന്നു. അതിനാൽ പ്രിവ്യൂ കണ്ട് ആവശ്യമുള്ളത് മാത്രം നിലനിർത്താം.

## പ്രധാന സവിശേഷതകൾ
- ചിട്ടയായ ഗാലറി: ഫോട്ടോകളും ഐക്കണുകളും ഫോണ്ടുകളും തത്സമയ എണ്ണവും തിരയൽ ബോക്സും സഹിതം സ്വന്തം ടാബുകളിൽ കാണാം.
- കൃത്യമായ ഫിൽട്ടറുകൾ: നിശ്ചിത കുറഞ്ഞ വീതിയേക്കാൾ (ഉദാ. 1200 px) വീതിയുള്ളവ മാത്രം കാണിക്കുക, അല്ലെങ്കിൽ തനിപ്പകർപ്പുകൾ മറയ്ക്കുക.
- യഥാർത്ഥ പ്രിവ്യൂ: ഗ്രാഫിക്സ് വലുതാക്കുകയും മീഡിയ പ്ലേ ചെയ്യുകയും ചെയ്യാം. ഫോണ്ട് മാതൃകയും സിന്റാക്സ് നിറമുള്ള കോഡും കാണാം.
- ഒരു ആർക്കൈവ്: വേണ്ടത് അടയാളപ്പെടുത്തി വൃത്തിയുള്ള ഫോൾഡർ ഘടനയുള്ള ഒരൊറ്റ ZIP നേടുക. പരാജയപ്പെട്ടവ ഒറ്റ ക്ലിക്കിൽ വീണ്ടും ശ്രമിക്കാം.
- പൂർണ്ണ പേജ് സ്ക്രീൻഷോട്ട്: എല്ലാം സ്ക്രോൾ ചെയ്ത് PNG, JPG അല്ലെങ്കിൽ PDF ആയി ചേർക്കുന്നു. ഒരു ഭാഗം മാത്രവും തിരഞ്ഞെടുക്കാം.
- ഭാഗം റെക്കോർഡിംഗ്: കാണുന്ന ഏതെങ്കിലും ഭാഗം GIF, MP4 അല്ലെങ്കിൽ WebM ക്ലിപ്പാക്കുക.
- പട്ടികയിൽ നിന്ന് സ്പ്രെഡ്ഷീറ്റിലേക്ക്: തത്സമയ പട്ടികകൾ Excel അല്ലെങ്കിൽ CSV ആയി കയറ്റുമതി ചെയ്യുക, പുതുക്കുന്ന പട്ടികകളുടെ മുൻ നിലകൾ സഹിതം.
- ഓഫ്‌ലൈൻ പകർപ്പ്: ഇന്റർനെറ്റില്ലാതെ തുറക്കുന്ന ഒരൊറ്റ HTML രേഖയായി സൈറ്റ് സൂക്ഷിക്കുക.
- നിറം തിരഞ്ഞെടുക്കൽ: കാണുന്ന ഏത് നിറവും എടുത്ത് HEX, RGB അല്ലെങ്കിൽ HSL ആയി പകർത്തുക.

## എങ്ങനെ തുടങ്ങാം
1. ജോലി ചെയ്യേണ്ട സൈറ്റ് തുറക്കുക.
2. F12 അമർത്തുക (Mac-ൽ Option + Command + I), Source Download ടാബ് തിരഞ്ഞെടുക്കുക. കാണുന്നില്ലെങ്കിൽ ടാബ് ബാറിന്റെ അവസാനത്തെ » ക്ലിക്ക് ചെയ്യുക.
3. ലോഡ് ചെയ്യുമ്പോൾ പാനൽ തുറന്നുവയ്ക്കുക, ഒന്നും വിട്ടുപോകില്ല.

സ്ക്രീൻഷോട്ട്, റെക്കോർഡിംഗ്, നിറം തിരഞ്ഞെടുക്കൽ എന്നിവ റൈറ്റ്-ക്ലിക്ക് മെനുവിലും എക്സ്റ്റൻഷൻ ബട്ടണിലും ലഭ്യമാണ്.

## സ്വകാര്യത

എല്ലാം നിങ്ങളുടെ കമ്പ്യൂട്ടറിൽ തന്നെ പ്രവർത്തിക്കുന്നു. അക്കൗണ്ടോ അനലിറ്റിക്സോ ഇല്ല, നിങ്ങൾ സൂക്ഷിക്കുന്ന ഒന്നും ഡെവലപ്പർക്ക് അയയ്ക്കുന്നില്ല. സൂക്ഷിച്ചവ Chrome വഴി സാധാരണ ഡൗൺലോഡ് ഫോൾഡറിലേക്ക് പോകുന്നു.

ഉറവിടങ്ങൾ കണ്ടെത്താനും ജോലി ചെയ്യാനും എക്സ്റ്റൻഷന് നിങ്ങൾ സന്ദർശിക്കുന്ന സൈറ്റുകളിലേക്ക് ആക്‌സസ് വേണം.

ദയവായി പകർപ്പവകാശവും ഉപയോഗ നിബന്ധനകളും മാനിക്കുക, ഉപയോഗിക്കാൻ അനുമതിയുള്ള ഉള്ളടക്കം മാത്രം സൂക്ഷിക്കുക.

## ഇൻസ്റ്റലേഷനും ദ്രുത തുടക്കവും

### രീതി 1: Chrome Web Store-ൽ നിന്ന് നേരിട്ട് ഇൻസ്റ്റാൾ ചെയ്യുക (ശുപാർശ ചെയ്യുന്നത്)
1. ഔദ്യോഗിക [Source Download Chrome Web Store പേജ്](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd) സന്ദർശിക്കുക.
2. **Chrome-ലേക്ക് ചേർക്കുക** ക്ലിക്ക് ചെയ്ത് അനുമതികൾ നൽകുക.
3. Chrome DevTools തുറക്കുക (`F12` അല്ലെങ്കിൽ macOS-ൽ `Ctrl+Shift+I` / `Cmd+Option+I`) ശേഷം **Source Download** ടാബിൽ ക്ലിക്ക് ചെയ്യുക, അല്ലെങ്കിൽ പേജിൽ എവിടെയെങ്കിലും റൈറ്റ്-ക്ലിക്ക് ചെയ്യുക.

### രീതി 2: സോഴ്സിൽ നിന്ന് അൺപാക്ക് ചെയ്ത എക്സ്റ്റൻഷൻ ലോഡ് ചെയ്യുക (ഡെവലപ്പർ മോഡ്)
1. ഔദ്യോഗിക GitHub റിപ്പോസിറ്ററി ക്ലോൺ ചെയ്യുക:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chrome തുറന്ന് `chrome://extensions` എന്നതിലേക്ക് പോകുക.
3. മുകളിൽ വലതുവശത്തെ മൂലയിലെ **ഡെവലപ്പർ മോഡ്** ടോഗിൾ ഓണാക്കുക.
4. **അൺപാക്ക് ചെയ്തത് ലോഡ് ചെയ്യുക** ക്ലിക്ക് ചെയ്ത് ക്ലോൺ ചെയ്ത `source-download` പ്രോജക്റ്റ് ഫോൾഡർ തിരഞ്ഞെടുക്കുക.
