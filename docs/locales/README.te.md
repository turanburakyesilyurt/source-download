- క్రమమైన గ్యాలరీ: ఫోటోలు, ఐకాన్‌లు, ఫాంట్‌లు ప్రత్యక్ష లెక్కింపు మరియు శోధన పెట్టెతో వాటి సొంత ట్యాబ్‌లలో కనిపిస్తాయి.
- ఖచ్చితమైన ఫిల్టర్లు: నిర్ణీత కనీస వెడల్పు (ఉదా. 1200 px) కంటే వెడల్పైనవి మాత్రమే చూపండి లేదా నకిలీలను దాచండి.
- నిజమైన ప్రివ్యూ: గ్రాఫిక్స్‌ను పెద్దవి చేసి మీడియాను ప్లే చేయండి. ఫాంట్ నమూనా లేదా సింటాక్స్ రంగుల కోడ్ కూడా చూడవచ్చు.
- ఒకే ఆర్కైవ్: కావలసినవి గుర్తించి చక్కని ఫోల్డర్ నిర్మాణంతో ఒకే ZIP పొందండి. విఫలమైనవాటిని ఒక్క క్లిక్‌తో మళ్లీ ప్రయత్నించండి.
- పూర్తి పేజీ స్క్రీన్‌షాట్: అంతా స్క్రోల్ అయి PNG, JPG లేదా PDFగా జతపడుతుంది. ఒక భాగాన్ని మాత్రమే కూడా ఎంచుకోవచ్చు.
- భాగం రికార్డింగ్: కనిపించే ఏ భాగాన్నైనా GIF, MP4 లేదా WebM క్లిప్‌గా మార్చండి.
- పట్టిక నుండి స్ప్రెడ్‌షీట్‌కు: ప్రత్యక్ష పట్టికలను Excel లేదా CSVకి ఎగుమతి చేయండి, మారుతున్న పట్టికల గత స్థితులతో సహా.
- ఆఫ్‌లైన్ కాపీ: ఇంటర్నెట్ లేకుండా తెరుచుకునే ఒకే HTML పత్రంగా సైట్‌ను ఉంచుకోండి.
- రంగు ఎంపిక సాధనం: కనిపించే ఏ రంగునైనా ఎంచుకుని HEX, RGB లేదా HSLగా కాపీ చేయండి.

## ఎలా ప్రారంభించాలి
1. మీరు పని చేయాలనుకునే సైట్‌ను తెరవండి.
2. F12 నొక్కండి (Macలో Option + Command + I), Source Download ట్యాబ్‌ను ఎంచుకోండి. కనిపించకపోతే ట్యాబ్ బార్ చివర ఉన్న » క్లిక్ చేయండి.
3. లోడ్ అవుతున్నప్పుడు ప్యానెల్‌ను తెరిచే ఉంచండి, ఏదీ తప్పిపోదు.

స్క్రీన్‌షాట్, రికార్డింగ్, రంగు ఎంపిక సాధనం రైట్-క్లిక్ మెనూలోనూ ఎక్స్‌టెన్షన్ బటన్‌లోనూ ఉన్నాయి.

## గోప్యత

అంతా మీ కంప్యూటర్‌లోనే నడుస్తుంది. ఖాతా లేదా విశ్లేషణ లేదు, మీరు ఉంచుకున్నదేదీ డెవలపర్‌కు పంపబడదు. సేవ్ చేసినవి Chrome ద్వారా మీ సాధారణ డౌన్‌లోడ్‌ల ఫోల్డర్‌కు వెళ్తాయి.

వనరులను కనుగొని తన పనులు చేయడానికి ఎక్స్‌టెన్షన్‌కు మీరు సందర్శించే సైట్‌లకు యాక్సెస్ కావాలి.

దయచేసి కాపీరైట్‌ను, ఉపయోగ నిబంధనలను గౌరవించండి. ఉపయోగించేందుకు అనుమతి ఉన్న కంటెంట్‌ను మాత్రమే ఉంచుకోండి.

- ఆఫ్‌లైన్ కాపీల్లో ఇప్పుడు అన్ని ఫోటోలు, నేపథ్యాలు, ఫాంట్‌లు ఉంటాయి.

## ఇన్‌స్టాలేషన్, త్వరిత ప్రారంభం

### పద్ధతి 1: Chrome Web Store నుండి నేరుగా ఇన్‌స్టాల్ (సిఫార్సు)
1. అధికారిక [Source Download Chrome Web Store పేజీ](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd)ని సందర్శించండి.
2. **Chromeకు జోడించు** క్లిక్ చేసి అనుమతులు ఇవ్వండి.
3. Chrome DevToolsను తెరవండి (`F12` లేదా `Ctrl+Shift+I` / macOSలో `Cmd+Option+I`), **Source Download** ట్యాబ్‌ను క్లిక్ చేయండి లేదా పేజీలో ఎక్కడైనా రైట్-క్లిక్ చేయండి.

### పద్ధతి 2: సోర్స్ నుండి అన్‌ప్యాక్డ్ ఎక్స్‌టెన్షన్‌ను లోడ్ చేయండి (డెవలపర్ మోడ్)
1. అధికారిక GitHub రిపోజిటరీని క్లోన్ చేయండి:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chromeను తెరిచి `chrome://extensions`కు వెళ్లండి.
3. ఎగువ కుడి మూలలో **డెవలపర్ మోడ్** టోగుల్‌ను ఆన్ చేయండి.
4. **అన్‌ప్యాక్ చేసినది లోడ్ చేయండి** క్లిక్ చేసి, క్లోన్ చేసిన `source-download` ప్రాజెక్ట్ ఫోల్డర్‌ను ఎంచుకోండి.
