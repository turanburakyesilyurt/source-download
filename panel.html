Source Download — User Guide

Getting started

Click the Source Download tab in the DevTools toolbar (press F12 / Ctrl+Shift+I, then the tab in the DevTools toolbar). Chrome does not allow extensions to open DevTools automatically, which is why the panel lives there. The toolbar icon popup lets you choose which categories feed the badge counter on the icon. The sun/moon button in the panel toolbar locks a light or dark theme independently of Chrome; that choice is remembered.

Categories

The vertical tabs on the left group every captured resource by type: Images, Videos, Audio, Captions, Documents, Fonts, Source maps, WASM, SVG, APIs, and more. Each tab shows a live count. Only one category is shown at a time; switching resets all filters, so what you see always matches the tab.

Search & filters

The search bar filters by name, URL, type, alt text or title. Enclose your query in /…/ to use a regular expression, e.g. /\.(png|jpg)$/. Below the toolbar, the filter bar changes per category: size and dimension ranges for media, HTTP method and request type for APIs, plus sorting and direction.

Grid & list view

Toggle between a compact grid (small thumbnails) and a detailed list with the buttons next to the search bar. Your choice is remembered between sessions. In list view, checkboxes let you select individual resources for a bulk download.

Inspect a resource

Click any resource to open it in the inspect pane on the right. Each opened file becomes a tab, so you can compare several resources side by side — the newest opens on the left. Specialized viewers exist for images, video, audio, fonts, SVG, and text/code (with a Beautify toggle). APIs show a split view: response on the left, request details (method, status, headers, query parameters and body) on the right.

Downloading

Download View saves the currently visible resources (active category + search + filters) as a ZIP; it relabels to Download Filtered (N) when filters are active. Hover any download button to see an estimated archive size before you click. Download Selected downloads only the checked items. Download All captures every discovered resource into a folder-structured ZIP. Failed downloads are retried automatically and can be retried again from the context menu. Export writes the visible list as JSON or CSV, or dumps Chrome's network log as a HAR file.

Lightbox

The zoom button opens media in a full-size lightbox where you can pan by dragging, zoom with the mouse wheel, the on-screen buttons or the keyboard (+/- to zoom, 0 to reset, Esc to close).

Text & tables

The Text category is a live, readable copy of the page. It captures every element that holds text — headings, paragraphs, list items, buttons, div/span and more — in DOM order, and keeps scanning while Live is on.

The Query box works four ways, picked from the dropdown beside it: Contains and Regex filter the text already captured, while CSS selector and XPath are run against the live page so they can reach anything in the DOM. XPath also accepts expressions that return a value rather than elements, such as count(//a) or //@href. Whatever the page says about a broken query is shown next to the box. Element narrows the result to a single tag, with the count of each tag found on the page. Clearing the query box (or pressing Clear) returns you to All elements and recaptures the page — you never have to reset the dropdown by hand.

Reading hides tags, checkboxes and location crumbs so the stream reads like a document. Tables store a bounded history of snapshots so dynamic (SPA) tables are never lost. Press Show all rows on a table to merge every snapshot into one deduplicated view — that is exactly what an export contains. Export as TXT (the readable page), MD (Markdown, tables included), or tables as CSV, HTML or a real multi-sheet XLSX workbook. Checked items win; otherwise everything currently visible is exported.

Captions & subtitles

WebVTT, SRT, TTML and other caption files — including <track> sources — land in their own Captions tab instead of mixing with documents.

Source maps

.map files and JSON bodies that look like source maps (they contain mappings and sources) are grouped under Source maps, with the JSON viewer and Beautify, so they no longer clutter the JSON tab.

Duplicate images

On the Images tab the panel hashes captured bytes and marks identical files. A Hide duplicates filter keeps the first copy of each set so a ZIP of the view does not ship the same thumbnail twice.

Video fallback & HLS

Streams the browser cannot play natively (HLS .m3u8, DASH .mpd, unknown codecs) show a fallback instead of a black player. For HLS you can merge the segments into a single video file right from the panel, or download the original manifest.

Pro tips

Dynamic API responses (XHR/fetch) are not deduplicated by URL — each reply stays in the list (capped FIFO) so you can compare repeated requests. Static assets are deduplicated. Use Refresh to re-scan the current DOM, and reload the page while the panel is open to capture every network request, including ones triggered before you switched tabs.
