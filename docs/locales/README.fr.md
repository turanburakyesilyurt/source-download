## Message de l'auteur

Pendant des années, j'ai développé des automatisations de **scraping web**, d'**analyse de données** et de **flux de test QA**. L'avènement des applications monopages (SPA) a rendu les données visuelles difficiles à extraire facilement. C'est exactement pour résoudre ce besoin que j'ai conçu **Source Download**.

N'hésitez pas à échanger avec moi sur [**LinkedIn**](https://www.linkedin.com/in/turan-burak-yesilyurt/) ou à visiter [**2run.dev**](https://2run.dev).

> **Chrome Web Store:** [Installer Source Download depuis le Chrome Web Store](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd)

---

> **Philosophie open source & engagement zéro dépendance:** De nombreuses extensions s’appuient sur des bibliothèques externes lourdes. Source Download est conçu sans compromis : le **moteur ZIP**, le **générateur XLSX**, le **fusionneur HLS**, l’**encodeur GIF** et le **formateur de code** sont intégralement écrits à la main en JavaScript vanilla pur, sans framework, sans étape de build et sans télémétrie.

Parcourez, inspectez et téléchargez chaque ressource chargée par une page web en toute simplicité sous forme d'archive ZIP.

Source Download — Chaque ressource d'une page à portée de clic
Source Download est un panneau Chrome DevTools qui détecte, inspecte et télécharge toutes les ressources chargées par une page web. Que vous ayez besoin de fichiers multimédias, de scripts, de feuilles de style ou de réponses réseau, enregistrez-les individuellement ou sous forme d'archive ZIP structurée en dossiers.

Conçu intégralement à partir de zéro sans dépendances tierces : le moteur ZIP, le constructeur XLSX, le fusionneur HLS et les formateurs de code sont tous développés en JavaScript pur. Aucun framework, aucune étape de compilation, aucune télémétrie. Tout s'exécute localement dans votre navigateur.

Nouveautés de la version 1.15.0
- Captures d'écran pleine page avec assemblage automatique et capture de zone personnalisée.
- Enregistrement vidéo de l'écran et exportateur de GIF animés légers.
- Outil pipette pour prélever et copier instantanément des codes couleur à l'écran.
- Optimisations des performances et stabilité renforcée du sniffer DevTools.
- Support multilingue étendu : 4 nouvelles langues (français, italien, coréen, portugais brésilien) intégrées — désormais 11 langues entièrement localisées dans l'interface et le guide d'utilisation.
- Évolution vers 17 catégories dédiées de ressources avec compteurs en temps réel.

Pourquoi vous en avez besoin
Une simple capture statique ne suffit pas toujours. Récupérez les fichiers d'origine : images haute résolution, flux vidéo réels, feuilles de style et scripts sources non altérés.

Les outils de développement peuvent sembler intimidants. Source Download propose une galerie claire et ordonnée face aux mêmes données réseau, avec filtres, recherche et téléchargements instantanés.

Les applications web modernes masquent souvent des ressources dynamiques. Source Download intercepte les appels API et les éléments créés en cours d'exécution, y compris les états intermédiaires.

Fonctionnalités principales
Détection complète
Combine l'analyse des requêtes réseau et l'exploration récursive du DOM pour détecter chaque élément visible ou structurel.

Exploration CSS récursive : analyse les directives url(...) et @import pour localiser les polices web et images d'arrière-plan imbriquées.

Identification intelligente par signature : examine les premiers octets des réponses pour catégoriser avec précision les fichiers aux extensions ambiguës.

17 catégories avec décompte en directies organisées : médias, code source, données, requêtes réseau et documents structurés dans des sections dédiées.

Filtres et prévisualisation
Recherche textuelle et par expressions régulières (Regex) sur les noms de fichiers, URL et types MIME.

Filtres précis par taille de fichier (Ko) et par dimensions (largeur et hauteur en pixels pour les images).

Affichage en grille ou en liste avec visionneuse intégrée pour les images, vidéos, flux audio, vecteurs SVG et code source formaté.

Téléchargement structuré
Téléchargez les ressources sélectionnées, la vue filtrée en cours ou l'intégralité des éléments sous forme d'archive ZIP propre avec déduplication d'images intégrée.

Prise en charge vidéo et flux HLS
Détecte les flux de diffusion HLS (.m3u8) et permet de fusionner directement tous les segments vidéo en un fichier unique téléchargeable.

Extraction de texte et de tableaux
Capture les tableaux dynamiques avec historique des instantanés et exporte les données au format Markdown, CSV ou classeur Excel XLSX multi-feuilles.

Guide d'utilisation rapide

### 1. Installez Source Download et appuyez sur F12 sur n'importe quel site web.


### 2. Ouvrez l'onglet Source Download dans la barre d'outils DevTools.


### 3. Parcourez les catégories, filtrez selon vos critères et cochez les fichiers souhaités.


### 4. Lancez le téléchargement au format de votre choix.


Confidentialité et sécurité
Fonctionne à 100 % en local dans votre environnement de navigation. Aucun serveur intermédiaire, aucune collecte de données personnelles, aucune télémétrie.

Compatibilité
Nécessite Google Chrome 114 ou version ultérieure (Manifest V3).

## Installation & Démarrage rapide

### Méthode 1 : Installation via le Chrome Web Store officiel (Recommandée)
1. Rendez-vous sur la [fiche Chrome Web Store](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd).
2. Cliquez sur **Ajouter à Chrome** et confirmez.
3. Appuyez sur `F12` (ou `Cmd+Option+I` sur Mac) sur n’importe quelle page et ouvrez l’onglet **Source Download**.

### Méthode 2 : Chargement depuis le code source (Mode Développeur)
1. Clonez le dépôt officiel sur votre machine :
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Ouvrez `chrome://extensions` dans la barre d’adresse de Chrome.
3. Activez le **Mode développeur** en haut à droite.
4. Cliquez sur **Charger l’extension non empaquetée** et sélectionnez le dossier `source-download`.
