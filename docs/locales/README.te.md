Source Download అనేది వెబ్ పేజీ లోడ్ చేసే ప్రతి వనరును కనుగొని, పరిశీలించి, డౌన్‌లోడ్ చేసే Chrome DevTools ప్యానెల్. మీకు మీడియా ఫైళ్లు, డెవలపర్ స్క్రిప్ట్‌లు, స్టైల్ వనరులు లేదా నెట్‌వర్క్ ప్రతిస్పందనలు ఏవి కావాలన్నా, వాటిని వేర్వేరు ఫైళ్లుగా లేదా చక్కని, ఫోల్డర్ నిర్మాణంతో ఉన్న ZIPగా సేవ్ చేసుకోవచ్చు.

మూడవ పక్ష డిపెండెన్సీలు లేకుండా మొదటి నుండి నిర్మించబడింది: ZIP రైటర్, XLSX బిల్డర్, HLS మెర్జర్, కోడ్ ఫార్మాటర్లు అన్నీ చేతితో రాసిన సాదా JavaScript. ఫ్రేమ్‌వర్క్‌లు లేవు, బిల్డ్ స్టెప్ లేదు, టెలిమెట్రీ లేదు. ప్రతిదీ మీ బ్రౌజర్‌లో స్థానికంగానే నడుస్తుంది.

## v1.16.0లో కొత్తగా ఏముంది
- పూర్తి DevTools, స్టోర్ స్థానికీకరణతో 54 భాషల్లో సంపూర్ణ బహుభాషా మద్దతు.
- మీడియా, కోడ్, API, స్టోరేజ్, పత్రాలన్నింటినీ కవర్ చేసే 17 ప్రత్యేక లైవ్-కౌంట్ వనరు వర్గాలు.
- స్మార్ట్ స్టిక్కీ హెడర్ అణచివేతతో ఫుల్-పేజ్ స్టిచ్డ్ స్క్రీన్‌షాట్‌లు, కస్టమ్ ఏరియా క్యాప్చర్.
- స్క్రీన్ వీడియో రికార్డింగ్ (MP4), అంచు లీకేజీ లేని తేలికపాటి యానిమేటెడ్ GIF ఎగుమతి ఇంజిన్.
- లైవ్ DOM టేబుళ్లను బహుళ-షీట్ Microsoft Excel (.XLSX), CSVలోకి సంగ్రహించే ఎక్స్‌ట్రాక్టర్, DOM Zapper ఎలిమెంట్ రిమూవర్‌తో సహా.
- hex/rgb/hsl తక్షణ కాపీతో స్క్రీన్ కలర్ పికర్ సాధనం, ఇంటిగ్రేటెడ్ కోడ్ బ్యూటిఫైయర్.
- మెరుగైన DevTools స్నిఫర్ స్థిరత్వం, అధిక-కాన్కరెన్సీ నెట్‌వర్క్ పైప్‌లైన్.

## మీకు ఇది ఎందుకు కావాలి
స్క్రీన్‌షాట్ సరిపోదు. చదును చేసిన చిత్రం కాకుండా అసలైన ఫైళ్లను పొందండి — పూర్తి రిజల్యూషన్ చిత్రాలు, నిజమైన వీడియో స్ట్రీమ్‌లు, అసలు స్టైల్‌షీట్‌లు, స్క్రిప్ట్‌లు.

DevTools చాలా క్లిష్టంగా అనిపిస్తుంది. Source Download అదే నెట్‌వర్క్ డేటాను శోధన, ఫిల్టర్లు, ఒక్క క్లిక్ డౌన్‌లోడ్‌లతో శుభ్రమైన, వర్గీకరించిన గ్యాలరీలో చూపిస్తుంది.

SPAలు ప్రతిదాన్నీ దాచేస్తాయి. డైనమిక్ యాప్‌లు పేజీ సోర్స్‌లో మీకు కనిపించని వనరులను, API కాల్‌లను సృష్టిస్తాయి. Source Download వాటిని మధ్యంతర స్థితులతో సహా అవి జరిగే సమయంలోనే క్యాప్చర్ చేస్తుంది.

## ఇది ఏమి చేస్తుంది
### ప్రతిదీ కనుగొనండి
- నెట్‌వర్క్ క్యాప్చర్ (HAR + లైవ్ అభ్యర్థనలు)ను అన్ని దృశ్య, నిర్మాణ ఎలిమెంట్ల కోసం DOM స్కాన్‌తో కలుపుతుంది — మీడియా ఫైళ్లు, స్క్రిప్ట్‌లు, స్టైల్‌షీట్‌లు, ఎంబెడెడ్ ఫ్రేమ్‌లతో సహా.
- **CSS-అవగాహన:** url(...), @import నియమాల లోపల ఉన్న వనరులు పునరావృతంగా అనుసరించబడతాయి, కాబట్టి దిగుమతి చేసిన స్టైల్‌షీట్‌లలో దాగిన ఫాంట్‌లు కూడా దొరుకుతాయి.
- **కంటెంట్ స్నిఫింగ్:** తెలియని ఫైళ్ల మొదటి కొన్ని బైట్‌లు చదివి, వాటి అసలు ఫైల్ రకం వర్గానికి మారుస్తారు.
- **17 లైవ్-కౌంట్ వర్గాలు:** క్యాప్చర్ చేసిన వనరులు మీడియా, కోడ్, డేటా, API కాల్‌లు, కుకీలు, స్టోరేజ్, పత్రాల కోసం ప్రత్యేక ట్యాబ్‌లలో చక్కగా నిర్వహించబడతాయి.

### ఫిల్టర్ చేయండి, శోధించండి, పరిశీలించండి
- ఫైల్ పేర్లు, URLలు, MIME రకాలు, alt టెక్స్ట్, చివరకు ఫైల్ కంటెంట్లలో కూడా Regex ఆధారిత శోధన.
- **వర్గం వారీ ఫిల్టర్లు:** కనిష్ట/గరిష్ట పరిమాణం, మీడియాకు కనిష్ట/గరిష్ట వెడల్పు, ఎత్తు కూడా — ఉదాహరణకు "≥ 1200px ఉన్న హీరో చిత్రాలు మాత్రమే". API కాల్‌లను HTTP పద్ధతి, అభ్యర్థన రకం ప్రకారం ఫిల్టర్ చేయవచ్చు.
- లిస్ట్ లేదా గ్రిడ్ వీక్షణ, క్రమబద్ధీకరణ, లైవ్ థంబ్‌నెయిల్ వాల్‌తో.
- **నిజమైన ప్రివ్యూలతో బహుళ-ట్యాబ్ ఇన్‌స్పెక్టర్:** జూమ్ చేయగల లైట్‌బాక్స్, వీడియో, ఆడియో ప్లేబ్యాక్, లైవ్ ఫాంట్ స్పెసిమెన్, SVG వ్యూయర్, లైన్ నంబర్లతో సింటాక్స్-హైలైట్ చేసిన కోడ్, సుందరీకరించు టోగుల్.
- **API స్ప్లిట్ వ్యూ:** ఎడమవైపు ప్రతిస్పందన, కుడివైపు పద్ధతి, స్థితి, క్వెరీ పారామీటర్లు, అభ్యర్థన బాడీ.

### సరిగ్గా డౌన్‌లోడ్ చేయండి
- ఎంచుకున్నవాటిని డౌన్‌లోడ్ చేయండి — మీరు టిక్ చేసిన ఫైళ్లు మాత్రమే.
- వీక్షణను డౌన్‌లోడ్ చేయండి — ప్రస్తుత ఫిల్టర్లు, శోధన తర్వాత కనిపించే ప్రతిదీ.
- అన్నీ డౌన్‌లోడ్ చేయండి — క్యాప్చర్ చేసిన ప్రతి వనరు ఫోల్డర్ నిర్మాణం గల ZIPలో, ఆటోమేటిక్ డీ-డూప్లికేషన్‌తో.
- బ్యాచ్ డౌన్‌లోడ్‌లు పరిమిత కాన్కరెన్సీతో, లైవ్ ప్రోగ్రెస్ బార్‌తో నడుస్తాయి; విఫలమైనవి ఆటోమేటిక్‌గా, అలాగే కాంటెక్స్ట్ మెనూ నుండి మళ్లీ ప్రయత్నించబడతాయి.

### HLS, క్లిష్టమైన వీడియో
- బ్రౌజర్ స్థానికంగా ప్లే చేయలేని స్ట్రీమ్‌లు (HLS .m3u8, DASH .mpd, తెలియని కోడెక్‌లు) నల్లని ప్లేయర్‌కు బదులు స్మార్ట్ ప్రత్యామ్నాయాన్ని చూపిస్తాయి.
- సెగ్మెంట్‌లను విలీనం చేసి డౌన్‌లోడ్ చేయి, HLS స్ట్రీమ్‌ను ప్యానెల్‌లోనే ఒకే ప్లే చేయదగిన ఫైల్‌గా మారుస్తుంది.

### టెక్స్ట్ వర్క్‌బెంచ్ (SPA కంటెంట్ టూల్‌కిట్)
- **టెక్స్ట్ ట్యాబ్ ఒక లైవ్ కంటెంట్ వ్యూయర్:** శీర్షికలు, పేరాలు, జాబితా అంశాలు, బటన్లు, div, span వంటి టెక్స్ట్ ఉన్న ప్రతి ఎలిమెంట్ DOM క్రమంలో క్యాప్చర్ చేయబడుతుంది.
- డైనమిక్ టేబుళ్లు పరిమిత స్నాప్‌షాట్ చరిత్రను ఉంచుతాయి (ఉదా. "8 స్నాప్‌షాట్‌లు · 124 ప్రత్యేక వరుసలు"), కాబట్టి ఆటో-రిఫ్రెష్ అయ్యే డ్యాష్‌బోర్డ్‌లు మధ్యంతర స్థితులను కోల్పోవు.
- Markdownగా, లేదా టేబుళ్లను CSV, HTML లేదా మా స్వంత చేతితో రాసిన XLSX రైటర్ నిర్మించే నిజమైన బహుళ-షీట్ XLSX వర్క్‌బుక్‌గా ఎగుమతి చేయండి.

## ఎలా ఉపయోగించాలి
1. Source Downloadను ఇన్‌స్టాల్ చేసి, ఏదైనా పేజీలో F12 నొక్కండి.
2. DevTools టూల్‌బార్‌లోని Source Download ట్యాబ్‌ను క్లిక్ చేయండి (Chrome ఎక్స్‌టెన్షన్‌లు DevToolsను ఆటోమేటిక్‌గా తెరవడానికి అనుమతించదు — అందుకే అది అక్కడ ఉంటుంది).
3. వర్గ ట్యాబ్‌లను బ్రౌజ్ చేయండి, శోధించండి, ఫిల్టర్ చేయండి, కుడి ప్యానెల్‌లో దేన్నైనా పరిశీలించండి.
4. మీకు కావలసిన ఫైళ్లను టిక్ చేసి, ఎంచుకున్నవాటిని డౌన్‌లోడ్ చేయండి, వీక్షణను డౌన్‌లోడ్ చేయండి లేదా అన్నీ డౌన్‌లోడ్ చేయండి నొక్కండి.
5. ప్రతి నెట్‌వర్క్ అభ్యర్థనను క్యాప్చర్ చేయడానికి పేజీ లోడ్ అవుతున్నప్పుడు DevTools ప్యానెల్‌ను తెరిచి ఉంచండి.

## వాస్తవ వినియోగ సందర్భాలు
- **పోటీదారుల విశ్లేషణ:** ఏ ఛానెల్ నుంచైనా వీడియో థంబ్‌నెయిల్‌లను — కనిష్ట వెడల్పు ఫిల్టర్‌తో — ఒకే ఫోల్డర్‌లో సేకరించండి.
- **కోడ్ లేకుండా వెబ్ స్క్రాపింగ్:** SPA యొక్క API కాల్‌లను గమనించండి, మీకు కావలసిన ఎండ్‌పాయింట్‌కు ఫిల్టర్ చేయండి, దాని ఖచ్చితమైన JSON ప్రతిస్పందనలను డౌన్‌లోడ్ చేయండి.
- **టైపోగ్రఫీ విశ్లేషణ:** ఒక సైట్ నిజంగా ఏ ఫాంట్ వాడుతుందో తెలుసుకుని, అసలు ఫాంట్ ఫైళ్లను పొందండి.
- **బగ్ పునరుత్పత్తి:** బగ్ వచ్చినప్పుడు అమలులో ఉన్న ఖచ్చితమైన CSS/JS వెర్షన్‌లను భద్రపరచండి.
- **డ్యాష్‌బోర్డ్ డేటా ఎగుమతి:** ఆటో-రిఫ్రెష్ అయ్యే టేబుల్‌ను చరిత్రతో సహా బహుళ-షీట్ Excel వర్క్‌బుక్‌కు ఎగుమతి చేయండి.
- **QA పరీక్ష:** ప్రతి A/B కాన్ఫిగరేషన్‌లో ఏ వీడియో/ఆడియో వేరియంట్ అందించబడుతుందో ధృవీకరించండి.

## గోప్యత
- 100% స్థానికంగా నడుస్తుంది. సర్వర్ లేదు, అనలిటిక్స్ లేదు, ఏ డేటా మీ మెషీన్‌ను వదిలి వెళ్లదు.
- **అవసరమైనవి మాత్రమే అడుగుతుంది:** స్టోరేజ్ (మీ ప్రాధాన్యతలు), క్లిప్‌బోర్డ్ (URLలు, రంగులను కాపీ చేయడం), డౌన్‌లోడ్‌లు (Chrome ద్వారా ఫైళ్లను సేవ్ చేయడం), కాంటెక్స్ట్ మెనూలు, స్క్రిప్టింగ్, హోస్ట్ యాక్సెస్ (పేజీలను స్కాన్ చేయడానికి, ఫైల్ బాడీలను పొందడానికి).
- ఫైళ్లు Chrome యొక్క సాధారణ డౌన్‌లోడ్ ప్రవాహం ద్వారా సేవ్ అవుతాయి — రహస్య డౌన్‌లోడ్‌లు లేవు.

## ఇన్‌స్టాలేషన్, త్వరిత ప్రారంభం

### పద్ధతి 1: Chrome Web Store నుండి నేరుగా ఇన్‌స్టాల్ (సిఫార్సు)
1. అధికారిక [Source Download Chrome Web Store పేజీ](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd)ని సందర్శించండి.
2. **Chromeకు జోడించు** క్లిక్ చేసి అనుమతులు ఇవ్వండి.
3. Chrome DevToolsను తెరవండి (`F12` లేదా `Ctrl+Shift+I` / macOSలో `Cmd+Option+I`), **Source Download** ట్యాబ్‌ను క్లిక్ చేయండి లేదా పేజీలో ఎక్కడైనా రైట్-క్లిక్ చేయండి.

### పద్ధతి 2: సోర్స్ నుండి అన్‌ప్యాక్డ్ ఎక్స్‌టెన్షన్‌ను లోడ్ చేయండి (డెవలపర్ మోడ్)
1. అధికారిక GitHub రిపోజిటరీని క్లోన్ చేయండి:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Google Chromeను తెరిచి `chrome://extensions`కు వెళ్లండి.
3. ఎగువ కుడి మూలలో **డెవలపర్ మోడ్** టోగుల్‌ను ఆన్ చేయండి.
4. **అన్‌ప్యాక్ చేసినది లోడ్ చేయండి** క్లిక్ చేసి, క్లోన్ చేసిన `source-download` ప్రాజెక్ట్ ఫోల్డర్‌ను ఎంచుకోండి.
