Source Download — це панель Chrome DevTools, яка знаходить, досліджує та завантажує кожен ресурс, що його завантажує вебсторінка. Потрібні медіафайли, скрипти розробника, стилі чи мережеві відповіді — зберігайте їх окремими файлами або акуратним ZIP-архівом зі структурою папок.

Створено з нуля без сторонніх залежностей: ZIP-архіватор, конструктор XLSX, об'єднувач HLS і форматувальники коду — усе це чистий JavaScript, написаний вручну. Жодних фреймворків, етапу збирання чи телеметрії. Усе працює локально у вашому браузері.

## Навіщо це потрібно
Скріншота замало. Отримайте справжні файли — зображення в повній роздільній здатності, реальні відеопотоки, оригінальні таблиці стилів і скрипти, а не пласку картинку.

DevTools здається складним. Source Download показує ті самі мережеві дані у зрозумілій галереї за категоріями з пошуком, фільтрами та завантаженням одним кліком.

SPA приховують усе. Динамічні застосунки створюють ресурси та API-виклики, яких не видно у вихідному коді сторінки. Source Download фіксує їх у момент появи, зокрема проміжні стани.

### Знаходить усе
- Поєднує мережеве захоплення (HAR + живі запити) зі скануванням DOM для всіх візуальних і структурних елементів, зокрема медіафайлів, скриптів, таблиць стилів і вбудованих фреймів.
- **Розуміє CSS:** ресурси всередині url(...) і правил @import відстежуються рекурсивно, тож знаходяться навіть шрифти, заховані в імпортованих таблицях стилів.
- **Визначення за вмістом:** невідомі файли зчитуються на кілька байтів і переносяться до категорії їхнього справжнього типу.
- **17 категорій із живими лічильниками:** захоплені ресурси акуратно розподілено за окремими вкладками — медіа, код, дані, API-виклики, cookie, сховище та документи.

### Фільтруйте, шукайте, досліджуйте
- Пошук за регулярними виразами в іменах файлів, URL, типах MIME, alt-текстах і навіть у вмісті файлів.
- **Фільтри для кожної категорії:** мінімальний/максимальний розмір, а для медіа ще й мінімальна/максимальна ширина й висота — наприклад, «лише головні зображення ≥ 1200px». API-виклики фільтруються за методом HTTP і типом запиту.
- Список або сітка, сортування, жива стіна мініатюр.
- **Багатовкладковий інспектор зі справжнім попереднім переглядом:** лайтбокс із масштабуванням, відео- й аудіовідтворення, живий зразок шрифту, засіб перегляду SVG, код із підсвічуванням синтаксису та номерами рядків і перемикач «Прикрашати».
- **Розділений перегляд API:** відповідь ліворуч, метод, статус, параметри запиту й тіло запиту праворуч.

### Завантажуйте правильно
- Завантажити вибране — лише позначені файли.
- Завантажити перегляд — усе, що видно після застосування поточних фільтрів і пошуку.
- Завантажити всі — кожен захоплений ресурс у ZIP зі структурою папок і автоматичним усуненням дублікатів.
- Пакетні завантаження виконуються з обмеженою паралельністю та живим індикатором прогресу; невдалі автоматично повторюються, також їх можна повторити з контекстного меню.

### HLS і складне відео
- Для потоків, які браузер не може відтворити нативно (HLS .m3u8, DASH .mpd, невідомі кодеки), замість чорного плеєра показується розумна альтернатива.
- Функція «Об'єднати сегменти й завантажити» перетворює потік HLS на один придатний для відтворення файл просто в панелі.

### Текстова робоча область (набір для вмісту SPA)
- **Вкладка «Текст» — це живий переглядач вмісту:** кожен елемент із текстом — заголовки, абзаци, пункти списків, кнопки, div, span — фіксується в порядку DOM.
- Динамічні таблиці зберігають обмежену історію знімків (наприклад, «8 знімків · 124 унікальні рядки»), тож інформаційні панелі з автооновленням ніколи не втрачають проміжні стани.
- Експорт у Markdown, а таблиць — у CSV, HTML або справжню багатоаркушеву книгу XLSX, створену нашим рукописним XLSX-записувачем.

## Як користуватися
1. Установіть Source Download, потім натисніть F12 на будь-якій сторінці.
2. Клацніть вкладку Source Download на панелі інструментів DevTools (Chrome не дозволяє розширенням автоматично відкривати DevTools — тому вона розташована саме там).
3. Переглядайте вкладки категорій, шукайте, фільтруйте, досліджуйте будь-що у правій панелі.
4. Позначте потрібні файли й натисніть Завантажити вибране, Завантажити перегляд або Завантажити всі.
5. Тримайте панель DevTools відкритою під час завантаження сторінки, щоб захопити кожен мережевий запит.

## Реальні сценарії використання
- **Аналіз конкурентів:** зберіть мініатюри відео з будь-якого каналу — з фільтром мінімальної ширини — в одну папку.
- **Веб-скрейпінг без коду:** спостерігайте за API-викликами SPA, відфільтруйте потрібну кінцеву точку, завантажте її точні відповіді JSON.
- **Розбір типографіки:** дізнайтеся, який шрифт насправді використовує сайт, і отримайте справжні файли шрифтів.
- **Відтворення помилок:** збережіть точні версії CSS/JS, що діяли, коли виникла помилка.
- **Експорт даних інформаційної панелі:** експортуйте таблицю з автооновленням у багатоаркушеву книгу Excel разом з історією.
- **QA-тестування:** перевіряйте, який варіант відео/аудіо віддається в кожній A/B-конфігурації.

## Встановлення та швидкий старт

### Спосіб 1: пряма установка з Chrome Web Store (рекомендовано)
1. Перейдіть на офіційну [сторінку Source Download у Chrome Web Store](https://chromewebstore.google.com/detail/source-download/nockdgincmpfojabnhbofkddgcmnodpd).
2. Натисніть **Додати до Chrome** і надайте дозволи.
3. Відкрийте Chrome DevTools (`F12` або `Ctrl+Shift+I` / `Cmd+Option+I` у macOS) і клацніть вкладку **Source Download** або клацніть правою кнопкою миші будь-де на сторінці.

### Спосіб 2: завантаження нерозпакованого розширення з вихідного коду (режим розробника)
1. Клонуйте офіційний репозиторій GitHub:
```bash
git clone https://github.com/turanburakyesilyurt/source-download.git
cd source-download
```
2. Відкрийте Google Chrome і перейдіть за адресою `chrome://extensions`.
3. Увімкніть перемикач **Режим розробника** у правому верхньому куті.
4. Натисніть **Завантажити розпаковане розширення** і виберіть клоновану папку проєкту `source-download`.
